## 零、一页摘要

**做什么。** 给定介质的 (ρ₀, c₀) 与接触面积比例 η，用无限障板圆活塞的辐射阻抗
算出 R_rad + jX_rad，折算到机械支路，由它导出 Rm、Lm、fs、Qm。
登记表从"八个互不相干的百分比因子"改成"一张二维负载格点"，每个点都能说出物理含义。

**为什么值得做。** 当前登记表的 Qm 族是 500 / 800 / 1000，峰宽 1800 / 1125 / 900 Hz。
复算表明，**这几乎精确地就是这只器件在空气中的表现**（固有 Qm 500 / 1000 / 2000
在空气中给出 Q_total 498.0 / 992.0 / 1968.3，峰宽 1807 / 907 / 457 Hz）。
换句话说，**登记表整族都待在"没有声负载"这个极端里，从未访问过器件真正工作的区域**。
有声负载时 Q 掉到 7–66，峰宽 8–130 kHz。

**不做什么。** 不删除现有 34 个场景，不改 `workspace/`，不动任何验收门槛，
不引入压电材料常数，不做二维/三维声场求解。

**最重要的一条先说：** 加载之后端口可交付功率从 0.170 W 掉到 0.0112 W（约 15 倍），
且限幅从"源幅度饱和"翻成"电压软限"。
**现有 L 型匹配是按未加载的 7.35 kΩ 设计的，在血液全接触的 189 kΩ 下严重失配。**
不先处理这一条，二维格点跑出来会是"每个点都被电压限死、只交付 6% 设计功率"，
很容易被误读成控制失败。详见第八节。

## 一、登记表缺了什么（修正后的证据）

先声明：本节引用的数字是**修正过的**。此前我给出的一版有三处错误，
错误内容与修正见第三节，请务必先读那一节再读这里的表。

### 1.1 Rm 只有增加方向

| 来源 | Rm 相对基线 |
|---|---|
| 登记表 `CASE_RM_P15/P30/P50` | ×1.15、×1.30、×1.50（**只增不减**） |
| 物理负载（相对未加载基线） | 空气 ×1.0、血液 25% ×7.2、血液全接触 ×25.7、钙化全接触 ×30.8 |
| 物理负载（相对"血液全接触"标称） | 空气 −96.1%、血液 25% **−72.1%**、钙化全接触 +19.9% |

失去接触会让 Rm **下降**，而且是大幅下降。登记表里没有任何一个场景是这个方向。
这是真实的覆盖缺口。

### 1.2 相关因子被当成独立因子

钙化全接触同时给出 **Rm 相对血液标称 +19.9%** 与 **fs −2.63%**。
这两件事在物理上是**同一个事件**（换了个声阻抗更高、声速更快的介质），
而登记表把 `CASE_RM_*` 与 `CASE_FS_*` 当成两个独立因子分别扫。
二维格点天然地把它们绑在一起。

### 1.3 Qm 族整族待在空气端

| 来源 | Qm | 峰宽 |
|---|---|---|
| 登记表 Qm 族 | 500 – 1000 | 900 – 1800 Hz |
| **同一器件在空气中**（固有 Qm 500 / 1000 / 2000） | 498.0 / 992.0 / 1968.3 | 1807 / 907 / 457 Hz |
| 有声负载的工况（a = 0.5 mm） | 27 – 112 | 8 029 – 32 201 Hz |
| 有声负载（半径扫到 0.3–1.5 mm） | 6.8 – 66 | 13 335 – 129 286 Hz |

空气中辐射阻只有 3.23e-4 kg/s，而内部机械阻尼是 5.02e-2 kg/s，
小两个数量级，所以空气中 Q 完全被内部损耗封顶（Q_rad = 124 174，几乎不起作用）。

**结论的方向很重要，不要说反：** 登记表不是"避开了最难的窄峰极端"，
而是"整族都待在那个极端里，缺席的是加载端"。而加载端的峰宽是粗扫步长 5 kHz 的
**1.6 到 26 倍**，对扫描反而更容易。所以第一层的价值是**物理可解释性与覆盖缺口**，
不是"给扫描加难度"。第九节会再强调一次：**窄峰场景必须保留，不许删。**

## 二、物理推导

### 2.1 一维集总等效

机械支路的质量 m、刚度 k、阻尼 c 通过机电变比 φ 映射到电学量：

```
Lm = m/φ²        Cm = φ²/k        Rm = c/φ²
ω_s = √(k/m) = 1/√(Lm·Cm)        Qm = ω_s·Lm/Rm = ω_s·m/c
```

### 2.2 串联辐射阻抗

无限障板中的圆活塞向 (ρ₀, c₀) 半空间辐射，力/速度意义上的辐射阻抗为

```
Z_rad = ρ₀·c₀·A·[ R1(2ka) + j·X1(2ka) ]          单位 kg/s
R1(x) = 1 − 2·J1(x)/x
X1(x) = 2·H1(x)/x            H1 为一阶 Struve 函数
k = ω/c₀        A = πa²
```

把它串进机械支路：

```
c → c + R_rad          m → m + m_rad          k 不变
R_rad = ρ₀c₀A·R1(2ka)          m_rad = ρ₀c₀A·X1(2ka)/ω
```

**刚度不变，所以 Cm 不变。** 这是第七节里 `CASE_CM_*` 不被涵盖的原因。

### 2.3 折算回 BVD

```
Rm' = Rm·(1 + R_rad/c)          Lm' = Lm·(1 + m_rad/m)          Cm' = Cm
fs' = 1/(2π√(Lm'·Cm))           Qm' = 2π·fs'·Lm'/Rm'
```

### 2.4 φ 约掉了，但 L 与 ρ 没有

两个比值里 φ 都不出现，所以**第一层不需要压电材料矩阵或顺服系数**——
这是它与第二、三层的关键区别，也是推荐它的主要理由。

但请注意一个我此前说过头的地方：**这不等于"什么绝对量都不需要"。**
把 m = ρ_PZT·A·L/2 与 R_rad、m_rad 代入：

```
R_rad/(ω·m) = 2·ρ₀·c₀·R1(2ka) / (ω·ρ_PZT·L)
m_rad/m     = 2·ρ₀·c₀·X1(2ka) / (ω·ρ_PZT·L)
```

端面面积 A **约掉了**，但是：

- **L（半波厚度）与 ρ_PZT（密度）以绝对量出现，必须声明；**
- **半径 a 仍然通过 2ka 进入 R1 与 X1**，而且那个依赖在 2ka ≈ 1–4 时非常陡（见第四节）。

诚实的表述是：**第一层需要端面几何与密度，第二层还额外需要压电材料常数。
差别是真实的，但比"第一层什么都不需要"要小。**

其中 `m = ρ·A·L/2` 的因子 1/2 来自半波厚度模式的正弦模态形状，是一个**声明的近似**，
不是从模型推出来的。

### 2.5 Q 的倒数分解

```
1/Q_total = 1/Q_int' + 1/Q_rad
Q_int' = ω'·m'/c = Q_int·√(1 + m_rad/m)
Q_rad  = ω'·m'/R_rad
```

**注意 Q_int' 与 Q_rad 都要在*加载后*的质量与频率上取值**，
用未加载的 ω、m 会得到 1% 量级的偏差。
参考实现里这条恒等式是一个运行时 `assert`，不是注释，请照做。

## 三、三个必须避免的错误（我都犯过）

### 3.1 Struve H1 的级数写错

正确的是

```
H1(z) = Σ_{k≥0} (−1)^k · (z/2)^(2k+2) / ( Γ(k+3/2) · Γ(k+5/2) )
```

两个 Gamma 的**宗量不同**，而且**没有 2/π 前因子**。
我此前写成 `Γ(k+1.5)²` 并多乘了 2/π：

| z | 错写法 | 正确值（级数 = scipy = A&S 表） |
|---|---|---|
| 1.0 | 0.181009 | **0.198457** |
| 3.0 | 0.548422 | **1.020110** |
| 5.0 | −0.294782 | **0.807812** |

到 z = 5 连符号都反了。由此给出的所有 fs 位移数字都是错的。

**强制要求：** 实现必须带一个测试，把级数同时对上
`scipy.special.struve(1, z)` 与上表的参考值，容差 1e-5。

### 3.2 算出负的附加质量却放过了

X1(x) = 2H1(x)/x 在 x > 0 上**恒正**，因此附加质量恒正。
我当时算出血液工况 X1 为负——负的附加质量在物理上不可能——
只在心里记了一句"奇怪"，没有追下去。那正是 3.1 的症状。

**强制要求：** `assert X1(x) > 0` 作为运行时断言，覆盖 0.05 ≤ x ≤ 33 的取样点。
**物理上不可能的中间量出现时必须让程序停下来，不许靠人眼发现。**

### 3.3 把 Q_辐射 当成 Q_总

我在同一段里刚推导完 `1/Q = 1/Q_int + 1/Q_rad`，紧接着就直接把 Q_rad 当成 Q_total 报了出去。

| 工况 | 我原来报的 | 正确 Q_total | 峰宽 |
|---|---|---|---|
| 血液 25% 接触 | 119.8 | **111.82** | 8 029 Hz |
| 血液 全接触 | 30.0 | **31.47** | 28 318 Hz |
| 钙化 全接触 | 15.5 | **26.95** | 32 201 Hz |

加载工况下两者差别不大，因为辐射确实主导；但**空气工况差两个数量级**
（Q_rad = 124 174 对 Q_total = 794.88），而空气工况恰恰是登记表所在的位置。

**强制要求：** 第 2.5 节的倒数恒等式作为运行时 `assert`。

## 六、二维格点的定义

### 6.1 两个轴

- **轴一：介质。** 必须是**具名介质加 (ρ₀, c₀) 对**，**不能**退化成单一声阻抗标量。
  理由：c₀ 单独通过 k = ω/c₀ 进入 2ka。血液与钙化的 Z 差 4.1 倍，
  但同样半径下 R1 差 3.4 倍（0.947 对 0.278），方向相反地抵消了一部分。
  只报 Z 会算错。
- **轴二：接触面积比例 η ∈ [0, 1]。** 未接触的部分仍看空气。

建议取值：介质 ∈ {air, blood, calcif}，η ∈ {0, 0.25, 0.5, 0.75, 1.0}。
15 个格点，去掉重复的 η = 0（三者相同）之后 13 个。

### 6.2 标称点取"血液 全接触"

这是器件的**设计工作点**，不是空气。以它为格点原点，
相对变化才有工程含义（第 1.1 节的 −72.1% 就是这么来的）。

### 6.3 部分覆盖用线性叠加，并且必须声明这是近似

```
Z_rad(η) = η·Z_rad(medium) + (1−η)·Z_rad(air)
```

**严格的活塞辐射函数假定整个端面均匀加载，部分覆盖不满足这个前提。**
真实的部分浸没会改变模态形状与辐射方向性。这是一个声明的一阶近似，
必须写在 JSON 的注释字段与文档里，不许悄悄用。

## 七、与现有 34 个场景的关系

### 7.1 不许删除现有登记表

用户的原话是"34 个场景会被一个二维扫描取代"。**这一条我要提出异议并说明理由，
然后按"新增而非替换"实施。**

理由：现有 34 个场景支撑着 `workspace/` 里全部历史批次、`reports/` 里的 32 页汇报、
以及 `review/07`–`review/13` 的全部对照结果。README 明确写着
"算法消融、失败和历史批次保留，不用后续成绩覆盖旧结果"。
**删掉它们等于放弃与此前每一个批次做同口径比较的能力，**
而那正是最近三轮审核里唯一稳定的证据来源。

**实施方式：** 负载格点作为**新增的场景族**并行存在，
旧的 34 个原样保留且仍可运行。两套各自出批次，各自报告，互不覆盖。
如果之后确认要收敛到一套，那是一个单独的、需要重跑全部历史对照的决定。

### 7.2 哪些单因子族被负载层涵盖

| 族 | 场景数 | 是否被涵盖 | 理由 |
|---|---|---|---|
| `CASE_RM_*` | 3 | **是** | R_rad 直接改机械阻尼 |
| `CASE_LM_*` | 3 | **是** | m_rad 直接改有效质量 |
| `CASE_FS_*` | 3 | **是** | fs 由 Lm′、Cm 导出，不再独立 |
| `CASE_QM_*` | 3 | **是** | Qm 由 ω′Lm′/Rm′ 导出，不再独立 |
| `CASE_CM_*` | 3 | **否** | Cm 是刚度，流体辐射负载不改刚度（见 2.2） |
| `CASE_C0_*` | 3 | **否** | 静态电容，与声负载无关 |
| `CASE_RS_*` | 3 | **否** | 源内阻，驱动侧 |
| `CASE_LMATCH_*` | 3 | **否** | 匹配网络 |
| `CASE_CMATCH_*` | 3 | **否** | 匹配网络 |
| `CASE_QL_*` | 3 | **否** | 匹配电感 Q，网络侧 |

**12 个被涵盖，18 个不被涵盖**，另有基线 1 个与组合 3 个。
所以"二维格点取代 34 个场景"这句话在物理上只对其中 12 个成立。
新的登记表应当是：**负载格点（13 个） × 保留的网络/电学单因子（18 个）**，
两者正交，不要混成一维列表。

### 7.3 组合场景怎么办

现有 `CASE_COMBINED_LOW/MEDIUM/HIGH` 把多个因子同时拉偏。
负载格点已经天然包含了 Rm、Lm、fs、Qm 的**物理相关**组合，
所以组合场景应当重新定义为"负载格点的一个点 + 网络因子的一个偏置"，
而不是继续手工拼百分比。这一步可以放到第二次迭代。

## 八、必须先处理：加载后匹配网络严重失配

这是本文最重要的一条工程结论。用冻结模型实算（100 Hz 网格、软限 130 Vpp / 5.5 mA）：

| 工况 | 峰频 | 峰值 P_Rm | 所需源幅度 | 峰处 Vpp | 峰处 mA_rms | 限幅来源 |
|---|---|---|---|---|---|---|
| 未加载基线 | 900 000 Hz | **0.17000 W** | 1.000 | 100.00 | 5.000 | 源幅度饱和 |
| 空气 全接触 | 900 000 Hz | 0.16993 W | 1.000 | 100.30 | 4.985 | 源幅度饱和 |
| 血液 25% 接触 | 897 800 Hz | 0.04006 W | 0.778 | 130.00 | 1.977 | **电压软限** |
| 血液 全接触 | 891 200 Hz | **0.01119 W** | 0.735 | 130.00 | 1.782 | **电压软限** |
| 钙化 全接触 | 867 800 Hz | 0.00933 W | 0.896 | 130.00 | 1.731 | **电压软限** |

三件事同时发生：

1. **可交付功率掉了约 15 倍**（0.170 → 0.0112 W）。
2. **限幅来源翻转**：未加载时是"源幅度已经到 1"，加载后变成电压软限；
   **电流软限 5.5 mA 完全不再起作用**（只到 1.78 mA）。
3. 峰频下移最多 −3.6%（867.8 kHz），仍在 0.8–1.0 MHz 带内。

根因：L 型匹配是按未加载的 Rm = 7.35 kΩ 设计的，
而血液全接触的 Rm′ = 188.7 kΩ，**差 25.7 倍**。

**因此实施顺序必须是：**

1. 先把负载层建起来，把上表复算出来（这一步就是交付物之一）；
2. **在跑任何控制验证之前**，明确回答"匹配网络按哪个工况设计"。
   两个选项：(a) 保持现网络，把失配作为一条**结论**报出来；
   (b) 为"血液全接触"重新设计匹配，作为新的标称。
   **不要默默选 (a) 然后去跑三策略排名**——那会得到一张每个点都被电压限死的表。
3. 无论选哪个，都要把"限幅来源"作为一列写进每段指标，否则读者无法判断
   捕获率低是控制没跟上还是物理上就交付不了。

**此处为模糊推测内容：** 我认为选 (b) 更接近真实工程，但重新设计匹配会改变
`stage2_匹配设计参数.json`，进而改变全部历史对照的基准，代价不小。
这是一个需要人来拍板的取舍，不要由实现自行决定。

## 九、对控制验证的影响：变容易了，不是变难了

| 来源 | 峰宽 | 相对粗扫步长 5 kHz |
|---|---|---|
| 登记表 Qm 族 | 900 – 1800 Hz | **0.18 – 0.36 倍（比一个粗格还窄）** |
| 负载格点（a = 0.5 mm） | 8 029 – 32 201 Hz | 1.6 – 6.4 倍 |
| 负载格点（半径扫 0.3–1.5 mm） | 13 335 – 129 286 Hz | 2.7 – 26 倍 |

一级扫描半窗是 ±50 kHz，负载引起的 fs 位移最大 −3.6%（−32 kHz），**在窗内**。

所以：

- **负载格点对三级扫描是容易的**，它不构成新的搜索压力；
- **真正难的是登记表里那些比一个粗格还窄的峰**，
  它们对应的是"器件脱离接触、在空气中"的工况。

**强制要求：不许因为"空气工况不现实"就把窄峰场景删掉。**
它们是当前唯一能压住三级扫描分辨率的用例，删掉之后验证会变弱而不是变强。
正确做法是把它们**重新标注**为"脱离接触 / 空气加载"这一物理工况，
放进负载格点的 η = 0 一端，而不是当成一个来路不明的 Qm 百分比。

**此处为模糊推测内容：** 低 Q 加载工况下峰变得又宽又浅，
匹配网络自身的频率依赖会与换能器峰变得可比。
`review/04` 里记录过 `arg(Zin)` 在中等以上扰动下会锁到匹配网络零点
（基线下该零点在 903 950 Hz）。加载之后这个问题是缓解还是加重，
**必须实测，不许假设**。这是负载层建好之后第一个该跑的诊断。

## 十二、局限与模糊推测清单

以下是本方案**已知站不住或未经验证**的地方，必须随交付物一起写明。

1. **无限障板圆活塞是一个理想化。** 真实的 CTO 导管头端没有无限障板，
   近场、导管本身的散射、非活塞式的模态形状都不满足前提。
   这是一阶模型，不是声场求解。

2. **把钙化斑块当成流体半空间是更强的理想化。** 固体接触会同时引入**刚度**，
   而本模型假定刚度不变（2.2 节）。**此处为模糊推测内容：**
   我预计刚度耦合会把 fs 往**上**推，与质量负载的方向相反，量级不明。

3. **钙化的 (ρ₀, c₀) 文献离散度很大。** 本文用 1900 kg/m³、3600 m/s（6.840 MRayl）。
   不同来源给出的钙化声阻抗从约 2.5 到 7.8 MRayl 都有。
   **此处为模糊推测内容：** 取值变化会显著改变第 10.3 节的钙化两行，
   但不改变"加载端 Q 在几十量级"这个结论。交付时请给出至少两组取值的对照。

4. **部分覆盖的线性叠加没有依据。**（6.3 节）

5. **m = ρAL/2 的因子 1/2 是声明的模态近似。**（2.4 节）

6. **血液的声衰减完全没有建模。** 本模型把介质当成无损耗半空间，
   只取 (ρ₀, c₀)。真实血液在 0.9 MHz 有可测的衰减。
   **此处为模糊推测内容：** 我预计衰减主要影响远场声强而不是负载阻抗的实部，
   因此对本层的 Rm、fs 影响较小，但没有验证。

7. **未加载基线的 Qm = 800 本身就是假设值**，不是实测。
   整个负载层建立在它之上，所以所有绝对数字都继承了这个假设。
   相对变化（第 1.1 节的 −72.1% 之类）比绝对值更可信。

8. **第八节的失配结论依赖现有匹配网络参数**，那也是设计值不是实测值。

9. 本文**未运行 LTspice、未做硬件实验、未做 COMSOL 或声场验证**，
   也未证明真实电路瞬态全过程不越限。

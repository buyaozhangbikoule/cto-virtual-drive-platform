## 零、一页摘要

**做什么。** 给定介质的 (ρ₀, c₀) 与接触面积比例 η，用无限障板圆活塞的辐射阻抗
算出 R_rad + jX_rad，折算到机械支路，由它导出 Rm、Lm、fs、Qm。
登记表从"八个互不相干的百分比因子"改成"一张二维负载格点"，每个点都能说出物理含义。

**为什么值得做。** 当前登记表的 Qm 族是 500 / 800 / 1000，机械支路常压 FWHM 为
1800 / 1125 / 900 Hz。复算表明，**在「把现有 BVD 当作未加载内部支路」这一假设下**，
叠加空气代理负载几乎不改变它（固有 Qm 500 / 1000 / 2000 → Q_total 498.0 / 992.0 / 1968.3，
FWHM 1807 / 907 / 457 Hz）。换句话说，**在该假设下登记表整族都落在"声负载可忽略"这一端，
从未访问过器件预期工作的加载端**。有声负载时 Q 掉到 7–66，支路 FWHM 8–130 kHz。
〔已改正〕原文写作"这几乎精确地就是这只器件在空气中的表现"，是把一个条件结论说成了事实，
理由见 1.3 节的勘误。

**不做什么。** 不删除现有 34 个场景，不改 `workspace/`，不动任何验收门槛，
不引入压电材料常数，不做二维/三维声场求解。

**最重要的一条先说：** 加载之后端口可交付功率从 0.170 W 掉到 0.0112 W（约 15 倍），
且限幅从"源幅度饱和"翻成"电压软限"。
〔已改正〕原文把这 15 倍归因为"现有 L 型匹配严重失配"，**这是错的，方向正好相反**。
机械支路功率有一个与匹配元件选择无关的解析上界 `P ≤ V_pp²/(8·Rm′)`；
血液全接触下该上界是 11.192164 mW，而现有网络实得 11.192121 mW，
**已达上界的 99.9996%——现网络在该工况下已经是最优的，没有失配可修。**
要在该 Rm′ 下达到 170 mW，即使正好串联谐振也需要约 506.65 Vpp，远超 160 Vpp 边界。
所以这 15 倍是端口电压边界下的**硬物理约束**，不是可以靠重新匹配消除的损失。详见第八节。

## 一、登记表缺了什么（修正后的证据）

先声明：本节引用的数字是**修正过的**。此前我给出的一版有三处错误，
错误内容与修正见第三节，请务必先读那一节再读这里的表。

### 1.1 Rm 只有增加方向

| 来源 | Rm 相对基线 |
|---|---|
| 登记表 `CASE_RM_P15/P30/P50` | ×1.15、×1.30、×1.50（**只增不减**） |
| 物理负载（相对未加载基线） | 空气 ×1.0、血液 25% ×7.2、血液全接触 ×25.7、钙化全接触 ×30.8 |
| 物理负载（相对"血液全接触"标称） | 空气 −96.1%、血液 25% **−72.1%**、钙化全接触 +19.9% |

失去接触会让 Rm **下降**，而且是大幅下降。登记表里没有任何一个场景是这个方向。
这是真实的覆盖缺口。

### 1.2 相关因子被当成独立因子

钙化全接触同时给出 **Rm 相对血液标称 +19.9%** 与 **fs −2.63%**。
这两件事在物理上是**同一个事件**（换了个声阻抗更高、声速更快的介质），
而登记表把 `CASE_RM_*` 与 `CASE_FS_*` 当成两个独立因子分别扫。
二维格点天然地把它们绑在一起。

### 1.3 Qm 族整族待在空气端

| 来源 | Qm | 机械支路常压 FWHM（fs/Qm） |
|---|---|---|
| 登记表 Qm 族 | 500 – 1000 | 900 – 1800 Hz |
| **在「现有 BVD = 未加载支路」假设下叠加空气代理**（固有 Qm 500 / 1000 / 2000） | 498.0 / 992.0 / 1968.3 | 1807 / 907 / 457 Hz |
| 有声负载的工况（a = 0.5 mm） | 27 – 112 | 8 029 – 32 201 Hz |
| 有声负载（半径扫到 0.3–1.5 mm） | 6.8 – 66 | 13 335 – 129 286 Hz |

〔已改正〕原表第二行写作「**同一器件在空气中**」，是肯定后件：
本项目没有实测阻抗，现有 Rm、Lm 是否已含某种负载损耗**并未经辨识确定**。
「加上空气代理后 Q 变化很小」只能说明*新增的*空气负载量小，
**不能反过来证明原参数就是某只真实器件的空气状态**；若原参数已含负载，这里还会重复计入。
正确口径：只在新增研究分支里**假设**把现有 BVD 用作未加载内部支路，再叠加假设辐射负载；
历史 34 场景的身份、文件与结论**不追溯改名**。
「这些参数对应真实器件的空气或血液状态」属于**此处为模糊推测内容**，需实测阻抗或更高层结构声学模型确认。

〔已改正〕原表列头写「峰宽」，实为 `fs/Qm`，即**孤立机械支路在常端口电压下**的半功率全宽，
**不是系统功率 FWHM**。两者定义不同，见第九节与 F4。

空气中辐射阻只有 3.23e-4 kg/s，而内部机械阻尼是 5.02e-2 kg/s，
小两个数量级，所以空气中 Q 完全被内部损耗封顶（Q_rad = 124 174，几乎不起作用）。

**结论的方向很重要，不要说反：** 登记表不是"避开了最难的窄峰极端"，
而是"整族都待在那个极端里，缺席的是加载端"。而加载端的峰宽是粗扫步长 5 kHz 的
**1.6 到 26 倍**，对扫描反而更容易。所以第一层的价值是**物理可解释性与覆盖缺口**，
不是"给扫描加难度"。第九节会再强调一次：**窄峰场景必须保留，不许删。**

## 二、物理推导

### 2.1 一维集总等效

机械支路的质量 m、刚度 k、阻尼 c 通过机电变比 φ 映射到电学量：

```
Lm = m/φ²        Cm = φ²/k        Rm = c/φ²
ω_s = √(k/m) = 1/√(Lm·Cm)        Qm = ω_s·Lm/Rm = ω_s·m/c
```

### 2.2 串联辐射阻抗

无限障板中的圆活塞向 (ρ₀, c₀) 半空间辐射，力/速度意义上的辐射阻抗为

```
Z_rad = ρ₀·c₀·A·[ R1(2ka) + j·X1(2ka) ]          单位 kg/s
R1(x) = 1 − 2·J1(x)/x
X1(x) = 2·H1(x)/x            H1 为一阶 Struve 函数
k = ω/c₀        A = πa²
```

把它串进机械支路：

```
c → c + R_rad          m → m + m_rad          k 不变
R_rad = ρ₀c₀A·R1(2ka)          m_rad = ρ₀c₀A·X1(2ka)/ω
```

**刚度不变，所以 Cm 不变。** 这是第七节里 `CASE_CM_*` 不被涵盖的原因。

### 2.3 折算回 BVD

```
Rm' = Rm·(1 + R_rad/c)          Lm' = Lm·(1 + m_rad/m)          Cm' = Cm
fs' = 1/(2π√(Lm'·Cm))           Qm' = 2π·fs'·Lm'/Rm'
```

### 2.4 φ 约掉了，但 L 与 ρ 没有

两个比值里 φ 都不出现，所以**第一层不需要压电材料矩阵或顺服系数**——
这是它与第二、三层的关键区别，也是推荐它的主要理由。

但请注意一个我此前说过头的地方：**这不等于"什么绝对量都不需要"。**
把 m = ρ_PZT·A·L/2 与 R_rad、m_rad 代入：

```
R_rad/(ω·m) = 2·ρ₀·c₀·R1(2ka) / (ω·ρ_PZT·L)
m_rad/m     = 2·ρ₀·c₀·X1(2ka) / (ω·ρ_PZT·L)
```

端面面积 A **约掉了**，但是：

- **L（半波厚度）与 ρ_PZT（密度）以绝对量出现，必须声明；**
- **半径 a 仍然通过 2ka 进入 R1 与 X1**，而且那个依赖在 2ka ≈ 1–4 时非常陡（见第四节）。

诚实的表述是：**第一层需要端面几何与密度，第二层还额外需要压电材料常数。
差别是真实的，但比"第一层什么都不需要"要小。**

其中 `m = ρ·A·L/2` 的因子 1/2 来自半波厚度模式的正弦模态形状，是一个**声明的近似**，
不是从模型推出来的。

### 2.5 Q 的倒数分解

```
1/Q_total = 1/Q_int' + 1/Q_rad
Q_int' = ω'·m'/c = Q_int·√(1 + m_rad/m)
Q_rad  = ω'·m'/R_rad
```

**注意 Q_int' 与 Q_rad 都要在*加载后*的质量与频率上取值**，
用未加载的 ω、m 会得到 1% 量级的偏差。
参考实现里这条恒等式是一个运行时 `assert`，不是注释，请照做。

## 三、四个必须避免的错误（我都犯过）

> 〔已改正〕本节原为三条。第二轮审查又发现第四条（3.4），
> 而且它比前三条更危险：**前三条会算错，第四条会算错却报告"全部断言通过"。**

### 3.1 Struve H1 的级数写错

正确的是

```
H1(z) = Σ_{k≥0} (−1)^k · (z/2)^(2k+2) / ( Γ(k+3/2) · Γ(k+5/2) )
```

两个 Gamma 的**宗量不同**，而且**没有 2/π 前因子**。
我此前写成 `Γ(k+1.5)²` 并多乘了 2/π：

| z | 错写法 | 正确值（级数 = scipy = A&S 表） |
|---|---|---|
| 1.0 | 0.181009 | **0.198457** |
| 3.0 | 0.548422 | **1.020110** |
| 5.0 | −0.294782 | **0.807812** |

到 z = 5 连符号都反了。由此给出的所有 fs 位移数字都是错的。

**强制要求：** 实现必须带一个测试，把求值结果同时对上
`scipy.special.struve(1, z)` 与上表的参考值。
〔已改正〕原文只要求"容差 1e-5"且只列了 z ≤ 5 三个点——**这个要求本身就不够**，见 3.4。

### 3.2 算出负的附加质量却放过了

X1(x) = 2H1(x)/x 在 x > 0 上**恒正**，因此附加质量恒正。
我当时算出血液工况 X1 为负——负的附加质量在物理上不可能——
只在心里记了一句"奇怪"，没有追下去。那正是 3.1 的症状。

**强制要求：** `assert X1(x) > 0` 作为运行时断言。
**物理上不可能的中间量出现时必须让程序停下来，不许靠人眼发现。**
〔已改正〕原文写"覆盖 0.05 ≤ x ≤ 33 的取样点"，**取样太稀且上界太低**：
x = 33 恰好是我取的最后一个样点，而级数在那里已经错到 2.3e-3；
真正炸掉的 x ≈ 49.46 落在取样范围之外。见 3.4。

### 3.3 把 Q_辐射 当成 Q_总

我在同一段里刚推导完 `1/Q = 1/Q_int + 1/Q_rad`，紧接着就直接把 Q_rad 当成 Q_total 报了出去。

| 工况 | 我原来报的 | 正确 Q_total | 峰宽 |
|---|---|---|---|
| 血液 25% 接触 | 119.8 | **111.82** | 8 029 Hz |
| 血液 全接触 | 30.0 | **31.47** | 28 318 Hz |
| 钙化 全接触 | 15.5 | **26.95** | 32 201 Hz |

加载工况下两者差别不大，因为辐射确实主导；但**空气工况差两个数量级**
（Q_rad = 124 174 对 Q_total = 794.88），而空气工况恰恰是登记表所在的位置。

**强制要求：** 第 2.5 节的倒数恒等式作为运行时 `assert`。

### 3.4〔新增〕级数数学上收敛 ≠ 双精度下可用，而自检必须覆盖**实际输入域**

这是第二轮审查（F1）发现的，是本文档此前最严重的缺陷。

3.1 修好的级数**公式是对的**（与 NIST DLMF 11.2.1 一致），但双精度直接求和
在 x 增大时被交替大项的相消摧毁：

| x | 朴素级数 | 稳定求值（= scipy = 独立自适应积分） | 相对误差 |
|---|---|---|---|
| 8 | 0.488116 | 0.488116 | 1.4e-14 |
| 20 | 0.472688 | 0.472688 | 8.1e-10 |
| **33** | 0.540200 | **0.541423** | **2.3e-3** |
| 40 | 0.070662 | 0.631223 | 0.89 |
| **49.45947617896467** | **−3934.379** | **0.638358** | **6.2e+03** |
| 49.45947617896466（相邻浮点数） | **+2555.472** | 0.638358 | 4.0e+03 |

`a = 1.5 mm` + 空气声速 343 m/s + 900 kHz 恰好给出 2ka = 49.4595，
而 `--radius-mm 1.5` 是本文档第 4.1 节明确要求扫描的取值。
原参考程序在该输入下给出 `fs′ = 900576.9 Hz`（真值 899999.9 Hz）、
产生**虚假的负附加质量与向上频移**，**却仍然打印"全部断言通过"**。

影响范围要说准：默认 0.5 mm 的主表可复现；出问题的是**大半径下的空气项**，
因此空气全接触与任何含空气权重的部分覆盖都被污染；大半径下 100% 覆盖血液/钙化
的空气权重为零，不受此错影响。

**强制要求（取代 3.1 的旧要求）：**

1. **不要用朴素级数做计算。** 用 DLMF 11.5.1 的积分表示配 Gauss–Legendre 求积：
   `H1(z) = (2z/π)∫₀^{π/2} cos²θ·sin(z·sinθ)dθ`，被积函数有界光滑、无相消。
   J1 同理用 Bessel 积分 `J1(z) = (1/π)∫₀^π cos(θ − z·sinθ)dθ`。
   节点数随 x 线性增长（实测 `n = 2⌈x⌉+64` 在 0 < x ≤ 400 上给出
   |ΔH1| ≤ 2.4e-12、|ΔJ1| ≤ 5.3e-15）。**这条路径只依赖 numpy。**
2. **自检必须覆盖整个允许的 2ka 范围**，不是几个点。参考实现用 1260 点网格。
3. **定义域守卫**：超出已验证范围、负值、NaN 一律**拒绝求值**，不外推。
4. **把朴素级数的失效写成测试**（`assert abs(naive(49.4594761789647)) > 100`），
   让这个坑不会被重新踩进来。
5. 小 x 的 `R1 = 1 − 2J1(x)/x` 有相消（x = 1e-6 时相对误差 8e-5），
   必须走等价级数 `R1(x) = Σ_{m≥1} (−1)^{m+1}/(m!(m+1)!)·(x/2)^{2m}`。

**更一般的教训：** 断言只验"符号对"或"低 x 精度"，等于没验。
自检的取样域必须由**代码实际会接受的输入域**决定，不是由写测试时想到的几个数决定。

## 六、二维格点的定义

### 6.1 两个轴

- **轴一：介质。** 必须是**具名介质加 (ρ₀, c₀) 对**，**不能**退化成单一声阻抗标量。
  理由：c₀ 单独通过 k = ω/c₀ 进入 2ka。血液与钙化的 Z 差 4.1 倍，
  但同样半径下 R1 差 3.4 倍（0.947 对 0.278），方向相反地抵消了一部分。
  只报 Z 会算错。
- **轴二：接触面积比例 η ∈ [0, 1]。** 未接触的部分仍看空气。

建议取值：介质 ∈ {air, blood, calcif}，η ∈ {0, 0.25, 0.5, 0.75, 1.0}。
15 个标签，去掉三介质共有的 η = 0 重复之后**登记 13 项**。

〔已改正〕但 **13 项 ≠ 13 个独立状态**。介质本身就是空气时，任何 η 都是同一负载，
所以 15 个标签在本公式下只对应 **9 个唯一 BVD 状态**：
空气 1 个、正覆盖比例的血液代理 4 个、正覆盖比例的钙化流体代理 4 个。
别名组为 `{(air,0), (air,.25), (air,.5), (air,.75), (air,1), (blood,0), (calcif,0)}`。

**强制要求：** 冻结 JSON 必须保留"标签 → 唯一状态"的映射，
并分别报告 `label_count` / `registered_count` / `distinct_state_count`。
**不得把重复状态当成独立覆盖证据，也不得在不说明权重的情况下把它们重复计入平均指标。**

### 6.2 标称点取"血液 全接触"

这是器件的**设计工作点**，不是空气。以它为格点原点，
相对变化才有工程含义（第 1.1 节的 −72.1% 就是这么来的）。

### 6.3 部分覆盖用线性叠加，并且必须声明这是近似

```
Z_rad(η) = η·Z_rad(medium) + (1−η)·Z_rad(air)
```

**严格的活塞辐射函数假定整个端面均匀加载，部分覆盖不满足这个前提。**
真实的部分浸没会改变模态形状与辐射方向性。这是一个声明的一阶近似，
必须写在 JSON 的注释字段与文档里，不许悄悄用。

### 6.4〔新增〕辐射阻抗的求值频率：冻结近似，且已量化其误差

参考实现在**未加载的 fs = 900 kHz** 处计算 R_rad 与 m_rad，再当成常数去更新 Rm′、Lm′。
它**没有**在每个扫频点重算 Z_rad(f)，也**没有**在加载后的谐振频率处迭代求解。

这在参考频率附近是合理的常参数近似，但必须登记
`radiation_evaluation_frequency_Hz` 与 `radiation_frequency_mode`，
**不能称为整个频带内精确的辐射负载模型**。

第二轮审查（F5）指出"对最宽峰或最大频移工况，冻结近似可能产生不可忽略的误差，
但尚未量化"。**本轮已量化**（参考实现 `self_consistent=True` 迭代到 Z_rad 的求值频率
与加载后 fs′ 一致，a = 0.5 mm）：

| 工况 | 冻结 fs (Hz) | 自洽 fs (Hz) | Δfs (Hz) | 冻结 Qm | 自洽 Qm | ΔQm |
|---|---|---|---|---|---|---|
| 空气 全接触 | 899 999.6 | 899 999.6 | −0.0 | 794.88 | 794.88 | −0.00% |
| 血液 25% 接触 | 897 782.4 | 897 771.6 | −10.8 | 111.82 | 111.80 | −0.01% |
| 血液 50% 接触 | 895 581.4 | 895 538.6 | −42.8 | 60.27 | 60.26 | −0.02% |
| 血液 全接触 | 891 227.6 | 891 058.2 | −169.4 | 31.47 | 31.46 | −0.03% |
| 钙化 50% 接触 | 883 476.6 | 883 377.2 | −99.3 | 51.27 | 52.00 | **+1.41%** |
| 钙化 全接触 | 867 831.4 | 867 465.4 | **−366.0** | 26.95 | 27.74 | **+2.94%** |

结论：**血液侧冻结近似可以接受（ΔQm ≤ 0.03%）；钙化侧不可忽略**
（ΔQm 到 +2.94%，Δfs 到 −366 Hz），恰好落在 F5 预测的"最大频移工况"上。
**强制要求：** 冻结格点必须同时导出两种模式的结果，或至少导出冻结模式并附这张对照表；
钙化相关结论不得只引用冻结值。

## 八、加载后可交付功率的硬上界（**本节结论已被推翻并重写**）

> 〔已改正 — 这是本轮最重要的一处更正〕
> 本节原标题是「必须先处理：加载后匹配网络严重失配」，原文把功率下降 15 倍归因为
> 匹配失配，并让实现方在"保持现网络"与"重新设计匹配"之间选。**这个因果判断是错的。**
> 加载后的功率下降是端口电压边界下的解析硬上界，**与匹配元件如何选择无关**，
> 重新匹配不能把它拿回来。下面是重写后的正确版本。

这是本文最重要的一条工程结论。用冻结模型实算（100 Hz 网格、软限 130 Vpp / 5.5 mA）：

| 工况 | 峰频 | 峰值 P_Rm | 所需源幅度 | 峰处 Vpp | 峰处 mA_rms | 限幅来源 |
|---|---|---|---|---|---|---|
| 未加载基线 | 900 000 Hz | **0.17000 W** | 1.000 | 100.00 | 5.000 | 源幅度饱和 |
| 空气 全接触 | 900 000 Hz | 0.16993 W | 1.000 | 100.30 | 4.985 | 源幅度饱和 |
| 血液 25% 接触 | 897 800 Hz | 0.04006 W | 0.778 | 130.00 | 1.977 | **电压软限** |
| 血液 全接触 | 891 200 Hz | **0.01119 W** | 0.735 | 130.00 | 1.782 | **电压软限** |
| 钙化 全接触 | 867 800 Hz | 0.00933 W | 0.896 | 130.00 | 1.731 | **电压软限** |

三件事同时发生：

1. **可交付功率掉了约 15 倍**（0.170 → 0.0112 W）。
2. **限幅来源翻转**：未加载时是"源幅度已经到 1"，加载后变成电压软限；
   **电流软限 5.5 mA 完全不再起作用**（只到 1.78 mA）。
3. 峰频下移最多 −3.6%（867.8 kHz），仍在 0.8–1.0 MHz 带内。

### 8.1 根因不是失配，是端口电压下的解析上界

机械支路两端为 V_port 时，其有功功率满足

```
P = V_rms²·R′ₘ/(R′ₘ² + Xₘ²)  ≤  V_rms²/R′ₘ  =  V_pp²/(8·R′ₘ)
```

等号在串联谐振（Xₘ = 0）处取到。**这个上界与前级匹配电感、电容如何选择无关**，
它只取决于端口电压上限与 R′ₘ。实算对照：

| 工况 | R′ₘ (Ω) | 现网络实得 | 130 Vpp 解析上界 | 达上界比例 | 要 170 mW 所需 Vpp |
|---|---|---|---|---|---|
| 未加载基线 | 7 352.9 | 0.17000 W | 0.28730 W | 59.17% | 100.00 |
| 空气 全接触 | 7 400.3 | 0.16993 W | 0.28546 W | 59.53% | 100.32 |
| 血液 25% 接触 | 52 737.3 | 0.04006 W | 0.04006 W | **100.00%** | 267.81 |
| 血液 全接触 | 188 748.1 | 0.01119 W | 0.01119 W | **100.00%** | **506.65** |
| 钙化 全接触 | 226 353.4 | 0.00933 W | 0.00933 W | **100.00%** | 554.83 |

**加载工况下现网络已经达到解析上界的 99.9996%——没有失配可修。**
（真正离上界远的反而是未加载基线，59.17%，因为那里的约束是"源幅度已到 1"，不是电压。）
要在血液全接触的 R′ₘ 下交付 170 mW，即使正好串联谐振也需要约 **506.65 Vpp**，
远超项目 160 Vpp 硬限。**这是说明不可行性，不是建议提高限值。**

### 8.2 因此实施顺序改为

1. 先把负载层建起来，把上表复算出来（这一步就是交付物之一）；
2. **在跑任何控制验证之前**，把"限幅来源"与"达解析上界比例"作为两列写进每段指标。
   没有这两列，读者无法判断捕获率低是控制没跟上，还是物理上就交付不了；
3. 正确的表述是：**"加载导致等效电阻显著增大，在现有端口电压边界下可交付功率上限下降；
   网络失配可能同时存在，但不能把这 15 倍下降都归因于可用重新匹配消除的失配。"**

**此处为模糊推测内容：** 重新设计匹配**可能**改善源侧效率、所需源幅度或带宽，
但这些改善幅度**本轮完全没有验证**，且它不可能突破 8.1 节的功率上界。
是否重新匹配是需要人来拍板的设计选择（它会改动 `stage2_匹配设计参数.json`，
进而改变全部历史对照基准），**不要由实现自行决定**。

## 九、对控制验证的影响：变容易了，不是变难了

〔已改正〕本节原来直接用 `fs/Qm` 当"峰宽"去论证扫描难度。
**`fs/Qm` 是孤立机械支路在常端口电压下的半功率全宽，不是系统功率 FWHM。**
实际平台的端口电压受源、匹配、频率和保护降幅共同影响。用冻结源、冻结匹配、
10 Hz 诊断网格实算（该诊断区间只用于找半高交点，**未改控制器 0.8–1.0 MHz 搜索边界**）：

| 工况 | fs/Qm (Hz) | 未保护系统功率 FWHM (Hz) | 逐点软限后安全功率 FWHM (Hz) |
|---|---|---|---|
| 未加载基线 | 1 125.0 | **2 141.9** | **1 735.6** |
| 空气 全接触 | 1 132.2 | 2 149.2 | 1 739.3 |
| 血液 25% 接触 | 8 029.1 | 9 026.6 | 8 029.1 |
| 血液 全接触 | 28 318.2 | 27 456.7 | 28 318.2 |
| 钙化 全接触 | 32 200.6 | 34 856.0 | 30 990.4 |

**基线处两者差 90%**（1125 vs 2141.9）。加载工况数值接近**不等于定义相同**。

| 来源 | 系统功率 FWHM | 相对粗扫步长 5 kHz |
|---|---|---|
| 登记表 Qm 族（fs/Qm 900–1800，系统值需另算） | 约 1 700 – 2 100 Hz | **0.34 – 0.43 倍（比一个粗格还窄）** |
| 负载格点（a = 0.5 mm） | 8 029 – 34 856 Hz | 1.6 – 7.0 倍 |

一级扫描半窗是 ±50 kHz，负载引起的 fs 位移最大 −3.6%（−32 kHz），**在窗内**。

所以：

- **负载格点对三级扫描看起来是容易的**，它不构成新的搜索压力；
- **真正窄的是登记表里那些比一个粗格还窄的峰**，
  它们对应"声负载可忽略"的一端。

**但不能据此宣布"5 kHz 粗扫已经充分"或"控制更容易通过"**——
那是一个需要同口径控制试验才能下的结论，不是从带宽数字推出来的。〔F4〕

**强制要求：不许因为"空气工况不现实"就把窄峰场景删掉。**
它们是当前唯一能压住三级扫描分辨率的用例，删掉之后验证会变弱而不是变强。
正确做法是把它们**重新标注**为"脱离接触 / 空气加载"这一物理工况，
放进负载格点的 η = 0 一端，而不是当成一个来路不明的 Qm 百分比。

**此处为模糊推测内容：** 低 Q 加载工况下峰变得又宽又浅，
匹配网络自身的频率依赖会与换能器峰变得可比。
`review/04` 里记录过 `arg(Zin)` 在中等以上扰动下会锁到匹配网络零点
（基线下该零点在 903 950 Hz）。加载之后这个问题是缓解还是加重，
**必须实测，不许假设**。这是负载层建好之后第一个该跑的诊断。

## 十、验收自检清单

实现完成后，下列每一条都必须通过。括号里是参考实现算出的值。

### 10.1 数学层〔已改正：原 5 条取样太稀、上界太低，是 F1 能逃过自检的直接原因〕

1. H1 求值在**整个允许的 2ka 域**上对上 `scipy.special.struve(1,z)`，
   网格不少于 1000 点，绝对容差 1e-10。参考实现在 (0, 400] 的 1260 点网格上
   实测 max|ΔH1| = 2.25e-12、max|ΔJ1| = 5.5e-15。
2. H1 对上定点参考值：H1(1) = 0.198457、H1(3) = 1.020110、H1(5) = 0.807812、
   **H1(33) = 0.541423、H1(49.45947617896467) = 0.638358**，容差 1e-5。
   后两个点是 F1 的复现点，必须在清单里。
3. 至少三个点再对上**独立的自适应积分**（DLMF 11.5.1），容差 1e-9，
   以免 scipy 与被测实现同源。
4. X1(x) > 0 在**同一张全域网格**上成立（不是十来个手挑的点）。
5. R1(x) → 1（x → ∞）：R1(400) = 1.000046。
6. R1(x) ≈ x²/8（x → 0）：**R1(1e-6) = 1.25e-13**，必须走小 x 级数；
   直接算 `1 − 2J1(x)/x` 在此处相对误差 8e-5。
7. 定义域守卫：负值、NaN、超出已验证上界一律**抛异常**，不外推。
8. 朴素级数的失效被测试固定：`abs(naive_series(49.45947617896467)) > 100`。

### 10.2 折算层

6. `ω·Lm/Rm == Qm` 对未加载基线成立（800.000）。
7. 倒数分解 `1/Q_total = 1/Q_int' + 1/Q_rad` 与直接算的 Qm′ **逐位相符**（相对 1e-9）。
8. 空气全接触几乎恢复未加载值：Rm 7400.3 Ω（+0.6%）、fs 899 999.6 Hz（−0.00%）、Qm 794.88。
9. 加载只会让 Rm 增加、fs 下降、Qm 下降（相对**未加载**基线），对全部格点成立。
10. `Q_total ≤ Q_intrinsic` 对**本登记格点**成立。
    〔已改正〕原文把它当成无条件物理定律，不对：由
    `Q′/Q_i = √(1+m_r)/(1+Q_i·r_r)` 可见，当 `Q_i·r_r < √(1+m_r) − 1` 时 `Q′ > Q_i`。
    它只是本格点上的**回归事实**，应当作为回归断言而不是物理断言写进测试。
11. 冻结频率近似与自洽迭代的差值被导出（6.4 节的表）。

## 十二、局限与模糊推测清单

以下是本方案**已知站不住或未经验证**的地方，必须随交付物一起写明。

1. **无限障板圆活塞是一个理想化。** 真实的 CTO 导管头端没有无限障板，
   近场、导管本身的散射、非活塞式的模态形状都不满足前提。
   这是一阶模型，不是声场求解。

2. **把钙化斑块当成流体半空间是更强的理想化。** 固体接触会同时引入**刚度**，
   而本模型假定刚度不变（2.2 节）。**此处为模糊推测内容：**
   我预计刚度耦合会把 fs 往**上**推，与质量负载的方向相反，量级不明。

3. **钙化的 (ρ₀, c₀) 文献离散度很大。** 本文用 1900 kg/m³、3600 m/s（6.840 MRayl）。
   不同来源给出的钙化声阻抗从约 2.5 到 7.8 MRayl 都有。
   **此处为模糊推测内容：** 取值变化会显著改变第 10.3 节的钙化两行，
   但不改变"加载端 Q 在几十量级"这个结论。交付时请给出至少两组取值的对照。

4. **部分覆盖的线性叠加没有依据。**（6.3 节）

5. **m = ρAL/2 的因子 1/2 是声明的模态近似。**（2.4 节）

6. **血液的声衰减完全没有建模。** 本模型把介质当成无损耗半空间，
   只取 (ρ₀, c₀)。真实血液在 0.9 MHz 有可测的衰减。
   **此处为模糊推测内容：** 我预计衰减主要影响远场声强而不是负载阻抗的实部，
   因此对本层的 Rm、fs 影响较小，但没有验证。

7. **未加载基线的 Qm = 800 本身就是假设值**，不是实测。
   整个负载层建立在它之上，所以所有绝对数字都继承了这个假设。
   相对变化（第 1.1 节的 −72.1% 之类）比绝对值更可信。

8. 〔已改正〕原第 8 条写"第八节的失配结论依赖现有匹配网络参数"。
   第八节现已重写：那里的核心结论是**与匹配无关的解析功率上界**，
   只依赖端口电压边界与 Rm′，不依赖匹配元件取值。
   依赖匹配参数的是"现网络实得功率"那一列，它恰好落在上界上。

9. **冻结辐射频率是常参数近似。** 钙化工况下它给出 ΔQm 达 +2.94%（6.4 节）。
   **此处为模糊推测内容：** 完整频变辐射模型（在每个扫频点重算 Z_rad(f)）
   与本近似在控制闭环中的差别，本轮完全没有评估。

10. **"相对变化一定比绝对变化可信"以及"新负载层一定能解决原扫频失败"**
    都**没有本轮证据**，属于**此处为模糊推测内容**。

11. 本文**未运行 LTspice、未做硬件实验、未做 COMSOL 或声场验证**，
    也未证明真实电路瞬态全过程不越限。给定声速与密度**不等于**已建立声压场。

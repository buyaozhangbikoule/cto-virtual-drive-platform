### F1 复验

`local_scan` 返回 `converged`，调用处写成 `frequency, t, completed = local_scan(...)` 之后
`completed` 从未被读取。第四消融项更严重：拿到失败结果后照样在该频率重记相位目标、替换参考曲线。

我按报告描述构造了同样的跨扰动扫描，独立复现：

| 项目 | 我的复算 | 报告值 |
|---|---|---|
| 返回频率 | 894.0000 kHz | 0.8940 MHz |
| `scan_converged` | false | false |
| 对新场景的捕获率 | 0.0402% | 约 0.0402% |

数字逐位一致。

### F3 复验，比报告更严重

`motional_phase_deg` 从 `scenario.matching` 和 `scenario.bvd.c0` 取值，而 `scenario` 是**扰动后的**
被控对象。所以控制器不仅拿到电压电流，还被告知了真实的扰动后 C0 与匹配元件。
我原先写的「never reads Rm, Lm or Cm」字面为真但具有误导性：关键不是读了哪个 BVD 元件，
而是控制器是否知道扰动后的被控对象，这里它知道。

把标定冻结在基线设计值后，复验误差与报告完全一致：

| 场景 | 固定标定去嵌相位误差 |
|---|---|
| 基准 | 0.000° |
| fs−5% | 0.000° |
| C0+30% | −4.890° |
| Lmatch+10% | −68.033° |
| 电感 Q=20 | +3.835° |
| 高组合 | +13.469° |

**报告没有说、但我复验发现的一条更要紧：固定标定下去嵌相位不再单调。**

| 场景 | 负斜率样本数 |
|---|---|
| Lmatch+10% | 816 / 1000 |
| Cmatch−10% | 383 / 1000 |
| C0+30% | 484 / 1000 |

单调性、唯一零点、因而「不可能锁到错误点」，是我整套相位论证的基础。
**这个基础只在标定精确时成立。** `review/05`、`review/06`、`review/08` 里的相关表述必须按此收窄，
已在代码注释中改正，文档修订见第四节。

### F4 复验

代码注释称「被控对象不变时残差处处为零」。复验：基线负载完全不变，
在 895 至 905 kHz 上取 1000 个频点，**60 个点的插值残差超过 10% 触发阈值**。
报告给的反例 898430 Hz、残差 11.059% 逐位复现。注释为假，已改正。

### F5 复验

三个用例全部复现：`1.0→nan`、`0.0→inf`、`inf→-inf` 均返回 `NUMERICALLY_IDENTICAL` 且 `worst_rel=0`。
根因是 `abs(x−y)` 对非有限数产生 NaN，而 `NaN > worst_rel` 恒为假，最大误差不被更新。

**这个缺陷动摇的是我所有验证声明所依赖的工具。** 已修并加回归用例。
用修好的比较器重验全部结果，结论未变，仍为 IDENTICAL。审核方也用独立的有限值感知逻辑
复算过 7 份 CSV 全部通过，两边一致。

### F8 复验，我此前的判断是错的

我在 `review/09` 里写「本轮规模下无害」。这是错的。复验确认有 6 条固定频率控制记录
因浮点累加被分到前一段，例如 6.3999999999999515 s 被归入第 7 段而理论 6.4 s 应属第 8 段。
**每条记录承载 20 ms**，若用于采样保持、触发延迟或连续合格样本计数，影响是一个完整控制样本，
不是 5e−14 秒。

## 二、本轮已修的内容

### 2.1 F5 比较器（P1）

非有限值在进入相对误差之前先筛。两侧同为 NaN 或同号无穷判为未变化；
其余任何涉及非有限值的变化一律判 CHANGED 并记录。已加三个回归用例。

### 2.2 F1 失败扫描不被接纳（P1）

平台补丁侧：`PERIODIC_SCAN` 与 `P_AND_O` 都改为分支于 `completed`。
失败时不按成功记账，改为有上限的快速重试，`FAILED_SCAN_RETRY_S = 0.05`、
`MAX_FAILED_SCAN_RETRIES = 2`。

第四消融项侧：失败时**不重记相位目标、不替换参考曲线**，只安排有界重试。
这是报告点出的关键升级，我原先没有考虑到失败扫描会同时污染保持环节和检测器。

**新增强制失败测试** `review/test_failed_scan_handling.py`，覆盖报告要求的四类：
扫描中途扰动、重定位预算耗尽、峰在频带边界、无有效测量。

写这个测试时抓到我自己刚引入的一个缺陷：`failed_scans` 未初始化。
因为本日程上没有任何扫描失败，该路径从不执行，跑起来一切正常。
**没有被执行过的代码等于没有被检查过**，这正是报告要求强制测试的理由。已修。

验收：修正后三策略输出仍为 IDENTICAL，第四消融项除新增 `failed_scans` 列外数字全不变，
该列全为 0，确认失败路径在本日程上不可达，只能由强制测试进入。

### 2.3 两处被证伪的代码断言

去嵌函数与模块文档的「只用可观测量、never reads Rm/Lm/Cm」，以及扫描曲线参考的
「残差处处为零」，都已在代码注释中改为事实描述并标注对应的审核编号。

## 三、未修的五条，及我的建议

### 3.1 F2 幅度状态未同步（P1）

复验确认：扫描期间实际施加 0.40，保护器仍记 1.00，扫描后第一个控制样本直接给 1.00，
没有按 `RAMP_STEP = 0.05` 渐升。实际动作序列是 0.40 → 1.00 的跳变。
另确认 `limit_probe` 在 HARD_TRIP 状态下仍返回 0.40，目前只靠外层 `tracking_allowed` 门控。

我接受报告的三职责拆分建议：不可被扫描清除的停机锁存、每条指令必经的限幅接口、
所有实际动作共同更新的 `applied_amplitude`。

**未修的理由**：这会改变三策略的恢复轨迹，因而改变历史结果，必须按 `review/07` 的方式
单独分步验收，不能在答复外部审核的同一轮里顺手带上。建议作为下一轮第一项。

### 3.2 F3 真值隔离（P1）

需要引入 `PlantTruth` 与 `CalibrationEstimate` 的接口隔离，登记标定来源，
单独测试 C0 与匹配 L/C/Q 的估计误差和噪声。这是架构改动，不是补丁。

在此之前，**第四消融项的全部结论只能表述为理想可观测性研究**，
不能用于支持「仅靠电学测量即可适应未知漂移」。报告给出的固定标定重跑结果
（`HOLD_SCANREF_SLEW` 约 1.91%、无 slew 对照约 1.57%）说明候选仍值得研究，
这一点我同意，不应因此全盘否定。

### 3.3 F6 统一事件日志（P2）

复验确认：`HOLD_SCANREF_SLEW` 导出 435 条记录全为 `CONTROL`，
持续时间合计 8.70 s 对名义 9.60 s，另报扫描耗时 0.9015 s，时间线中扫描行为 0。
`actual_hard_violations` 只遍历导出行，`status=PASS` 只依赖这些行。

**所以该 PASS 不能解释为扫描全过程已审计或动态硬保护已通过。** 这条我完全接受。
建议按报告做统一事件日志，并在图上保留扫描间隙。

### 3.4 F7 斜率查询未计入时序（P2）

属实。每个控制周期直接用模型算 `f±100 Hz` 的相位差，没有为这两次查询安排执行、驻留、

建议按报告改为标明「模型辅助斜率估计」，或把两次试探纳入实际控制时序。

### 3.5 F8 整数时间刻度（P2）

建议改为整数时间刻度或事件调度。修正后必须重新统计，不能用旧表证明新调度等价。

## 四、对我送审说明的更正

1. **「6 个提交、全部新增」不准确。** 实际领先 main 7 个提交，且 README 被修改。
   送审说明写于第 6 个提交，之后又提交了一次，我没有回头更新。属实，已更正。
2. **「逐字节一致」用得过宽。** 我的比对是同一台机器、同一 numpy 版本下复现自己的结果，
   那确实逐字节一致；跨 numpy 版本只能说数值一致。审核方在 numpy 2.2.4 上复算，
   得到末位差异是正常的。今后区分表述为「同版本逐字节一致、跨版本数值一致」。
3. **「无噪声上界」改为「理想无噪声模型结果」。** 未经理论证明不应称严格上界，接受。
4. **「真实器件不成立」改为「是否适用取决于经过验证的线性幅度范围」。** 接受。
5. **`review/04` 对 Qm=800 的物理判断应收窄。** 我写的「Qm=800 对应空载或声辐射可忽略」
   证据不足。PI Ceramic 材料表确实列有机械 Q 达 1000 与 2000 的硬 PZT。
   准确表述应为：**当前是高 Q、弱有效耦合的假设模型，其对具体 0.9 MHz 换能器的代表性尚未验证。**
   同样，把 BVD 有效耦合指标直接与 PZT 材料耦合系数比较，依据不足。
6. **「耦合系数改成真实值会产生多峰」是推测而非结论。** 增大单支路模型的耦合参数
   不会自动建立真实结构的额外机械模态。此前已标注为模糊推测，措辞再收紧。
7. **报告补充的一条我没做过的检查值得记入**：基准下源侧电流约 58.27 mA RMS，
   换能器端口才约 5.00 mA RMS。**5 mA 不能用作功放或匹配电感的器件选型电流。**

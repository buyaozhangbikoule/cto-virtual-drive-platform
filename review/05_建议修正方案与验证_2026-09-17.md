## 一、扫描：加窗口边缘检测与重定心

### 问题复述

现 `local_scan` 三级取最大值，不检查最大值是否落在窗口端点。真峰跌出粗扫窗口后，
每一级都钉在各自左边缘，最终恒定返回 844.0 kHz，且无任何失败标志。
有效搜索下界 = 900 − 50 − 5 − 1 = 844 kHz。

### 修法

粗扫最大值落在窗口端点且该端点不是频带边界时，以该端点为新中心重扫一轮，最多 3 轮；
同时输出 `converged` 标志，供控制器判断本次捕获是否可信。精扫、超精扫同样上报端点命中。

判定要区分两种端点：**窗口边界**说明还没搜到头，要继续；**频带边界** 0.8 或 1.0 MHz
说明已经搜到头，不算失败。原型里用 `at_band_limit` 区分。

### 验证结果

34 个登记场景，逐一对比：

| 场景 | 真峰 | 现方案 | 现捕获 | 新方案 | 新捕获 | 点数 |
|---|---|---|---|---|---|---|
| CASE_LM_P20 | 821.4 kHz | 844.0 kHz | 0.10% | 821.4 kHz | 100% | 74 |
| CASE_CM_P20 | 821.4 kHz | 844.0 kHz | 0.14% | 821.4 kHz | 100% | 74 |
| 其余 32 个 | — | 不变 | 100% | 不变 | 100% | 53 |

**无一场景变差。** 代价只在需要重定心时发生：74 点对 53 点，111.0 ms 对 79.5 ms，多 31.5 ms。

搜索半径从 56 kHz 扩展到全频带：

| fs 漂移 | 真峰 | 现捕获 | 新捕获 | 点数 | 耗时 | converged |
|---|---|---|---|---|---|---|
| −5.0% | 854.8 kHz | 100% | 100% | 53 | 79.5 ms | True |
| −6.5% | 841.3 kHz | 6.39% | 100% | 74 | 111.0 ms | True |
| −7.0% | 836.8 kHz | 1.00% | 100% | 74 | 111.0 ms | True |
| −8.0% | 827.8 kHz | 0.22% | 100% | 74 | 111.0 ms | True |
| −10.0% | 809.8 kHz | 0.06% | 100% | 74 | 111.0 ms | True |
| −12.0% | 800.0 kHz | 5.76% | 100% | 59 | 88.5 ms | True |

一轮重定心即可覆盖全带：起点 0.9 MHz，粗扫 ±50 kHz 到 850 kHz，重定心到 850 kHz 后再 ±50 kHz
到 800 kHz，正好触及频带下界。所以 `MAX_RECENTRES = 3` 有充足裕量。

### 仍然成立的限定

这个修法解决的是「窗口不够宽」和「失效不可见」，**不解决「栅格不够密」**。
粗扫步长 5 kHz 对 1133–2778 Hz 的峰宽仍然偏粗，之所以还能用，是因为本模型的安全功率曲线单峰单调，
离真峰最近的栅格点必然是粗扫最大值。这个单峰性质本身是弱耦合带来的（见审查 P2 条），
一旦耦合系数取真实值或器件出现多模态，粗扫步长必须重新论证。

**结论：修完之后仍应称之为「带边界自检的局部搜索」，不能称为全局搜索。**

## 二、相位：改用去嵌后的机械支路相位，并改变其定位

### 去嵌是可行的，而且是精确的

驱动器在功放端能测到的是输入电压和源电流。匹配电感、其 ESR、匹配电容、其 ESR 和 C0 都是已知设计值，
所以机械支路可以解析剥离：

```
z_in       = v_input / i_source
z_parallel = z_in - r_L - jwL
v_port     = i_source * z_parallel
i_port     = i_source - v_port / z_cmatch
i_motional = i_port - jw*C0*v_port
arg(Zm)    = arg(v_port / i_motional)
```

原型验证：全 34 场景下，由上式还原的 arg(Zm) 与模型内部真值的偏差在 **10⁻¹⁵ 到 10⁻¹² 度**量级，
即浮点精度。整个推导不读取 Rm、Lm、Cm。

### 为什么机械支路相位是更好的误差信号

`arg(Zm) = atan((wLm − 1/(wCm)) / Rm)`，对频率**严格单调递增**。原型确认：34 个场景全部单调，
全部**恰好一个零点**。单调且唯一零点的误差信号不可能锁到错误点。

`arg(Zin)` 则不然。零点个数分布：

| arg(Zin) 零点个数 | 场景数 |
|---|---|
| 3 个 | 20 |
| 1 个 | 14 |

| arg(Zm) 零点个数 | 场景数 |
|---|---|
| 1 个 | 34 |

而且零点个数**完全预测**相位策略成败：「arg(Zin) 有 3 个零点」与「arg(Zin) 跟踪达到 95% 捕获」
在 **34 / 34** 个场景上一致。

机制是清楚的。换能器谐振靠近网络设计点时，arg(Zin) 在带内有三个过零：换能器自身串并联结构贡献两个，
匹配网络贡献一个。换能器谐振跑开后，它自己那两个离开频带，只剩网络那一个，
即 `f = 1/(2π√(L(C0+C_match))) = 903.95 kHz`，控制器就锁到它。

### 由此得到一个免费的在线自检

**在捕获扫描的同时统计 arg(Zin) 在带内的过零个数。只剩一个，就不要把频率交给相位控制器。**
这个判据不需要额外测点，扫描已经逐点测过电压电流了。

### 建议的分工

| 环节 | 用什么 | 理由 |
|---|---|---|
| 捕获 | 带边界自检的功率扫描 | 唯一能找到真正的受约束最大功率点 |
| 保持 | 机械支路相位，目标取捕获时记录的值 | 单调且唯一零点，非零目标也唯一可达 |
| 重捕获 | 现有可观测 2/4 检测器，或 converged 为假 | 已实现，且不偷看真值 |

注意「目标取捕获时记录的值」这一步是必要的：`arg(Zm) = 0` 对应的是 fs，
而 fs 与受约束最大功率点在匹配网络失谐时并不重合。审查里 arg(Zm) 零点的捕获率只有 26/34 就是这个原因，
最差的 CASE_LMATCH_P10 只有 81.6%。改成跟踪「捕获时刻记录的 arg(Zm) 值」即可消除这个偏差，
而单调性保证了这个非零目标是唯一可达的。现 `run_phase_ablation.py` 对 arg(Zin) 已经是这么做的，
把信号换掉即可，控制律不用改。

### 对计划书的影响

计划书把「基于相位误差的离散频率跟踪」列为第三个正式策略，与固定、周期扫频并列比较。
按上面的结论，这个并列在本拓扑下没有意义：相位不是一个能独立完成捕获的策略。
建议改成「固定 / 周期扫频 / 扫频捕获＋相位保持」三者比较，把纯相位作为消融项保留，
并把 `wrong_phase_lock_flag` 提升为一等评价指标。

## 三、扫描点接入保护链

现 `local_scan` 把 0.40 探测幅度直接传给测量函数，绕过 `Protection.apply()`。

原型量化了这件事的现状：在全 34 场景、全频带、100 Hz 栅格共 68034 个采样点上，
软限限幅器**一次也不会削减** 0.40 的探测幅度；最坏的「探测幅度 / 允许幅度」比值是 0.6099。

所以这项改动在今天的登记表上是 no-op。**仍然建议做**，理由有三：

1. 它把一个余量变成一个强制不变量。探测幅度一旦上调，或场景扩展到更强失配，现结构会静默越限。
2. 计划书第 3 周原文要求「所有扫描／试探样本逐点进入同一保护链」。
3. 改动量极小，且因为是 no-op，改完后历史结果应当逐位不变，这本身就是一次可用的回归验证。

## 四、落地顺序与验收建议

1. `handoff.py prepare --name working_fix01` 建工作副本，不动 `workspace/`。
2. 先做第三项（扫描点接保护链）。因为预期是 no-op，跑完应当与历史结果逐位一致；
   如果不一致，说明对现结构的理解有误，先查清楚再往下走。
3. 再做第一项（扫描边界自检）。验收标准：34 场景捕获率不低于现值，
   LM_P20 与 CM_P20 从 0.1% 升到 95% 以上，`converged` 标志在人为构造的出界场景上为假。
4. 把 LM_P20、CM_P20 加进 stage 4/5 闭环日程，重跑三策略。
   注意这会使 FIXED_0P9 的表现进一步变差，属于预期，不是回归。
5. 最后做第二项（相位信号替换）。这一项改变策略定义，需要先与导师确认计划书三策略的措辞是否可调整。
6. 全程按 `docs/02` 的要求新建会话、保存新版本号与哈希，不覆盖历史证据。

## 五、本文没有解决的问题

以下审查条目本文不涉及，它们需要决策或补做实验，不是代码修改：

- 幅度上界 a ≤ 1 是否放开（审查 B3）。这是口径决策，不是 bug。
- 全链路无噪声、无量化、无延迟（审查 B5）。所有捕获率仍是无噪声上界。
- Qm 族不是负载扫描（审查 B6）。需要重新设计扰动族，使 Rm 与 Qm 同步变化。
- 脉冲与连续波的选择（审查 P5）。这是最上游的前提，上述所有修法都假定连续波准稳态成立。
- Qm=800 与 k_eff=0.066 的物理合理性（审查 P1、P2）。
  **若将来把耦合系数改成真实值，第一节的扫描结论必须重新验证**，因为多峰会破坏粗扫所依赖的单峰单调性质。

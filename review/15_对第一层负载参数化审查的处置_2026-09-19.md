## 三、代码改进

`review/radiation_load_layer1_reference.py` 重写。

### 3.1 特殊函数改为全域稳定求值（F1）

朴素交替级数**不再用于计算**，改为 DLMF 11.5.1 / Bessel 积分表示 + Gauss–Legendre 求积：

```
H1(z) = (2z/π) ∫₀^{π/2} cos²θ · sin(z·sinθ) dθ
J1(z) = (1/π)  ∫₀^{π}   cos(θ − z·sinθ) dθ
```

被积函数有界光滑、无相消。节点数随 x 线性增长：`n = 2⌈x⌉ + 64`。
**只依赖 numpy**（`numpy.polynomial.legendre.leggauss`）。

实测精度（对照 scipy，(0, 400] 的 1260 点网格）：

| 函数 | 最大绝对误差 |
|---|---|
| H1 | **2.25e-12** |
| J1 | **5.51e-15** |

另外三点再对上**独立的自适应积分**（`scipy.integrate.quad`，epsabs=1e-13），
以免 scipy 与被测实现同源：x = 33 / 49.4594761789647 / 400 全部一致到 1e-12。

小 x 的 `R1 = 1 − 2J1(x)/x` 有相消（x = 1e-6 时相对误差 8e-5），
改走等价级数 `R1(x) = Σ_{m≥1} (−1)^{m+1}/(m!(m+1)!)·(x/2)^{2m}`。

### 3.2 自检改为覆盖实际输入域（F1 的根因）

原自检的问题不是少写了几个点，而是**取样域由写测试时想到的数字决定，
而不是由代码实际接受的输入域决定**。现在：

- H1 定点校验扩到 **H1(33) 与 H1(49.45947617896467)**，即 F1 的两个复现点；
- `X1(x) > 0` 在 (0, 400] 的 **1260 点网格**上验，不是十来个手挑的点；
- `--cross-check` 在同一张网格上对照 scipy，绝对容差 1e-10；
- **定义域守卫**：负值、NaN、超出 `MAX_VALIDATED_2KA = 400` 一律抛 `ValueError`，**不外推**；
- **把朴素级数的失效写成测试**：`assert abs(naive_series(49.45947617896467)) > 100`，
  并保留该函数作为带注释的反例，让这个坑不会被重新踩进来。

### 3.3 输入校验从 assert 改为正式校验（F8）

`radius_m`、`rho_pzt`、`c_d`、`qm_intrinsic`、`contact`、`bvd.*` 全部走
`_positive_finite()` / 区间检查，抛 `ValueError`。
构造时还检查 `ω·Lm/Rm == Qm` 自洽，并用**声速最低的介质**预先检查 2ka 是否落在已验证域内。

### 3.4 字段拆分与改名（F4 / F5 / F7）

`LoadPoint` 现在导出：

| 字段 | 含义 |
|---|---|
| `rm` / `rm_internal` / `rm_radiation` | 总 / 内部阻尼 / 辐射阻，三者分开（F7） |
| `radiation_evaluation_frequency_Hz` | Z_rad 实际求值所用频率（F5） |
| `radiation_frequency_mode` | `frozen_at_unloaded_fs` 或 `self_consistent`（F5） |
| `motional_constant_voltage_fwhm_Hz` | 原 `width_Hz` 改名；**不是**系统功率 FWHM（F4） |

系统 FWHM 由新增的 `report_electrical()` 从实际 `P(f)` 与 `safe_power(f)` 提取，
字段独立，半高交点找不到时返回 `None`，**不外推**。

### 3.5 新增自洽辐射频率求解（F5）

`load(..., self_consistent=True)` 迭代到 Z_rad 的求值频率与加载后 fs′ 一致，
输出与冻结模式并列，直接给出该近似的误差（见 F5 表）。

### 3.6 新增电学与登记节，使可追溯性陈述成立（F8）

- `report_electrical()`：在本脚本内调用 `model.response()` / `allowed_amplitude()` /
  `safe_power()`，算出功率表、**解析上界与达上界比例**、限幅来源、
  支路带宽 vs 系统带宽对照、内部/辐射功率拆分。运行时断言 `实得 ≤ 解析上界`。
- `report_registry()`：输出标签数 / 登记数 / **唯一状态数**与别名组（F6）。

### 3.7 scipy 退出运行路径（F8）

模块顶层只 `import numpy`。scipy 与 scipy.integrate 只在
`verify_special_functions(cross_check=True)` 的**函数体内** import。
不带 `--cross-check` 时整个脚本不 import scipy。

## 六、模糊推测清单

1. **此处为模糊推测内容**：`MAX_VALIDATED_2KA = 400` 是我按"半径 ≤ 5 mm、空气、1 MHz"
   估的覆盖上界（该组合给 2ka ≈ 183），留了约两倍裕量。它**不是**从任何物理约束推出来的，
   要扩大范围必须先扩展验证网格再改这个常数。

2. **此处为模糊推测内容**：`n = 2⌈x⌉ + 64` 的节点规则是在 (0, 400] 上实测拟合的，
   我**没有**给出误差界的理论证明。更大的 x 或更高精度要求下它是否仍然成立，未知。

3. **此处为模糊推测内容**：自洽迭代（3.5 节）解的是"Z_rad 求值频率 = 加载后 fs′"
   这个不动点，它**仍然不是**完整的频变辐射模型——后者要在每个扫频点重算 Z_rad(f)
   并重解整个电路。两者的差别本轮没有评估。

4. **此处为模糊推测内容**：报告 F2 提到重新匹配"可能影响源侧效率、所需源幅度或带宽"。
   我同意这个方向，但**这些改善幅度本轮完全没有验证**，且它不可能突破 8.1 节的功率上界。

5. 报告第 4 节列出的全部已声明局限（无限障板、均匀活塞振速、一维模态、质量因子 1/2、
   部分覆盖线性叠加、钙化的流体代理、无声压场）**本轮一条都没有解除**，
   只是把它们写得更显眼了。

6. 本轮**未运行 LTspice、未做硬件实验、未做 COMSOL 或声场验证**，
   也未证明真实电路瞬态全过程不越限。所有几何、介质与源 BVD 数值**均为假设值，非实测**。

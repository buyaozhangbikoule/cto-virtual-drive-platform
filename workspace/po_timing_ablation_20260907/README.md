# 独立调幅与 P&O 调度：第三轮预先登记实验

本轮在第二轮 E04_B 上独立开展，不修改正式平台、网页、PPT或既有结果。所有电路参数是冻结的假设模型/扫描变量，控制参数是本次假设实验设置，均非实测、非论文复现。

## 固定条件

- 相位辅助关闭；受约束选频评分关闭；独立幅度 PI 保持 Kp=0.6、Ki=0.8/s。
- 0.8–1.0 MHz；相同戴维南源，幅度命令 0–1。
- 130/160 Vpp 软/硬电压限值，5.5/6 mA RMS 软/硬电流限值。
- 硬停机 60 ms、低幅恢复保持 100 ms、软稳定 100 ms，不缩短。
- 20 ms 控制周期；扫描点 1.5 ms；重新扫频幅度上限仍为 0.4。
- 重扫后 0.4 s 冷却加 10×20 ms 参考稳定等待保持不变。
- 验收仍为 NORMAL、频率未冻结、捕获率≥98%，连续10个合格控制样本。
- 所有动作调用同一个保护器。该保护器使用真实仿真模型预览，不是硬件安全过滤器。

## 18 个版本（运行前登记）

三个因素全因子，先分析单因素再查看交互，不随机挑一个“最好”的组合：

1. P&O等待间隔 T=100、300、600 ms。
2. P&O试探幅度命令上限 a=0.4、0.7、1.0；实际命令还受当前幅度与保护器限制。此因素不改变重扫幅度。
3. R0：从试探 RETURN 完成计时（复现旧调度）。R1：从调幅恢复后的首个 NORMAL CONTROL 样本完成计时。R1不用离线最优值或验收98%阈值来触发。

版本名示例 `T100_A040_R0`。它必须精确复现第二轮 E04_B 的所有已有轨迹字段（除版本名）。

## 预先登记的测试序列

- 主结果：原始同扰动序列，每段0.8 s。
- 延长窗口对照：完全相同顺序，每段1.6 s。
- 顺序鲁棒性补充：固定随机种子41、43、47，打乱6个中间扰动、保留首尾基准，每段0.8 s。仅作补充，不称统计置信度验证。
- 机制隔离：基准负载连续保持4 s，仅用于分析试探、恢复和稳态可用时间，不替代扰动验收。
- 补充两个原始 E02（无独立PI）P&O锚点，供定位改进来源。

## 输出及解释限制

每个版本保存配置、完整时序、每段指标、试探事件、扫频事件和审计。统计所有扫描/试探/保护动作的能量，不只画控制样本。记录试探次数、恢复耗时、实际试探间隔及采样间保持指令越限风险。降低试探频率可能提高输出但削弱变化检测，不能仅凭验收段数选优。

所有时间为假设的离散准稳态时间；未建模测量噪声、实际采样/通信延迟、开关瞬态或非线性。即使采样点不越限，也不能宣称160 Vpp在连续时间或实物中绝不超过。

运行：`python run_ablation.py` → `python validate_ablation.py` → `python validate_ltspice.py` → `python make_report.py`。重跑指定新的输出目录 `python run_ablation.py --out repeat_results`，禁止覆盖原证据。

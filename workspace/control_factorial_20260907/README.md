# 三因素控制消融：预先规定的试验与边界

本轮为用户要求的相位辅助、独立调幅、受约束选频及组合验证。不是任何论文算法的逐式复现。保留第一轮和正式平台，不覆盖旧数据或PPT。

## 版本矩阵

以第一轮E02为000对照，执行三因素完整2^3矩阵：A=相位提示+局部功率核验；B=独立幅度PI；C=受约束选频评分。另加两个匹配对照：LOCAL_ONLY、LOCAL_BC（保留局部功率捷径但去掉相位提示），防止把所有局部扫描收益都归于相位。

每个版本均运行固定频率、周期扫频、扫描辅助P&O；A/C不改变固定频率策略，B可调节其幅度。运行原0.8 s/段主序列及1.6 s/段补充序列。固定频率+B不再叫“固定幅度”。不随机拼接算法。另对34个注册场景逐个作离线寻峰诊断；这些诊断不等于34个闭环序列均已验收。

## 不变项

20 ms控制周期，1.5 ms扫描采样假设；硬保持60 ms、恢复保持100 ms、软稳定100 ms；恢复上升速率0.05/20 ms；0.8—1.0 MHz；软限130 Vpp/5.5 mA RMS、硬限160 Vpp/6 mA RMS；源幅度比例0≤a≤1及原戴维南源不变。限值属于用户要求/假设控制设置，不是器件安全额定值。

原正式验收仍为CONTROL、NORMAL、频率控制未冻结、捕获率≥98%，相邻CONTROL间隔≤30 ms，连续10样本。另计算不依赖NORMAL标签但仍排除扫描的连续功率窗口，以暴露状态标签影响，不替换正式验收。

## A：相位提示并用功率确认

- 相位固定为匹配网络输入相位arg(Zin)，不是换能器端口相位。
- 在原频率及±500 Hz以低幅采样，估计局部相位斜率。相位参考来自先前稳定工作点或实际扫描选中的工作点，不把0°当作功率目标。
- 局部功率已括住峰位则直接100 Hz细化；否则用(参考相位−当前相位)/局部斜率给出最多±50 kHz的候选频移，再在候选附近±2 kHz比较功率。斜率不可信、没有参考、候选不优或没有括住峰位则回退原完整扫描。
- 相位斜率最小1e-5度/Hz；候选功率改进与括峰对比阈值0.2%。全部为假设阈值，先不按结果整定。
- 局部功率法只验证局部峰，不能保证全局最优。LOCAL对照不使用相位候选，仅作同样的原频率局部括峰检查。

## B：独立幅度PI

仅用已经获得的Pport、Vpp、Irms及源幅度a估计线性增益G=Pport/a²，以及a_goal=min(1,130a/Vpp,0.0055a/Irms)。参考功率Pset=G*a_goal²，不主动降低功率目标。

在w=a²坐标中控制：e_w=(Pset−Pport)/G；w_request=w+0.6e_w+I；积分增益0.8/s，条件积分防饱和。保护/扫描/调频时重置或冻结积分；保护器仍限制实际升幅。误差进入目标功率的0.5%以内时请求精确目标，避免纯渐近到达。

若a_goal<1，达到该允许目标后可以进入NORMAL；不是要求所有工作点最终a=1。仍保留原功率98%及连续10样本标准，并另报去状态标签的功率窗口。B没有实现电流内环，也没有模拟完整功放。

## C：受约束评分

从实际低幅样本估算a_allow=min(1,130a/Vpp,0.0055a/Irms)，按J=(Pport/a²)*a_allow²排名，而非仅按Pport/a²。控制器不读取离线最优频率/功率；离线最优只用于评价。本轮C选择的是软限约束下、源幅度上限不变的准稳态局部工作点，不是动态MPC或安全定理。

## 输出与真实性

所有动作统一保护、实际幅度同步、完整计时。能量包含保护、扫描、试探和恢复，不删失败样本；采样间隙另以保持指令重放评估，不冒充动态瞬态。噪声、模型估计误差、执行延迟、储能/振铃仍未建模。

Python图像使用定量网格，分别呈现版本收益、失败段、能量代价与风险；提供PNG/SVG/PDF和可追溯脚本。无随机重复的结果不标误差棒或统计显著性。

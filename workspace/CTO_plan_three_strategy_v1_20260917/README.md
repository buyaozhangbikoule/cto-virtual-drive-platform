# 计划书三策略统一验证 v1（独立新实现）

本目录补齐固定频率、周期扫频、相位误差闭环的**同批次、同口径准稳态比较**。
历史平台、Claude 送审代码、P&O/相位消融文件及旧结果均未覆盖。本文不是全部项目完成声明。

## 如何运行

在本目录打开终端（Python 3.12、NumPy 2.2.4 已在本机验证）：

```powershell
python run_unified.py --test-only
python run_unified.py --suite all
python run_unified.py --suite historical
python run_unified.py --verify "outputs/具体批次目录"
python audit_batch.py "outputs/具体批次目录"
```

每次运行创建时间戳＋源码摘要的新输出目录，`exist_ok=False` 防止覆盖。
`--suite all` 包含原 12 段绝对日程和全部 34 个登记场景的独立基准→场景→基准试验。
每个三段试验开始显式重置控制器；不在一个连续试验中悄悄重置失败预算。
登记场景含 Qm=800、QL=100 等与基准物理参数相同的条目；34 是登记条目数，不是 34 种独立物理负载。

## 模块与边界

- `models/model_v2_1.py`、`stage2_matching/`：从第二轮审核 testbed 复制、冻结的 v2.1 线性电路模型及源标定；Rm-only 派生 Qm 修正保留。
- `engine.py`：共用实际执行、保护、整数微秒时间和分段积分日志。
- `controllers.py`：三个控制器；窄数据接口不提供场景编号、扰动开始时刻、离线最优频率或真值去嵌相位。
- `metrics.py`：唯一正式指标函数，不合格段的稳态误差为空值，不以尾窗/回退替代。
- `tests/test_unified.py`：故障注入和边界行为测试；这些测试不代表真实器件实验。
- `run_unified.py`：测试、校准冻结、批量运行、源码快照与哈希清单。
- `audit_batch.py`：从保存的CSV独立复算时间覆盖、验收、响应及能量，不调用正式指标函数；审计记录另存 `audits/`，不改原批次。电路复算仍用同一解析模型，不冒充LTspice独立求解。

这是新控制器实现，不是仅在旧程序上改三策略名称；不可把新数字与旧图拼成同次运行。

## 统一的物理和信号口径

基准假设：fs=0.9 MHz、Qm=800、Rm≈7352.94 Ω、C0≈6.858 pF。Lm/Cm 为机械支路电学等效元件，不是实际绕制电感。
戴维南源 a=1 对应约 6.21736 V RMS、Rs=50 Ω，匹配后换能器端约 100 Vpp / 5 mA RMS / 170 mW。
全部 BVD、匹配损耗、源阻抗为假设基线；场景变化为扫描变量；无实测器件参数。

相量统一 RMS；`S_port=V_port*conj(I_port)`，P=实部，Q=虚部。
频率记录 Hz，电压 Vpp，电流 A RMS（汇总另外给 mA RMS），功率 W，时间整数 us。
相位控制测点为 `arg(V_input/I_source)`；换能器端口相位另列，二者不混用。
理想 C0 不耗散，因此本模型 P_port=P_Rm；P_Rm 不是声功率。

## 正式策略

1. **FIXED**：0.9 MHz、不主动选频，名义幅度 a=1，受共同保护改变实际幅度。
2. **PERIODIC_SCAN**：每 0.5 s 的绝对周期到期后、在保护允许时启动。三级局部扫描为 ±50 kHz/5 kHz → ±5 kHz/1 kHz → ±1 kHz/0.1 kHz，边缘峰最多重定位 3 次。每点 1.5 ms，低幅请求 a=0.4，但仍必须经过保护。选频比较从实际 V/I/P 推算的软阈值可行功率，不查询当前场景最优表。起止锚点和最终候选复测验证失败即拒收。它只能确认局部候选，不证明全局最优。
3. **PHASE_FEEDBACK**：基准 0.9 MHz 输入相位标定约 −1.078209637°，每轮测试前冻结；增益 5 Hz/°、死区 0.1°、单次最大 500 Hz 均为假设控制参数。误差超死区时真实执行 f±100 Hz 邻频试探，各 1.5 ms，按测得斜率符号更新频率。试探被保护打断则本次斜率作废，不用免费模型查询补齐。未用去嵌机械相位，也未把相位目标自动更新为扰动后最优点。

三者共用 20 ms 普通控制采样时间格点。长扫描会错过格点，其成本照实计入；短试探在本格点间消耗时间，不能额外凑足验收样本。
未添加 PI 积分器，因此不存在需要伪装为已实现的“积分饱和修复”。

## 保护与失败处理

- 电压硬限 160 Vpp 是用户边界；130 Vpp 软限、5.5/6 mA RMS 软/硬限是待验证的假设控制阈值。
- 所有普通控制、扫描、相位试探、重试等待和回退都调用同一个保护器，实际幅度每次同步；先降幅再改变频率，渐升冻结频率。
- 假设硬停保持 60 ms、恢复保持 100 ms、软降幅保持 100 ms；渐升速率 2.5 每秒（等价每 20 ms +0.05），不能通过密集扫描点加速升幅。
- 无效/无信号/平坦扫描不得成功。失败保留旧可信目标，不采用末扫描频率；实际回退动作也走保护接口，并保持 a≤0.4。
- 初次失败后最多再试 2 次，每次至少间隔 50 ms，且还要等待保护放行。耗尽低幅锁存到测试显式重置，周期触发不能重新获得预算。50 ms / 2 次都是假设，不是论文证明值。
- 失败可能使后续跟踪和电能下降；这一代价必须保留，不删失败场景。
- **理想接口限制**：保护器在指令执行时刻用当前精确电路模型检查可行幅度。它不是仅靠有延迟测量的硬件保护，也没有证明真实 160 Vpp 绝不越限。调频器不获知这些模型参数。
- 若负载在一次保持期间发生变化，模拟器只分割电学响应和积分，不偷偷提前调用保护；已施加指令导致的样间越限单独记录。指令时刻保护前值、候选被拒和执行后值分别列出。
- 反射代理仅监测；本轮没有新增独立绝对功率上限或经验证的反射硬约束。

## 统一验收与积分

连续采样验收仍是：普通 CONTROL 样本、NORMAL、频率未冻结、有效测量、捕获率≥98%、相邻样本相隔20 ms，连续10个。
扫描和试探不计为普通样本；错过控制格点打断连续串。试探期间短暂功率损失不会被该采样验收自动表述为“没有损失”：完整能量和峰值单列。

- `first_qualified_sample_ms`：该段第一个合格控制样本，不保证以后形成10个连续样本。
- `recovery_enter_ms` / `recovery_confirm_ms`：首个成功10样本窗口的第一个/第十个采样时刻，相对扰动段起点；未成功均为空。
- `steady_error_pct`：首个已确认10样本窗口的平均绝对相对功率误差；未通过为空。不存在任何回退样本。
- `fixed_tail_error_pct`：最后200 ms所有执行阶段的时间加权功率缺额，单列诊断，不冒充稳态指标。
- `energy_J`：含扫描/试探/保护/等待/渐升的 P_Rm 分段保持积分，不是瞬态模拟。
- 捕获率分母是软阈值130 Vpp/5.5 mA和a≤1下的100 Hz网格最大P_Rm，明确叫“策略可行参考”；另存160 Vpp/6 mA硬限下参考，不混用。
- 功率稳定性、峰值过冲、V/I峰值、保护触发、候选限幅、实际越限持续时间、扫描失败/耗尽、频率饱和分别记录。
- 主表峰值包括保护前旧命令在新负载下的准稳态预测；保护后/保持区间峰值另外给出。可能出现“保护后峰值≤130 Vpp、保护前预测>160 Vpp”：必须报告，不能用保护后的值掩盖。这不是LTspice瞬态峰值或实测尖峰；理想瞬时保护前观测不被赋予虚构的持续时间。
- 100 Hz离散参考可能略低于网格之间的真实峰，故原始捕获率可能略高于100%。这不是能量创造；不截断掩盖，另用10 Hz网格作离散误差诊断，不事后修改本批次验收分母。

通过连续采样验收不证明采样间隙无波动、无越限；不通过也不等于电路求解错误。

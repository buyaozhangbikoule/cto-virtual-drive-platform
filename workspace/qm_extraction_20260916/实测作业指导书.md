# Qm / C_cable 实测作业指导书 · 2026-09-16

配套 `README.md`（算法验证）与 `janu2021_extraction.py`（提取脚本）。
本文只讲**怎么动手**：需要什么器材、按什么顺序扫、记什么数据、哪些坑会毁掉结果。

> 目标量只有三个：**Qm**（决定课题成败）、**C0**、**C_cable**。
> Rm/Lm/Cm 是顺带得到的。

---

## 1. 这是一次什么性质的测量

先把量级说清楚，器材选择全由它决定：

| | 数值 |
|---|---|
| 频率 | 0.9 MHz 附近 |
| \|Z\| 最小（串联谐振） | **约 6.8 kΩ** |
| \|Z\| 最大（并联谐振） | 27 ~ 97 kΩ（随 Qm 变） |
| 带外 \|Z\| ≈ 1/(ωC0) | 23 ~ 29 kΩ |
| 全程动态范围 | **仅 12 ~ 23 dB** |

**结论：这是一次低频、高阻、窄动态范围的测量。** 不需要射频级设备，
但**必须控制夹具杂散电容**（见第 5 节）。

## 2. 器材：三档方案

### 方案 A（推荐，最省）：信号源 + 双通道示波器 + 一只电阻

```
   信号发生器 ──[ Rref = 10 kΩ ]──┬── 换能器 ──┐
        │                          │            │
       CH1                        CH2          GND
```

测 CH1（激励）与 CH2（换能器端）的**幅度比与相位差**，即得
`Z = Rref · V2 / (V1 − V2)`。

| 器材 | 要求 | 说明 |
|---|---|---|
| 信号发生器 | ≥2 MHz，可扫频或可程控步进 | 任何入门级 AWG |
| 示波器 | 双通道，≥10 MHz 带宽 | 0.9 MHz 正弦，10 MHz 带宽绰绰有余 |
| Rref | **10 kΩ**，金属膜 1% | 见下表选值依据 |
| 探头 | **10× 探头，并做探头补偿** | 1× 探头输入电容近 100 pF，会毁掉 C0 |

Rref 选值依据（1 Vpp 激励下 CH2 的幅度）：

| Rref | 分压比范围 | CH2 最小幅度 |
|---:|---|---:|
| 1 kΩ | 0.880 – 0.999 | 880 mVpp（灵敏度差） |
| **10 kΩ** | **0.416 – 0.957** | **416 mVpp（推荐）** |
| 22 kΩ | 0.242 – 0.875 | 242 mVpp |

10 kΩ 让分压比落在 0.4–0.96，两个通道都在示波器舒适区，不需要额外增益级。

### 方案 B：USB 一体机（论文用的就是这类）

Digilent **Analog Discovery 2/3** 的 Impedance Analyzer 模式。
论文在 40 kHz 用的正是 AD2。**用前务必确认它在 0.9 MHz、kΩ 量级仍在规格内**——
这类设备的阻抗模式在高频高阻区精度会掉。先用已知电阻（如 6.8 kΩ）标定验证。

### 方案 C：实验室有现成的阻抗分析仪 / LCR 表 / VNA

直接用，但注意：
- **LCR 表**通常只到 1 MHz 或 2 MHz，且多为固定频点，**不一定能扫频** —— 我们需要整条曲线。
- **VNA** 要能工作到 0.9 MHz 以下（NanoVNA 类从 50 kHz 起，可用）。
  但 VNA 是 50 Ω 系统，测 7–97 kΩ 需要合适的夹具，反射法在高阻区精度差。
- **不需要**能直接读出 BVD 参数的高端机型。论文的核心论点就是这个，
  而且我们的噪声验证证明 0.5 dB / 2° 精度已足够（Qm 误差 <1%）。

## 3. 扫频怎么设：必须两遍

> ⚠️ **这一条修正了本批次 README 初稿的说法。**
> 初稿写「fS ±3%、4001 点」，那是**按 Qm=800 反推的**。
> Qm 未知时这个跨度可能太窄：

| Qm | 功率峰 FWHM | ±3%（±27 kHz）够吗 |
|---:|---:|---|
| 10 | 116.0 kHz | **远远不够** |
| 30 | 46.3 kHz | **不够** |
| 100 | 13.9 kHz | 勉强 |
| 300 | 4.6 kHz | 够 |
| 800 | 1.7 kHz | 够 |

**Qm 正是待测量，所以不能先假定扫宽。** 必须两遍：

**第一遍（粗扫，定位 + 估 Q）**
- 范围：**0.80 – 1.00 MHz 全带**
- 点数：**≥2001**（步长 100 Hz，即使 Qm=800、峰宽 1.7 kHz 也有 17 个点落在峰上，不会漏）
- 目的：找到 \|Z\| 极小/极大的大致位置，并**粗估 Qm ≈ fS / (−3dB 带宽)**

**第二遍（细扫，供拟合用）**
- 范围：以第一遍的 fS 为中心，**跨度取粗估 FWHM 的 5–10 倍**
  （Qm≈800 → ±15 kHz；Qm≈30 → ±250 kHz，此时直接用全带数据即可）
- 点数：**≥4001**，保证峰内有 ≥100 个采样点
- 这一遍的数据用于最终拟合

## 4. 驱动幅度

**用小信号。** 建议激励 0.5–1 Vpp，换能器端实际只有约 0.2–0.4 Vpp，
远低于 100 Vpp 工作点，不会触发非线性，也不会损坏器件。

模型本身是线性小信号模型，**不要**在大幅度下测——那样测到的是别的东西。

## 5. 最容易毁掉结果的一件事：杂散电容

C0 只有 **6.86 pF**（假设值）。夹具、引线、探头的杂散电容会直接并上去：

| 杂散 | 测得 C0 | 偏差 |
|---:|---:|---:|
| 1 pF | 7.86 pF | **+14.6%** |
| 5 pF | 11.86 pF | **+72.9%** |
| 10 pF | 16.86 pF | +145.8% |
| 20 pF | 26.86 pF | +291.6% |

**但好消息是：杂散电容对 Qm、Rm、Lm、Cm 完全没有影响（实测误差 0.0000%）。**
它只加性污染 C0。

所以：

1. **测 Qm 时不必纠结杂散** —— 这是本次测量最重要的量，它是免疫的。
2. **要拿到真 C0，必须先测空夹具**：不接换能器、其余一切照旧，扫同样的频段，
   得到的纯容性阻抗即杂散 C_stray。
3. 真 C0 = 测得 C0 − C_stray。

务必用 **10× 探头并做好探头补偿**；1× 探头的输入电容近 100 pF，会把 C0 淹没 15 倍。

## 6. 操作顺序（三次扫频）

| 次序 | 接什么 | 得到 |
|---|---|---|
| **① 空夹具** | 只有 Rref，换能器开路 | **C_stray** |
| **② 换能器直接接** | 换能器接在夹具上，不接导管电缆 | Rm, Lm, Cm, **Qm**, (C0 + C_stray) |
| **③ 换能器 + 导管电缆** | 按实际装配接上 1–1.5 m 导管线 | (C0 + C_stray + **C_cable**) |

推算：

```
C0      = ②的C0 − ①的C_stray
C_cable = ③的C0 − ②的C0
Qm      = ②直接读出（③也行，结果一样）
```

每次扫频都在**同一温度**下做，并记录温度 —— 论文在 28 °C 测量，并引用其
参考文献 [8] 讨论温度对等效电路参数的显著影响。

## 7. 交给我什么

每次扫频存一个 CSV，三列：

```
frequency_Hz,impedance_magnitude_ohm,impedance_phase_deg
800000.0,29013.2,-89.1
...
```

或者存复阻抗实虚部（`frequency_Hz,Z_real_ohm,Z_imag_ohm`）也可以。
文件名标明是①②③哪一次，并在同目录放一个文本说明：器材型号、Rref 实测值、
探头档位、激励幅度、温度、换能器型号与批次。

拿到后我会：
1. 用 `janu2021_extraction.py` 跑拟合，输出 Rm/Lm/Cm/C0/Qm 及拟合残差
2. 做三次扫频的交叉核对（C_stray / C_cable 是否自洽）
3. 用实测 Qm 替换 `bvd_parameters.json` 的假设值，重跑一致性测试
4. 把 C_cable 建进模型，重算功率结论

## 8. 常见坑

| 坑 | 后果 | 对策 |
|---|---|---|
| 用 1× 探头 | C0 偏大 15 倍 | 一律 10× 探头并补偿 |
| 没测空夹具 | C0 无法去杂散 | 三次扫频缺一不可 |
| 只按 ±3% 扫 | 低 Qm 时峰占满全屏，拟合发散 | 先全带粗扫再细扫 |
| 大幅度驱动 | 非线性，测到的不是小信号模型 | 激励 ≤1 Vpp |
| 只记幅度不记相位 | 拟合退化，Qm 不可靠 | 幅度与相位都要 |
| 换能器悬空/接触不良 | 谐振消失或畸变 | 先确认带外阻抗接近 1/(ωC0) |
| 三次扫频温度不同 | 参数漂移，相减无意义 | 同一温度，并记录 |

## 9. 测完先自检

数据交过来之前，你自己就能判断有没有测对：

- **带外阻抗**应接近纯容性（相位约 −90°），且 \|Z\| 随频率下降 —— 若不是，接触有问题
- **\|Z\| 极小值**应在 kΩ 量级（预期约 6.8 kΩ）—— 若是几十欧或几 MΩ，夹具接错了
- **极小与极大之间**应有清晰的相位穿越 —— 若相位曲线平坦，说明机电耦合极弱或没测到谐振
- **粗估 Qm = fS / (−3dB 带宽)** 应落在 10–2000 —— 超出这个范围先怀疑测量而不是器件

# 工作点 v3：由材料与几何正向推导 · 2026-09-16

取代 v2.1 的反推工作点。复现：`python3 workspace/operating_point_v3_20260916/bvd_from_geometry.py`

## 为什么重建

v2.1 把 `|Z(fs)| = 7.071 kΩ`（由 100 Vpp ÷ 5 mA 反推）当成硬性工作点，
34 个场景全部锚在它上面。导师 2026-09-16 澄清后该前提失效：

| v2.1 假设 | 澄清后 |
|---|---|
| 0.9 MHz 标称 | **0.8 MHz** |
| 100 Vpp 为工作点 | **推荐值**，与振幅成正比，越高越好 |
| 5 mA 为标称电流 | **上限**，推荐更小 |
| C0 = 6.86 pF（反推） | 由**材料与几何**决定，材料可选、⌀≤2 mm |

**v3 改为正向推导**，每一步都有物理出处，不再有反推的循环依赖：

```
L  = N33 / f0                     谐振长度（材料频率常数）
C0 = ε₀·εr·A / L                  静态电容（几何）
Cm = C0·k33²/(1−k33²)             机电耦合
Lm = 1/(ω₀²·Cm)
Qm = 1/(1/Qm_material + 1/Q_rad)  材料损耗与辐射损耗并联
Rm = ω₀·Lm / Qm
```

## 基线：PZT-8、⌀0.6 mm、0.8 MHz

| | |
|---|---|
| 谐振长度 | 1.88 mm（沿导管轴向放置） |
| C0 | **1.335 pF** |
| Cm / C0 | 0.694（k₃₃=0.64） |
| Qm | **30.3**（材料 1000 与辐射 31.2 并联 → 辐射主导） |
| Rm | **7093 Ω** |
| 工作点 | **100.2 Vpp、5.00 mA、176.9 mW**，受电流限制（不含任何连接导线） |
| ka | **0.98** |

**为什么是这一点**：它是四种候选材料里唯一能在 ka≈1 的前提下，用 5 mA 建立
100 Vpp 的组合。其余材料要达到 100 Vpp 都得缩到 ka=0.45–0.74，元件已远小于波长。

**⚠️ 余量为零**：ka=0.98 恰在辐射有效边界，电压刚过 100 Vpp。

## 导管电缆：本阶段不建模

**2026-09-16 决定移除。** 电缆假设来自 `HANDOFF.md` 第 4 节（上一会话提出），
**不是计划书要求，也未经确认**：

| 出处 | 是否提及电缆 |
|---|---|
| 计划书全文 | **0 次** |
| 项目自身 `docs/`、报告、讲稿 | **0 次** |
| HANDOFF.md 第 4 节 | 有，标题即「计划书漏掉的一阶效应」 |

移除理由：

1. 计划书第一章明确不涉及实物换能器与功放，纯电学建模阶段无需引入连接方式；
2. 长度（1.0–1.5 m）与容值（约 100 pF/m）全为推测，无任何依据；
3. **其影响完全取决于 5 mA 约束的是哪股电流**，而该问题尚未确定 ——
   在未定的假设上再叠一层假设，结论不可用。

> 供日后参考：若 5 mA 是**器件耐受**限值，电缆电流不流经压电体，
> 换能器工作点完全不受影响（125 pF 下仍是 100.2 Vpp / 176.9 mW），
> 代价是功放须额外供给约 22 mA 无功电流；
> 若 5 mA 是**功放能力**限值，同样电缆会把电压压到 21.7 Vpp、功率压到 8.3 mW。
> 交接文档「150 pF 衰减 41 倍」采用的是后一口径。
> `build()` 仍保留 `cable_pF` 参数，确认连接方案与电流口径后可随时启用。

| 材料 | ⌀0.4 | ⌀0.5 | ⌀0.6 | ⌀0.8 | ⌀1.0 | ⌀1.5 | ⌀2.0 |

| PZT-5A | 109.6 | 70.1 | 48.7 | 27.4 | 17.5 | 7.8 | 4.4 |

| **ka** | 0.65 | 0.82 | **0.98** | 1.31 | 1.63 | 2.45 | 3.26 |

ka ≤ 1 的列电学数值偏乐观：元件远小于波长时辐射效率显著下降。

**PZT-5H（先前使用的材料）在这组约束下是四种里最差的** ——
εr=3400 使 C0 过大、阻抗过低，同样电流下电压建不起来。

## 与 v2.1 的对照

| | v2.1 | v3 |
|---|---:|---:|
| 频率 | 0.9 MHz | 0.8 MHz |
| C0 | 6.86 pF（反推） | 1.335 pF（几何正向） |
| Cm/C0 | 0.0044 | **0.694** |
| Qm | 800（假设） | **30.3**（材料+辐射推导） |
| Rm | 7353 Ω | 7093 Ω |
| 峰宽 | 1.7 kHz | 约 26 kHz |

**Qm 从 800 降到 30**，正是前几轮三路径分析的推断值。
这意味着 v2.1 的三级扫描阶梯（为 1.7 kHz 尖峰设计）需整体重设计，
终扫级 0.1 kHz 已无必要。

## 边界

- 材料常数（εr、k₃₃、Qm、频率常数）取自**公开典型值，非本项目实测**。
- Q_rad 用空气背衬平板平面波近似，⌀0.6 mm 处 ka=0.98 已在适用性边界外。
- 33 模柱体假设；未建模匹配网络、背衬、粘接层与温度依赖。
- 全部为**电学**估算，不构成声输出、组织效应或临床结论。

# v3 扰动表重建（空心圆柱基线）

2026-09-16。**不覆盖** `active_stage3_5/stage3_disturbance/` 的历史结果，另开批次。

## 为什么要重建

v2.1 的 34 场景扰动表整表锚在 `|Z(0.9 MHz)| = 7.071 kΩ` 上。这个数不是测出来的，
是 `100 Vpp ÷ 5 mA` 反推的。导师 2026-09-16 澄清：100 Vpp 是推荐值、5 mA 是上限、
0.8 MHz 才是合适的振动条件、材料与尺寸都可选。反推的前提没了，C0 与 Rm 随之失去依据，
34 个场景全部失去基准点。

v3 改为由材料与几何**正向推导**，每一步都有物理出处。基线取文献器件的结构
（`reference/前视超声治疗.pdf`：PZT-5H 径向极化空心圆柱，OD/ID 1.35/0.73 mm，
31 模三次谐波 @ 0.8 MHz，长 5.62 mm）。

## 跑法

```
python3 run_disturbance_v3.py     # 34 场景扰动表
python3 scan_ladder_v3.py         # 扫描阶梯候选对照
python3 adaptive_matching_v3.py   # 固定匹配 vs 自适应匹配
```
输出在 `results/`。所有参数取自 `registry_v3.json`，代码里不写死数值。

## 基线对照

| 量 | v2.1（实心柱假设，反推） | v3（空心圆柱，正向推导） | 倍数 |
|---|---|---|---|
| C0 | 6.86 pF | 1730.5 pF | 252× |
| Rm | 7353 Ω | 30.38 Ω | 1/242 |
| Lm | 1.040 H | 127.5 µH | 1/8160 |
| Qm | 800（硬编码假设） | 21.09（材料 65 与辐射 31.2 并联） | 1/38 |
| \|Z_BVD(f0)\| | 7071 Ω | 29.4 Ω（28.40 − j7.51） | 1/241 |
| 功率峰 FWHM | 1.74 kHz | 74.5 kHz | 43× |
| 匹配拓扑 | 串联 L + 负载并联 C（降阻） | 源侧并联 C + 串联 L（升阻） | 翻转 |

功率平衡最大残差 4.4e-16 W；基线匹配后 Z_in = 50.03 − j0.56 Ω，Γ = 0.006，φ = −0.64°，
落在文献器件自身的容差（50 Ω±3 Ω、0°±5°）之内。

## 四条结论

### 1. stage2 的匹配拓扑整体作废，不是参数要改

旧拓扑（并联 C 跨负载）在新负载上**物理不可行**，不是调参能救的。
并联 C 只改虚部，输入实部上限为 `1/Re(Y_load)` = 30.38 Ω，恒小于 50 Ω，
C 取任何值都够不到。v3 把并联元件挪到 50 Ω 一侧（`max_real_part_with_shunt_c()`
就是用来给出这个上界的，不靠试算）。元件种类没变，仍是一个 L 一个 C，
只是接法不同：L = 6.421 µH，C = 3.470 nF。

### 2. 约束者从 V/I 变成了功率，34/34 全部由功率咬住

v2.1 里 V/I 硬约束「一次都没触发」曾被当成问题查。在 v3 里这个问题消失了，
但原因不是修好了限幅逻辑，而是**约束的性质变了**：
100 Vpp 与 5 mA 相除即 7.07 kΩ，在 50 Ω 功放下不成立；两者之积 176.8 mW 才是
可跨几何迁移的量。34 个场景全部被端口功率上限咬住（`binding_soft_limit_at_f0` 一律为 `P`）。

电压上限也必须随几何重算：31 模的电极间距是**壁厚 0.31 mm**，不是长度。
按 250 V/mm 场强限得 155 Vpp；33 模实心柱的电极间距是长度 5.6 mm，同样场强下
容许电压高 18 倍。v2.1 的 160 Vpp 不能原样搬。

### 3. 扫描阶梯：三级 53 点 → 两级 18 点，又快又准

FWHM 从 1.74 kHz 变成 74.5 kHz，v2.1 的 0.1 kHz 终扫级步长相当于峰宽的 **1/745**，
纯属把时间花在不需要分辨的尺度上。

| 阶梯 | 点数 | 时间代理 | 最差捕获 | <90% |
|---|---|---|---|---|
| v2.1 原样搬运 ±50k/5k→±5k/1k→±1k/0.1k | 53 | 79.5 ms | 0.870 | 1 |
| v2.1 加宽粗扫 ±100k/5k→… | 73 | 109.5 ms | 1.000 | 0 |
| **v3 推荐 ±80k/20k→±20k/5k** | **18** | **27.0 ms** | **0.996** | **0** |
| v3 单级 ±80k/10k | 17 | 25.5 ms | 0.988 | 0 |

推荐 **±80 kHz/20 kHz → ±20 kHz/5 kHz**：比 v2.1 快 2.9 倍，最差捕获还从 0.870 升到 0.996。
依据是测出来的，不是拍的：粗扫半宽须 ≥ fs 最大偏移 69.7 kHz；步长取最窄峰
（Qm 两倍基线的场景，37.7 kHz）的 1/4 即 9.4 kHz 就够，20 kHz 配上细扫级仍达标。

v2.1 的 `known_coverage_gap`（CASE_LM_P20 / CASE_CM_P20 够不到）在 v3 下**仍然存在但不再致命**：
这两个场景的 fs 偏移 −69.7 kHz 依旧超出 ±50 kHz 粗扫，但峰宽 74.5 kHz 意味着
偏 69.7 kHz 仍落在半功率点附近，捕获率 0.870 而不是 v2.1 的 0.001。

### 4. 自适应匹配：值得做，但理由和原先设想的不一样

计划书第 4 周的四种策略（FIXED / PERIODIC_SCAN / P_AND_O / PHASE_LOCK）都只调频率，
匹配网络是 stage2 一次定死的。文献器件用继电器切换 L-C 逐频重调。三种策略对照：

| 策略 | Γ 均值 | Γ 最差 | 超 VSWR 3:1 | 文献容差达标 |
|---|---|---|---|---|
| A 固定匹配 + 固定频率 | 0.235 | 0.903 | 8/34 | 17/34 |
| B 固定匹配 + 频率跟踪 | 0.034 | 0.203 | 0/34 | 26/34 |
| C 自适应匹配 + 频率跟踪 | 0.007 | 0.026 | 0/34 | 30/34 |

**按功放保护判据（VSWR），自适应匹配没有必要**——B 已经 0/34 超限。
交付到 Rm 的功率三者相同（都驱到 176.8 mW），功放输出功率 B→C 中位数只差 −0.2%。
原因是这个匹配网络的 Q 只有 0.87（50/28.4 的阻抗比很小），本身就很宽带，
在 ±70 kHz 内几乎不失谐。

**真正的收益在电阻漂移，不在频率漂移。**
B 的 8 个未达标场景没有一个是频率漂移：3 个 Rm +15/30/50%（相位误差至 −21.5°）、
2 个 Rs +10/20%、3 个同时含 Rm 与 Rs 分量的 combined。
而 9 个纯 fs/Lm/Cm 漂移场景 B **全部达标**。原理上如此：挪频率挪不动负载电阻。

这对本课题不是边角情况——器件发热、以及顶到斑块与泡在血里之间的声负载变化，
改的正是 Rm。所以频率跟踪与自适应匹配是**互补**关系，不是二选一：
前者管 fs 漂移，后者管 Rm 漂移。

C 需要的调谐范围：L −4.3% ~ +27.0%，C −41.0% ~ +5.2%。

一处需要说明：C 有 4 个场景按文献容差「不达标」，全部是 Rs +10/20% 的场景，
此时 |Z_in| = 55 / 60 Ω 而相位近 0°——匹配网络正确地匹配到了**漂移后的源阻抗**，
Γ 只有 0.005~0.026，是完美匹配。不达标的是「50 Ω±3 Ω」这把绝对尺子本身，
它默认源就是 50 Ω。**当 Rs 本身是扫描变量时，只有 Γ 这个判据仍然成立。**

## 与 v2.1 相比，场景定义只改了一处

Qm 档位由 500/800/1000 改为基线的 0.5×/1×/2×（10.55 / 21.09 / 42.19）。
基线 Qm 由材料损耗（PZT-5H 典型 65）与辐射损耗（平面波近似 31.2）并联导出，约 21；
浸入血液的 PZT-5H 上 500/800/1000 物理不可达——单是辐射损耗就把 Qm 压到 31 以下。
其余 31 个场景的因子与百分比档位与 v2.1 完全一致，可逐格对照。

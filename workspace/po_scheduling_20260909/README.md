# P&O试探周期、幅度及恢复时序：第三轮预先规定的验证

研究对象仍是假设小信号线性BVD的离散准稳态电学控制，不是实测、硬件、声学或临床结果。保留第一、第二轮及正式平台，不覆盖历史成绩。

## 试验设计

在两个匹配控制组中分别验证：B0=无独立幅度PI（第二轮E02）；B1=有独立幅度PI（第二轮E04_B）。相位辅助A、约束评分C不加入本轮，避免混淆。

三个因素完整交叉：

|因素|等级|定义|
|---|---|---|
|P&O等待间隔T|100、300、500 ms|R0从上次试探返回动作结束起计时，不等于实际试探起点间隔|
|P&O试探幅度上限|0.4、0.7、0.9|相对冻结戴维南源幅度；实际值还受保护器限制，不保证较高档一定安全|
|恢复后的再试探规则|R0、R1、R2|见下文；不修改恢复速率或保护保持时间|

R0：保留旧逻辑，计时到期且保护允许后试探。计时可能在恢复期间已经到期。

R1：在R0条件之外，要求最近一次恢复后的NORMAL起点至今至少T；任何扫描、试探或非NORMAL状态重新建立该起点。

R2：在R1条件之外，要求10个连续稳定NORMAL控制样本（频率相同、幅度相邻变化≤0.002、无异常投票、相邻样本≤30 ms）。不读取离线最优功率，也不检查评价用的98%捕获率；这个规则不等于验收通过。原检测器在a<0.999时仍冻结，因此也不能把R2叫作“原检测器参考已就绪”。

初始首次试探保留旧行为；安全触发或可观测异常触发的重捕获不受R1/R2延迟规则阻挡。原重捕获冷却时间保留。

2×3×3×3=54种配置，全部运行原0.8 s/段主序列及1.6 s/段补充序列，共108条P&O时序。选出的候选只可称在本测试集合中表现较好，不是独立验证过的通用最优参数。

## 冻结项及额外恢复诊断

硬限160 Vpp/6 mA RMS，软限130 Vpp/5.5 mA RMS，控制周期20 ms，硬保持60 ms，恢复保持100 ms，软保持100 ms，主试验升幅上限0.05/20 ms，频段0.8—1.0 MHz，源幅度上限a=1，PI增益0.6/0.8每秒均不变。

重捕获扫描幅度上限始终0.4，不能随P&O试探幅度一起改变。每个参考、试探、返回及扫描动作都走原统一保护接口。

另作24组固定频率恢复台架诊断：B0/B1、初始幅度0.4/0.7/0.9、升幅步长0.025/0.05、基准与Rm−30%两个场景。只隔离恢复段，不含此前硬/软保持；较慢步长仅为敏感性检查，不进入主矩阵。没有采用更快升幅、减少保持或提高硬限来换取成绩。台架诊断中的功率目标是固定频率允许输出，不是全频最优。

## 验收及数据口径

主验收保持为CONTROL、NORMAL、频率控制未冻结、当前场景安全功率捕获率≥98%，连续10样本且相邻CONTROL间隔≤30 ms；确认时刻为第10样本时间戳。另报不依赖状态标签的连续功率窗口，不替代主验收。

同时报告全过程能量、全部动作中捕获率≥98%的保持时间占比、实际试探间隔、扫描及试探时间、限幅次数、采样间隙重放越限及峰值V/I。较长间隔可能更容易满足连续窗口，不能只凭通过段数宣称算法更好。

原保护器仍利用当前精确模型预估。保持指令的间隙重放不包含储能振铃、真实延迟或噪声，不是LTspice瞬态。此次主要改动调度层，不以重复AC对照冒充调度瞬态验证；保留此前AC审计出处及哈希。

## 已运行的交付与复现入口

详细结论在`deliverables/独立调幅与P&O调度验证报告.md`。`results/`保留108组主结果，`recovery/`保留24组固定频率恢复诊断，`independent_tests.json`记录程序约束检查。脚本依赖Python 3.12、numpy、scipy、matplotlib（具体实际版本见执行环境审计）。

解压后进入本目录，在PowerShell中运行（输出目录须为新目录，不覆盖旧证据）：

```powershell
$env:PYTHONUTF8='1'
python reproduce.py --out rerun_matrix --bench-out rerun_recovery
python make_report.py
```

`reproduce.py`只依赖包内冻结代码及参数，不要求历史文件仍位于原路径。`make_report.py`默认绘制交付的`results/`和`recovery/`，不会悄悄改用新目录；需对新一轮出图时显式修改其输入路径并保留版本。每组结果包含配置、时序、评价表、试探/扫描事件与哈希。

关键参数：`B1`为有独立PI；`T500`为等待参数500 ms，不是实际试探周期；`A90`为P&O幅度上限0.9，扫描仍为0.4；`R2`为恢复后等待加稳定样本门槛。新参数均为**假设控制设置/扫描变量**，不是文献已验证值。全部结论仅限假设BVD电学模型。

本轮未更改正式网页、PPT或旧实验。没有新增LTspice控制瞬态或GUI截图；`frozen/prior_AC`是历史真实AC审计副本，不能当成本轮控制验证证据。

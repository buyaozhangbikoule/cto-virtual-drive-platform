# 本次真实LTspice截图：操作与口径

## 必须区分

- `.raw` 是LTspice求解产生的二进制瞬态数据。
- `RAW_*.png` 是Python从RAW提取后绘图，**不是软件截图**。
- `GUI_*.png` 仅能由真实LTspice窗口截取，不能用绘图代替。
- 本次只重放P&O历史指令片段；没有在LTspice中运行实时反馈控制器，也不代表整页三策略全部完成瞬态验证。

## 打开基准波形

1. 启动LTspice，File → Open，文件类型选择All files / RAW。
2. 打开本目录 `BASELINE_DT_2NS.raw`。同名`.plt`用于预置波形布局；若未加载，使用Plot Settings → Open Plot Settings File。
3. 显示 `V(n_port)` 和 `I(Vprobe)`。前者是端口瞬时电压，后者是进入BVD端口的瞬时电流。
4. 把横轴放大到1.98–2.00 ms，显示约18个载波周期。必要时右击纵轴选择自动范围。
5. 截图保留软件标题/RAW文件名、曲线名、完整坐标和单位，不只截一小块曲线。

## 打开指令重放波形

1. 打开本目录 `PO_FS_M5_REPLAY_DT2NS.raw`，同名`.plt`预置四个面板。
2. 面板为 `V(n_port)`、`I(Vprobe)`、`V(a_cmd)`、`V(f_MHz)`。
3. `a_cmd`和`f_MHz`是指令记录辅助节点，虽然LTspice以电压节点显示，分别代表无量纲幅度和以MHz为单位的频率，**不是换能器的实际电压**。
4. 全时段图显示0–224 ms；前3 ms是人为加入的电路建立时间。
5. 原控制时序时间 = LTspice时间 + 2.835 s。正式比较使用LTspice 3–224 ms，即原2.838–3.059 s。
6. 另截尾段223.94–223.95 ms，展示真实约0.8548 MHz载波。
7. 全时段载波很密，呈包络填充状属正常。请保留原始截图，不把密集带误称为低频振荡。

## 日志截图

1. 在LTspice中打开对应`.cir`；使用View → SPICE Error Log（常见快捷键Ctrl+L）。
2. 若该窗口不关联已完成批处理日志，使用File → Open直接打开同名`.log`，不要为了截图改写日志内容。
3. 保存含文件名、软件版本、Total elapsed time和`.meas`结果的页面；日志分屏时可分两张。
4. `.meas`尾段数据与全时段最大值不是同一个统计量。不能拿尾段正常证明全过程无越限。

## 不能写的结论

- 不能写“整张历史保护图由LTspice直接生成”。
- 不能写“三种控制器都已完成LTspice瞬态闭环验证”。
- 不能以有限时间步长和有限窗口统计证明硬件160 Vpp绝不越限。
- 所有模型参数均是假设值；不是实测，不包含功放、声场、组织或临床验证。

# 控制器参数设定：文献依据、工程选择与适用边界

## 1. 本轮采用的架构

采用 Python 执行控制器、保护状态机和统计，LTspice AC `.raw` 作为被控电路的频率响应查表数据。当前仍是线性、小信号、准静态电路模型；没有真实换能器数据、功放开关瞬态、温升、非线性、声压或 COMSOL 声场。

三种策略共用同一保护层：

`NORMAL → SOFT_LIMIT → HARD_TRIP → RECOVERY_LOW_AMPLITUDE → RAMP_UP`

保护层优先级高于频率策略。也就是说，一旦过压或过流，控制器不能只记录“约束触发”，而必须实际降幅、关断或低幅恢复。

## 2. 为什么不直接锁定总端口相位 0°

压电换能器的静态电容、匹配网络和动态支路共同决定端口相位。不同频率判据对应的特征点并不完全相同：机械串联谐振、最大导纳和端口电纳为零可能仅在特定条件下近似重合。改进 LC 匹配网络的研究也明确区分了 (f_s)、最大导纳频率 (f_m) 和端口相位为零的 (f_r)。因此总端口相位 0° 不能未经校准就当成最大功率点。[Sensors 2023](https://doi.org/10.3390/s23125745)

高功率换能器的 PLL 研究指出，静态电容会缩窄跟踪范围并造成误跟踪或失锁，因此提出静态电容宽带补偿。[IEEE TUFFC 2012](https://ieeexplore.ieee.org/document/6156822)

近期最大电导极值寻优研究采用最大电导而非单纯端口零相位作为串联谐振跟踪目标，并强调其对 (C_0) 不敏感。[Applied Acoustics 2025](https://doi.org/10.1016/j.apacoust.2024.110409)

基于这些结果，本轮相位策略采用：

1. 先以低幅扫频找到“约束下最大安全有功功率点”；
2. 把该点的端口相位设为局部目标 (phi_\text{target})，而不是固定为 0°；
3. 从扫描点估计局部斜率 (s_\phi=d\phi/df)；
4. 使用

\[
\Delta f=\operatorname{clip}\!\left(\alpha\frac{\phi_\text{target}-\phi}{s_\phi},-\Delta f_\max,\Delta f_\max\right)
\]

更新频率。斜率决定符号，因此不会再次把正反馈误写成负反馈。

## 3. 为什么仍然测量电压和电流

HIFU 电功率监测研究表明，仅测电压不足以可靠估计实际送入换能器的电功率；联合瞬时电压和电流测量更合适，也直接服务于过压、过流和有功功率保护。[IEEE TUFFC 2020](https://doi.org/10.1109/TUFFC.2019.2941185)

导纳特征跟踪研究同样使用端口电压、电流及相位重建阻抗/导纳，并采用粗到细的频率修正；其建议初始频率步长应小于有效谐振带宽，以免跨过峰值。[Mechanical Sciences 2026](https://doi.org/10.5194/ms-17-255-2026)

因此，未来实物系统至少应同步记录：端口电压、端口电流、相位、有功功率、命令频率、幅度命令和保护状态。只记录频率与相位不足以验收功率恢复和器件安全。

## 4. 本轮冻结参数

| 参数 | 数值 | 选择理由 |
|---|---:|---|
| 控制周期 | 2 ms | 对 0.9 MHz 载波属于慢包络控制；当前 RAW 模型不解析载波周期内开关瞬态 |
| 扫频点总耗时 | 1.5 ms/点 | 包含换频与等待的工程假设，明确计入总时间轴 |
| 扫描探测幅度 | 50% | 当前全部 RAW 中单位幅度最坏约 194.77 Vpp、5.16 mApeak，50% 探测仍低于本轮软限值 |
| 周期扫频间隔 | 1 s | 在 2 s 扰动驻留时间内至少有一次重捕获，同时避免 500 ms 设置造成过高扫描占空比 |
| 相位强制复核 | 2 s | 平时依靠相位跟踪；功率掉落、相位大误差、斜率过小或频率饱和会立即提前重扫 |
| 频率范围 | 0.84–0.96 MHz | 与现有 LTspice RAW 数据范围一致 |
| 粗扫步长 | 2 kHz | 快速接近局部峰；随后用 0.1 kHz 细扫修正 |
| 细扫窗口/步长 | ±1.5 kHz / 0.1 kHz | 粗扫点距为 2 kHz，局部窗口足以覆盖最近峰并给出相位斜率样本 |
| 相位归一化增益 (alpha) | 0.25 | 每次只消除约四分之一局部线性误差，保留稳定裕量 |
| 相位死区 | ±0.5° | 避免微小数值误差导致频率抖动；真实硬件应由相位噪声决定 |
| 单步最大频移 | 2 kHz | 防止斜率估计误差造成一次大跳；超过捕获条件时改用重扫 |
| 软限值 | 150 Vpp、5.5 mApeak | 基于既有 100 Vpp 标定留出裕量的仿真假设 |
| 硬限值 | 160 Vpp、8 mApeak | 用于验证保护跳闸流程，不是换能器数据手册额定值 |
| 硬关断/恢复观察 | 100 ms / 20 ms | 让状态机动作可观察；实物值需结合功放、温升和器件手册重定 |

## 5. 触发重新扫描的条件

满足任一条件即退出纯相位跟踪并低幅重扫：

- 幅度归一化后的有功功率低于上次捕获参考值的 80%；
- (|\phi_\text{target}-\phi|>20°)；
- (|s_\phi|<0.2°/\text{kHz})，局部相位对频率不敏感；
- 频率到达 0.84 或 0.96 MHz；
- 发生硬保护；
- 距上次校准达到 2 s。

这使相位环成为“局部维持器”，扫频成为“全局捕获/纠错器”。它避免把多相位零点系统当作全局单调对象。

## 6. 接入真实数据后必须重定的参数

以下参数不能以当前虚拟模型结果直接用于硬件：

- 过压、过流、温度和占空比限值；
- 实际换频后的稳定时间和扫描点驻留时间；
- 相位测量噪声、固定通道延迟与死区；
- 幅度命令到端口电压/电流的比例关系；
- 功率放大器效率、匹配网络温升和换能器非线性；
- 扫描探测幅度；
- 扰动的真实时间尺度。

在这些数据到位前，本轮结果可以用于审核算法逻辑和生成实习报告的方法章节，但不能作为硬件安全参数或声学效果结论。

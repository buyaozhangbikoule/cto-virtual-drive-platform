# 第四、第五步重做：实操计划与证据保留清单

## 1. 最终目标

完成一套可以放进实习报告、且能区分“真实运行证据”和“虚拟模型假设”的结果包：

1. 使用本机 LTspice 真实运行全部基准和扰动 `.cir`，保存 `.raw/.log`。
2. 基于 LTspice RAW 实现公平的准静态控制时序。
3. 三种策略使用同一扰动、同一保护状态机、同一时间口径。
4. 重新生成第五步综合表和全部控制图。
5. 保存程序、参数、运行记录、文件哈希、软件截图和结果解释。
6. 最终为实习报告提供“方法—仿真—结果—讨论—局限性”的完整证据链。

## 2. 工作边界

报告中的准确表述：

> LTspice用于生成各扰动状态的线性稳态AC频率响应；外部控制程序读取LTspice RAW数据，实现带保护状态机的离散准静态控制仿真。

不能写成：

> 已在真实换能器、功率放大器或LTspice瞬态闭环中完成控制实验。

本轮不包括真实声功率、声压、温升、空化、COMSOL、患者数据或CTO治疗效果。

## 4. 推荐的默认仿真时间口径

在没有硬件时序数据时，建议同时输出两套时间：

1. **无量纲控制步数**：不依赖硬件，作为主要可复现指标。
2. **假设工程时间**：仅用于说明扫描开销，报告中必须标“假设”。

推荐默认值：

| 参数 | 推荐值 | 身份 |
|---|---:|---|
| 普通测量/控制步 | 2 ms | assumed |
| 频率切换与建立时间 | 0.5 ms/点 | assumed |
| 扫频测量驻留 | 1.0 ms/点 | assumed |
| 单个扫描点总时间 | 1.5 ms | derived |
| 周期扫描间隔 | 500 ms | assumed |
| 每个基准段 | 1.0 s | assumed |
| 每个扰动段 | 2.0 s | assumed |
| 硬停机保持 | 100 ms | assumed |

原始 ±50 kHz、0.5 kHz 局部扫描约201点，对应约301.5 ms。该时间必须计入恢复时间，不能再当作瞬时动作。

## 5. 重做后的统一扰动序列

采用以下形式，避免从一种单因素直接跳到另一种单因素：

```text
baseline
→ C0 +10% → baseline
→ C0 +20% → baseline
→ C0 +30% → baseline
→ Rm +15% → baseline
...
→ Q=20 → baseline
→ combined low → baseline
→ combined medium → baseline
→ combined high → baseline
```

要求：

- 三种策略使用完全相同的状态顺序和持续时间。
- 扰动开始时刻不与周期扫描时刻对齐。
- 使用固定随机种子生成轻微时间偏移，并保存最终时间表CSV。
- 每次状态切换先记录当前工作点响应，再允许控制器采取动作。

## 6. 三种策略的正式定义

三种策略共用同一个幅度保护状态机。这里的“固定幅度”指固定标称幅度，保护动作可以覆盖它。

### A. 固定频率、固定标称幅度

- 频率保持0.9 MHz。
- 标称源幅保持基准值。
- 只允许公共保护状态机降幅或停机。

建议报告名：`固定频率+固定标称幅度（保护可覆盖）`。

### B. 周期性局部扫频

- 按固定周期触发，而不是在已知状态变化时获得额外扫描机会。
- 在当前频率附近逐点扫描。
- 每个扫描点占用真实/假设时间，并记录扫描期间的电压、电流和功率。
- 在低探测幅度下扫描，防止搜索过程引发过压。
- 候选点按“满足约束时最大运动支路有功功率”选择。
- 最优点位于窗口边缘时触发扩窗或全局重捕获。

### C. 基于标定相位的离散跟踪

- 初始/重捕获扫频先找到安全最大功率点。
- 把该点相位记为 `phi_target`，不固定为0°。
- 保存全部相位零点，但不默认选择零相位作为功率目标。
- 在当前点附近估计 `dphi/df`。
- 根据斜率符号调整控制方向。
- 加入相位死区、最大步长、频率限幅、失锁判定和重新扫频。

推荐控制形式：

```text
df = clip(Kphi * (phi_target - phi) / slope_sign_or_magnitude,
          -df_max, df_max)
```

最终实现会使用数值稳定、避免斜率接近零除法的等价形式。

## 7. 公共保护状态机

建议状态：

```text
NORMAL
  ↓ 软越限
SOFT_LIMIT（逐步降幅）
  ↓ 恢复安全
NORMAL

任意状态 ↓ 硬越限
HARD_TRIP（幅度置零）
  ↓ 保持时间结束
RECOVERY_LOW_AMPLITUDE
  ↓ 低幅重捕获/安全确认
RAMP_UP
  ↓ 达到目标或软限
NORMAL / SOFT_LIMIT
```

软限幅比例初值：

```text
scale_v = Vsoft / Vpredicted
scale_i = Isoft / Ipredicted
new_amplitude = current_amplitude * min(scale_v, scale_i) * 0.98
```

硬越限后必须改变后续状态，不能只增加一个计数器。

每次保护记录：事件编号、进入时间、退出时间、场景、频率、幅度、最大Vpp、最大Ipeak、恢复结果。

### LTspice常用Add Trace表达式

输入阻抗幅值：

```text
mag(V(n_s)/I(Rlesr))
```

输入阻抗相位：

```text
ph(V(n_s)/I(Rlesr))
```

运动支路有功功率：

```text
re(V(n_in)*conj(I(Rmot)))
```

换能器端Vpp：

```text
mag(V(n_in))*2*sqrt(2)
```

BVD端总峰值电流：

```text
mag(I(Rmot)+I(Cstatic))*sqrt(2)
```

固定50 Ω参考反射代理：

```text
mag((V(n_s)/I(Rlesr)-50)/(V(n_s)/I(Rlesr)+50))
```

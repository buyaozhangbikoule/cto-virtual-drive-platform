# 项目任务说明审核：忽略参考参数后的非参数条款核查

审核日期：2026-08-14  
审核范围：不评价任何BVD元件值、扰动百分比、阈值或控制增益是否合适，只审核项目边界、技术路线、指标、控制逻辑、软件证据和验收规则。

## 1. 总结论

任务说明的总体技术路线符合当前第一月虚拟建模项目：

`BVD等效电路 → L型匹配 → 单因素/组合扰动 → 选频准则 → 离散准稳态控制 → 统一扰动综合比较`

项目边界、工具分工和可复现性要求基本正确，COMSOL与真实测量延后也合理。但任务说明不能不加修订地直接作为最终验收标准。以下三项属于必须修改的原则性口径：

1. BVD的串联谐振 `fs`、总阻抗最小点、最大导纳/电导点和端口相位零点不能预设为同一点。
2. 匹配前后功率比较必须冻结相同的源条件、测量平面和功率定义，否则比较没有唯一含义。
3. LTspice AC响应表加Python离散控制器属于准稳态虚拟闭环，不能表述为LTspice瞬态控制、真实PLL或真实毫秒级硬件动态。

在修订这些口径后，任务说明可以作为项目正式执行规范。

## 2. 逐条合理性审核

| 模块 | 判断 | 审核意见 |
|---|---|---|
| 项目边界 | 通过 | 仅研究线性小信号等效电路，不外推到真实声场、CTO效果或临床安全，符合当前数据条件。 |
| 数值来源分类 | 通过 | 文献参考值、假设基线值、扫描变量三类身份必须保留；图、表、CSV和报告均应带来源字段。 |

| LTspice+Python分工 | 通过 | LTspice负责电路AC响应，Python负责解析交叉验证、扰动生成、控制时序和统计，适合当前阶段。 |

| 步长/窗口比较 | 通过 | 应以更细离线参考解衡量频率和功率误差；扫描时间只能按点数×假设驻留时间估算。 |

| 周期局部扫频 | 通过 | 扫频探测本身的功率跌落、耗时和跨扰动边界问题必须进入综合指标。 |

## 3. 各阶段应采用的正式验收文字

### 阶段一：裸BVD

建议把原来的“确认0.9 MHz附近出现 `|Z|`最小、相位过零的串联谐振”改为：

> 根据运动支路电抗零点或总电导峰值识别系列谐振 `fs`，并分别记录总阻抗局部最小点、最大导纳点、全部相位零点及并联/反谐振点。比较这些特征频率，不预设它们完全相同。

“无损耗理想BVD”也应改成“保留表示机械阻尼的 `Rm`，暂不加入匹配元件ESR、介质损耗和源附加损耗”。若把 `Rm` 同时去掉，模型会变成无限Q理想谐振，既不利于数值计算，也不符合后续峰宽分析。

### 阶段二：匹配网络

匹配前后比较必须同时声明：

- 同一个源Thevenin电压和源阻抗；
- 同一个频率网格；
- 电压、电流和功率的测量节点；
- 匹配目标是源端共轭匹配、换能器有功最大，还是反射代理最小；
- 匹配损耗、源电阻损耗、运动支路功率和总输入功率分别记录。

否则“匹配后功率提高”可能只是源幅度或测点改变造成的。

### 阶段三：扰动与选频

- 每个单因素场景只改变一个独立参数。
- 通过 `Lm` 或 `Cm` 实现 `fs` 漂移时，必须注明另一个元件、`Rm`和`Qm`是保持还是联动。
- 源/匹配网络的“小、中、大偏差”必须展开成具体元件和方向，不能只保留文字标签。
- 峰宽需指定对象，例如有功功率相对局部基线的FWHM。
- 相位没有过零时，仍可输出最小绝对相位点，同时设置 `phase_zero_exists=false`。
- 粗扫的最优点应由细扫或连续优化复核，避免把网格误差当成物理漂移。

### 阶段四：控制器

控制器正式定义为离散准稳态循环：每次根据当前场景和频率，从解析模型或LTspice AC响应表获得复数稳态响应，再更新下一步命令。报告必须说明：

- 它不是开关功放瞬态模型；
- 它不包含真实换能器机械建立时间；
- 控制周期和频点驻留时间是仿真假设；
- 恢复时间是该假设时间轴上的算法指标。

主策略应保持互斥：

1. 正常态固定频率和幅度，保护覆盖；
2. 周期局部扫频选择受约束最大有功点；
3. P&O直接追踪受约束有功功率。

纯相位闭环作为第四个消融对照更合理。若混入功率扫描重新捕获，应命名为“扫描捕获+相位维持混合策略”，不能简称相位策略。

保护执行顺序应为：

`读取/预测当前响应 → 硬限命令裁剪 → 状态机转移 → 幅度命令 → 仅在NORMAL态更新频率`

### 阶段五：综合比较

每个扰动场景先用细离线搜索得到受约束参考最优功率 `P*` 和频率 `f*`，再定义：

- 稳态误差：相对 `P*` 的功率损失，而不只是频率差；
- 恢复时间：进入规定误差带并连续保持规定样本数；
- 功率稳定性：稳态CV和峰峰值；
- 过冲：相对新场景稳态值或 `P*`，二者择一并统一；
- 振荡：稳态频率峰峰值、方向反转次数或极限环幅度；
- 错误相位锁定：相位误差已小，但功率显著低于 `P*`；
- 扫描开销：扫频期间的时间占比和能量损失进入比较。

## 5. 最终判断

忽略参考参数后，任务说明不是“方向错误”，而是“主线通过、验收口径有条件通过”。在正式报告中修订谐振判据、匹配比较条件、准稳态时间含义和保护硬限逻辑后，其余阶段安排符合当前项目要求。

当前不能写成“已经完成整个任务说明”。准确表述应为：

> 已完成项目边界冻结、非参数条款审核、自洽假设基线选择和裸BVD的LTspice/解析交叉验证；匹配网络、扰动、选频和控制器综合比较仍需基于活动模型重新执行。

# CTO超声换能器虚拟阻抗建模与自适应驱动控制：改动后项目总整理

生成日期：2026-08-18  
活动模型：MODEL_V2_1_HYPOTHETICAL  
适用范围：第一月虚拟电学建模、LTspice/Python交叉验证、扰动扫描、离散准稳态控制策略比较。  

## 1. 当前最终口径

本项目当前只讨论“小信号线性BVD等效电路 + L型匹配网络 + 虚拟扰动 + 离散准稳态控制”。没有实物换能器、功放、人体/动物实验，也没有声压、温升、空化或CTO开通效果结论。

所有数值必须标明来源类型：

- USER_CONSTRAINT：用户给定约束，例如0.8-1.0 MHz、0.9 MHz、100 Vpp、不超过160 Vpp、约5 mA。
- HYPOTHETICAL_BASELINE：为让仿真自洽而构造的假设基线，不代表真实器件。
- SCAN_VARIABLE：扰动扫描变量，例如C0、Rm、fs、匹配参数、ESR、Qm。
- DERIVED_VALUE：由上述数值计算得到的派生值。

主控制目标已经改为：在频率、电压和电流约束内最大化BVD运动支路电阻Rm吸收的有功功率P_Rm。相位不再被当作最终目标，只作为辅助观测或消融对照。

## 2. 已修正的关键问题

原先的参数口径存在物理冲突：若C0=25 pF、Rm=100 ohm、Qm=800且0.9 MHz正好为串联谐振，则100 Vpp端口电压会带来远大于5 mA的电流和瓦级以上功率，无法同时满足约7 kohm、5 mA和0.1 W量级。

v2.1已经改为从端口目标反推一个数学自洽的BVD假设基线：

|项目|v2.1取值|说明|
|---|---:|---|
|fs|0.9 MHz|假设基线|
|Vport|100 Vpp / 35.355 Vrms|用户约束与校准目标|
|Iport|5 mA RMS|用户约束，仍待实测确认口径|
|P_Rm|0.170 W|派生目标量级|
|S_port|0.1768 VA|由Vrms和Irms派生|
||Z_port||7.071 kohm|由Vrms/Irms派生|
|phase(Z)|-15.916 deg|假设偏容性端口相位|
|Rm|7.353 kohm|假设基线，非实测|
|C0|6.858 pF|假设基线，非实测|
|Qm|800，另跑500/1000|假设基线与敏感性变量|

因此，报告中不能再使用旧的“Rm=100 ohm且100 Vpp约5 mA”的说法。旧结果只能称为LEGACY或PRELIMINARY工作痕迹。

三种选频准则的关键结论：

- 最大功率点、最小绝对相位点、最小反射代理点不保证重合。
- 基线下最大功率点与最小反射点都在0.900 MHz附近，但最小绝对相位点约在0.907 MHz，且功率明显较低。
- 高组合扰动下最大功率点约0.855 MHz，而最小相位/最小反射可能在0.904 MHz附近，存在“相位看起来很好但功率很低”的错误锁定风险。

## 5. 控制策略的正式讲法

固定频率策略是基线：0.9 MHz不动，幅度请求a=1，保护状态机可以降幅。它用于证明扰动后不调频会损失功率。

周期局部扫频策略是当前最稳妥的工程方案：扰动后或周期到达时，用低幅度做局部扫频，先粗扫再细扫，最后选择P_Rm最大的频率锁定。优点是全局性比P&O强，缺点是扫描开销较大。

P&O最大功率跟踪是轻量在线优化方案：通过相邻频点试探判断功率上升方向，功率增加则保持方向，下降则反向并减小步长。它扫描点少，但需要处理窄峰、低幅探测时间和恢复判据之间的矛盾。

相位闭环不作为主策略：因为本项目已验证零相位不必然对应最大P_Rm。若保留相位控制，目标相位必须来自“最大功率点处的相位”，并用局部dphi/df修正符号；不能简单以0 deg为目标。

保护状态机：NORMAL -> SOFT_FOLDBACK -> HARD_TRIP -> RECOVERY_HOLD -> RAMP_UP -> NORMAL。非NORMAL状态冻结频率，先降幅再恢复；硬限采用命令施加前预测裁剪，因此实际硬越限次数必须为0。

## 9. 不能这样讲

不能说“已经完成结构-声场仿真”。只能说“结构-声场建模方案和后续截图清单已准备，尚未真实求解”。

不能说“该控制方法能提高CTO开通效果”。只能说“在特定假设BVD模型与扰动范围内，提高电学有功功率捕获或降低失配影响”。

不能说“这些是实测换能器参数”。必须说“这是根据100 Vpp、约5 mA和0.9 MHz目标构造的假设基线，等待实测阻抗后替换”。

不能说“相位为0就是最佳频率”。应说“相位是有用观测量，但最大功率、最小相位、最小反射在扰动下可能分离，本项目因此选择最大P_Rm作为主目标”。

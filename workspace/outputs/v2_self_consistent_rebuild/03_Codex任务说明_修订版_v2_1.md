# CTO超声换能器虚拟阻抗建模与自适应驱动控制——Codex任务说明（修订版v2.1）

修订日期：2026-08-14  
适用范围：第一月虚拟电学建模与离散准稳态控制验证  
活动模型：`MODEL_V2_1_HYPOTHETICAL`  
取代范围：取代此前任务说明中的物理判据、活动基线和控制验收口径；旧结果保留为 `LEGACY` 工作痕迹。

## 0. 项目边界（必须遵守）

- 本项目不涉及实物换能器、功放、人体或动物实验，不输出临床剂量、CTO开通效果或临床安全结论。
- 所有数值必须标注为以下身份之一：
  1. `USER_CONSTRAINT`：用户给定约束；
  2. `LITERATURE_REFERENCE`：文献参考值；
  3. `HYPOTHETICAL_BASELINE`：假设基线值；
  4. `SCAN_VARIABLE`：扫描变量；
  5. `DERIVED_VALUE`：由上述量计算得到的派生值。
- `USER_CONSTRAINT`不等同于已确认的器件额定值；`HYPOTHETICAL_BASELINE`不得写成实测参数。
- 禁止把临床、声学和电学三个层次的数值直接互相代入。COMSOL接口字段可以预留，但本阶段不计算声压、声强、温升或组织效应。
- 建模范围为小信号线性BVD等效电路和线性匹配网络；不模拟功放开关损耗、器件温升、介质非线性、空化和组织热效应。
- 所有结论限定为“特定BVD假设模型、匹配拓扑与扰动范围内的电学响应和虚拟控制性能”。

## 1. 项目目标和统一功率口径

建立可复现流程：

`裸BVD → L型匹配 → 单因素/组合扰动 → 三种选频准则 → 三种控制策略 → 统一综合比较`

主控制目标为：在频率、电压和电流约束内，最大化BVD运动支路电阻 `Rm` 吸收的有功功率：

\[
\max_f P_{Rm}(f,a),
\]

其中 `a` 为源幅度比例。三种主策略在NORMAL状态下均不得把 `a` 主动提高到基准校准值以上；保护状态机可以降低 `a`。因此比较重点是选频和恢复能力，而不是通过主动升压获得更高功率。

必须同时记录：

- `P_Rm`：运动支路有功功率，主控制指标；
- `P_port/Q_port/S_port`：换能器端口有功、无功和视在功率；
- `P_source`：源输出有功功率；
- `P_Rs`与匹配元件损耗；
- `eta_elec=P_Rm/P_source`，仅称电学功率分配或电学效率代理，不称电声效率。

## 2. 测量平面、符号和控制边界

| 项目 | v2.1定义 | 身份 |
|---|---|---|
| 控制器搜索范围 | 0.8–1.0 MHz | USER_CONSTRAINT |
| 初始工作点 | 0.9 MHz | USER_CONSTRAINT |
| 电压测点 | 换能器BVD端口；正弦稳态Vpp | 口径定义 |
| 电流测点 | 流入整个BVD端口的总电流；默认RMS | 口径定义+HYPOTHETICAL_BASELINE |
| 基准幅度 | 阶段二匹配冻结后，`a=1`在“活动BVD+活动匹配”基准的0.9 MHz校准为换能器端约100 Vpp | USER_CONSTRAINT+校准定义 |
| 电压保护 | 软触发130 Vpp；硬限160 Vpp | USER_CONSTRAINT/控制假设 |
| 电流参考 | 约5 mA RMS | USER_CONSTRAINT+待确认口径 |
| 电流保护 | 软触发5.5 mA RMS；硬限6 mA RMS | HYPOTHETICAL_BASELINE，非器件额定值 |
| 源阻抗 | 50 Ω | HYPOTHETICAL_BASELINE |

相位统一定义为换能器端口阻抗相位：

\[
\phi_Z=\arg\left(\frac{V_{port}}{I_{port}}\right).
\]

正相位表示感性，负相位表示容性。所有输出同时给出Hz/kHz/MHz、Vpp/Vrms、Arms/Apeak的明确单位。

## 3. 活动BVD假设基线

活动基线 `MODEL_V2_1_HYPOTHETICAL` 由目标端口量反推，仅用于虚拟仿真：

| 参数 | 数值 | 身份 |
|---|---:|---|
| `fs` | 0.9 MHz | HYPOTHETICAL_BASELINE |
| `C0` | 6.858064 pF | HYPOTHETICAL_BASELINE |
| `Rm` | 7.352941 kΩ | HYPOTHETICAL_BASELINE |
| `Qm` | 800 | HYPOTHETICAL_BASELINE |
| `Lm` | 1.040228 H | DERIVED_VALUE |
| `Cm` | 0.0300626 pF | DERIVED_VALUE |

该基线在0.9 MHz、换能器端100 Vpp时对应约5 mA RMS、0.170 W运动支路有功功率和0.1768 VA视在功率。它是数学自洽的假设，不代表真实换能器。

Qm敏感性至少运行500、800和1000三组；每组按以下关系重新计算 `Lm/Cm`，保持 `fs`和`Rm`不变：

\[
L_m=\frac{Q_mR_m}{2\pi f_s},\qquad
C_m=\frac{1}{(2\pi f_s)^2L_m}.
\]

此前0.125 W候选基线和所有旧模型结果均标记为 `LEGACY/PRELIMINARY`，不得与活动模型数据混表。

## 4. BVD特征频率的正确判据

不得预设以下频率完全相同：

- `fs`：运动支路串联谐振，`Im(Zm)=0`或运动支路电导最大；
- `fm`：总导纳幅值最大或总阻抗局部最小附近；
- `fr`：端口相位零点/总电纳为零的候选点；
- `fp/fa`：并联或反谐振候选点；
- 最大受约束 `P_Rm` 频率；
- 最小电学反射代理频率。

阶段一和后续场景必须分别计算这些点。相位没有过零时输出 `phase_zero_exists=false`，仍可输出最小绝对相位点。

“裸、无附加损耗BVD”定义为：保留表示机械阻尼的 `Rm`，不加入源附加寄生、匹配元件ESR和介质损耗；不得把 `Rm`设为零。

## 5. 扰动定义

### 5.1 单因素扰动

每个case只改变一个抽象独立变量，其他定义量按以下规则保持：

1. `fs_shift`：保持 `Rm`和`Qm`固定，根据目标 `fs`同步重算 `Lm/Cm`；这是频率漂移变量，不把伴随的元件重算计为第二扰动。
2. `C0_shift`：只改变 `C0`，运动支路参数固定。
3. `Rm_shift`：只改变 `Rm`，`Lm/Cm/C0`固定，因此Q变化是阻尼扰动的派生结果，必须记录。
4. `source_shift`：改变源阻抗；反射代理同时相对于实际源阻抗和固定50 Ω参考各输出一版。
5. `matching_shift`：分别改变匹配电感、匹配电容和元件ESR，不使用未展开的“小/中/大匹配偏差”标签。
6. `Qm_shift`：保持 `fs/Rm`固定，按第3节同步重算 `Lm/Cm`。

默认低/中/高幅度可以使用±5%/±10%/±20%，但必须在场景配置中写出实际方向和值。为与早期工作对照而保留的非对称档位应另建 `LEGACY_COMPATIBILITY` 场景组，不得混入正式趋势表。

### 5.2 组合扰动

至少建立低、中、高三种组合复杂度，每个场景包含两类以上扰动，并保存完整绝对参数快照。组合扰动用于验证控制器鲁棒性，不用于代替单因素因果结论。

### 5.3 每个场景输出

- `|Z|、Re(Z)、Im(Z)、phase(Z)`；
- `P_Rm、P_port、Q_port、|S_port|、P_source`；
- 电学反射代理及其参考阻抗；
- 主功率峰的频率、高度和FWHM；
- `fs/fm/fr/fp`等特征频率及存在状态；
- 固定0.9 MHz处的全部指标；
- 电压、电流的RMS、peak和Vpp口径。

FWHM默认定义为控制范围内主 `P_Rm` 局部峰相对零功率基线的半高宽。缺少左右半高交点、多峰歧义或峰位落在边界时，输出状态码而不是伪造峰宽。

## 6. 技术栈与执行方式

- 电路仿真：优先调用LTspice命令行 `-b` 运行 `.cir/.net/.asc`并保存`.raw/.log`。
- 解析模型：Python `numpy/scipy`计算复阻抗、复电压、复电流和复功率。
- 控制器与后处理：Python `numpy/scipy/matplotlib`；当前活动线不使用MATLAB，避免双轨维护。
- LTspice和Python能同时运行时必须对同一拓扑、同一源定义、同一测量点和同一频率网格交叉验证。
- Python离散控制可查表使用LTspice AC RAW，也可调用已交叉验证的解析模型；报告必须说明控制器不是LTspice瞬态闭环。

## 7. 分阶段执行与产出

### 阶段一：裸BVD验证

AC扫描0.5–1.5 MHz，保留 `Rm`，不加匹配与附加损耗。分别标注 `fs`、总阻抗局部最小、总导纳最大、全部相位零点和并联/反谐振候选点。

产出：

- `.cir/.raw/.log`；
- 全频和谐振区放大图；
- LTspice/解析逐点误差表；
- 特征频率表和RAW哈希。

### 阶段二：匹配网络

加入Thevenin源、源阻抗和明确拓扑的L型匹配网络。优化时先使用固定的归一化Thevenin源（例如1 Vrms），匹配前后使用相同源电压、源阻抗、频率网格和测量平面；匹配目标定义为相同源条件下基准频率附近 `P_Rm` 最大，同时报告源端反射代理。

活动匹配元件冻结后，再单独校准Thevenin源幅度，使活动BVD+活动匹配在0.9 MHz时的换能器端电压约为100 Vpp，并把该源幅度定义为控制阶段的 `a=1`。该源幅度随后在所有扰动场景和三种策略中保持一致，除非保护状态机执行foldback。不得一边改变匹配网络，一边重新校准到相同端电压后再比较功率，因为那会消除匹配比较的共同源条件。

先做理想匹配，再加入电感/电容ESR。不得沿用其他BVD模型的旧元件值。

产出：匹配前后阻抗、相位、`P/Q/S`和损耗同图对比；匹配参数优化记录；LTspice交叉验证。

### 阶段三A：扰动扫描

按第5节运行单因素、Qm敏感性和组合扰动，生成场景登记、逐频数据、特征汇总、固定0.9 MHz表和趋势表。

### 阶段三B：三种选频准则

在每个场景中比较：

1. 最大受约束 `P_Rm` 点；
2. 最小绝对端口阻抗相位点；
3. 最小电学反射代理点。

以高分辨率离线参考解为真值，比较不同步长和窗口造成的频率误差、功率损失和扫描点数。扫描时间=`点数×假设驻留时间`，必须标为仿真时间代理。

### 阶段四：三种控制策略与保护状态机

三种主策略均为离散准稳态循环：

1. `FIXED`：正常态固定0.9 MHz和基准源幅度；保护可以降幅。
2. `PERIODIC_SWEEP`：低幅度粗细两级局部扫频，选择受约束 `P_Rm` 最大点；扰动发生在扫描中时废弃本轮并重新开始。
3. `P_AND_O`：通过相邻频率试探比较 `P_Rm`，功率增加保持方向，下降则反向并缩小步长；包含死区、频率边界、持续低梯度判断和重新捕获扫描。

活动高Q模型的在线步长必须小于或经过验证不会跳过有效功率峰；建议从0.5 kHz细化到0.2和0.1 kHz。周期扫描可先粗扫再在候选点细扫，粗扫结果不得直接作为最终锁定频率。

纯相位闭环仅作为第四个消融对照。其目标相位取基准受约束最大功率点相位，控制符号通过局部 `dφ/df` 试探确定；不得把“扫描捕获+相位维持”简称为纯相位控制。

保护状态机：

`NORMAL → SOFT_FOLDBACK → HARD_TRIP → RECOVERY_HOLD → RAMP_UP → NORMAL`

执行顺序必须为：

`计算/读取当前响应 → 施加前硬限裁剪 → 更新保护状态 → 更新幅度 → 仅NORMAL态更新频率`

非NORMAL态冻结频率。硬保护时危险命令不得施加；分别记录硬限请求、命令裁剪和实际越限，实际越限必须为零。该软件保护仅是虚拟逻辑，不等同于真实硬件保护。

### 阶段五：统一综合比较

三种策略使用相同扰动场景、发生时刻、初始状态和随机种子。每个场景先离线求得受约束参考最优值 `P*、f*`。

正式指标：

- 稳态功率误差：`(P*−mean(Psteady))/P*`；
- 恢复时间：进入±2% `P*`并连续保持10个控制样本；
- 功率稳定性：稳态CV和峰峰值；
- 峰值过冲：相对新场景 `P*`；
- 锁定频率及相对 `f*`误差；
- 峰值端口电流、电压；
- 软折返、硬限请求、命令裁剪和实际越限次数；
- 频率边界饱和次数和持续时间；
- 振荡：稳态频率峰峰值和方向反转次数；
- 错误相位锁定：相位误差进入阈值但 `P_Rm<0.95P*`；
- 扫描开销：扫描时间占比和扫描期间能量损失。

恢复时间只适用于本次指定的控制周期、频点驻留时间和准稳态假设，不外推到真实硬件。

## 9. 验收标准

1. 活动模型裸BVD的 `fs` 与参数解析值误差小于1%；其他特征频率分别报告，不要求强制重合。
2. LTspice和Python在同一频率网格上的阻抗、相位和功率对齐；正式失败线为5%，线性同拓扑模型原则上应远小于该值。
3. 匹配前后比较使用相同源条件和测量平面，功率守恒误差可审计。
4. 每个单因素case只改变一个抽象变量，并保存其余参数快照。
5. 三种主策略和可选相位消融组使用同一扰动序列。
6. 三策略表至少包含稳态误差、恢复时间、功率稳定性、过冲、锁定频率、峰值电流、保护事件和频率饱和。
7. 实际电压/电流硬限越限次数为零；若使用事后采样模型而不能保证，应明确判FAIL，不得只统计跳闸。
8. 所有图表可追溯到活动配置、生成脚本和源数据。
9. 报告不出现超出第0节边界的结论。

# v2.1第三步：三种扫频选点准则与步长/窗口比较

## 初始设置

- 扫频范围：0.84-0.96 MHz；步长：0.5 kHz；每点时间代理：1.5 ms。
- 三种准则：最大运动支路有功、最小绝对输入相位、最小反射代理。

## 基准场景结果

- 最大功率频率：0.900000 MHz。
- 最小绝对相位频率：0.907000 MHz。
- 最小反射频率：0.900000 MHz。

三个指标分别定义并输出，不能把相位零点直接当成功率最大点。

## 精度与扫描时间

以全部28个活动场景、全局10 Hz参考网格为验收基准，满足窗口不漏掉最大功率点且离散误差不超过0.5 kHz的最快组合为：±50 kHz窗口、1.0 kHz步长，101点，扫描时间代理约151.5 ms。

窗口误差和步长误差必须分开：步长决定局部离散误差；窗口过窄会完全漏掉漂移后的全局最优点。
当前结果只适用于活动v2.1线性模型与所列扰动范围。

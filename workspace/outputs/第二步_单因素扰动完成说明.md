# 第二步：单因素扰动完成说明

## 1. 本步目的

组合扰动只能说明系统在多参数同时偏离时会失配，但不能拆分“是谁导致的”。本步采用单因素扰动：每个非基准场景只主动改变一个参数，其余 BVD、源阻抗和匹配网络参数保持基准值。

模型边界：所有参数均为当前虚拟 BVD 电学模型中的假设基线值或扫描变量，不代表实测换能器，也不能直接推导声学输出、组织温升、空化阈值或 CTO 临床效果。

## 2. 扰动场景

共 21 个场景：1 个基准 + 20 个单因素扰动。

| 类别 | 单因素等级 |
|---|---|
| C0 | +10%、+20%、+30% |
| Rm | +15%、+30%、+50% |
| fs | −1%、−3%、−5%；通过只改变 Cm 实现 |
| 源阻抗 Rs | +5%、+10%、+20% |
| 匹配电感 Ls | +2%、+5%、+10% |
| 匹配电容 Cp | −2%、−5%、−10% |
| 电感损耗 Q | 基准 Q=100，扰动 Q=50、Q=20 |

说明：用户提出的“源/匹配网络小、中、大参数偏差”已拆成 Rs、Ls、Cp 三个单因素系列；这样比把匹配网络合成一个小/中/大片段更能回答“谁导致的”。电感损耗单独用 Q 表示。

## 3. 每个场景输出指标

每个场景均输出：

- 逐频指标：|Z|、ReZ、ImZ、相位、有功功率、反射代理；
- 固定 0.9 MHz 指标：|Z|、ReZ、ImZ、相位、有功功率、功率下降比例、反射代理、换能器 Vpp、BVD 端总峰值电流、运动支路峰值电流、源侧峰值电流、匹配损耗；
- 峰值特征：功率峰值频率、峰值高度、FWHM 峰宽、95% 峰宽、输入阻抗极值频率、相位零点/最小相位频率、最小反射代理频率。

## 6. 主要结论

1. C0 在当前虚拟 BVD + 固定低通 L 型匹配口径下影响最小，主要造成轻微相位/静电支路变化，峰位、峰高和峰宽变化都很弱。
2. Rm 主要改变能量耗散能力，因此峰高下降、峰宽变宽；峰位基本不移动。
3. fs 漂移是峰位移动的主导因素；固定 0.9 MHz 工作时，一旦真实谐振点偏离，功率和匹配状态会快速恶化。
4. Ls 与 Cp 属于匹配网络核心参数，会同时影响峰位、峰高、峰宽和反射代理。
5. Rs 改变源侧加载条件，峰位变化不大，但固定源幅值下功率传递会明显变化。
6. Q 降低等价于电感 ESR 增大，主要吃掉可传递功率；在本模型里对峰高影响非常强。

## 7. 建议审核顺序

1. 先看 `单因素扰动_参数登记.csv`，确认每个 case 只主动改变一个参数。
2. 再看 `单因素扰动_固定0p9MHz指标.csv`，核查固定工作点下全部指标。
3. 再看 `单因素扰动_特征汇总.csv`，核查峰值频率、峰高和 FWHM。
4. 用 `单因素扰动_趋势表.csv` 形成报告里的趋势表。
5. 最后看 `LTspice_解析交叉验证.csv`，确认解析模型与 LTspice 日志一致。

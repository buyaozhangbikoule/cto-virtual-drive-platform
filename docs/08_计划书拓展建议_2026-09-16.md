# 围绕计划书目标的拓展建议

2026-09-16。导师：「计划书的安排也不一定正确，围绕着计划书想做的东西可以适当拓展一些思路」。

区分两件事：**计划书想做什么**，和**计划书安排了什么**。

想做的（第二章核心问题）：
> 当换能器的等效谐振频率、静态电容或机械支路损耗因负载变化而漂移时，
> 能否利用虚拟测得的电压、电流和相位信息，自动调整驱动频率或幅度，
> 使电学有功功率和匹配状态保持在合理范围？

这个目标没有问题。有问题的是为达成它所做的**安排**。下面四条，前三条有计算，后两条是提议。

## 一、扰动等级比应用真正隐含的小一个量级〔有计算〕

计划书第三章立了一条很严的规矩：

> 不能缺少实验或多物理场依据地把其中一个层次的数值直接代入另一个层次。

**规矩本身是对的，但在这里用过头了。** 辐射阻抗不是需要实验才能得到的量，
它是解析结果 `Q_rad = π·Z_piezo/(2·Z_medium)`。用公开的组织声阻抗算 Rm，
属于「**有**多物理场依据」，不是把临床参数硬塞进电路。

于是扰动档位可以推出来，而不是取 ±15/30/50% 这种整数：

| 声学负载 | Z (MRayl) | Q_rad | Qm | Rm / 血液 | FWHM |
|---|---|---|---|---|---|
| 空气/气泡（空化或失接触） | 0.0004 | 129591 | 64.97 | **0.32×** | 12.3 kHz |
| 脂质斑块 | 1.38 | 37.6 | 23.81 | 0.89× | 33.6 kHz |
| **血液（基线）** | 1.66 | 31.2 | 21.09 | 1.00× | 37.9 kHz |
| 组织化血栓 | 1.70 | 30.5 | 20.76 | 1.02× | 38.5 kHz |
| 纤维斑块 | 1.90 | 27.3 | 19.22 | 1.10× | 41.6 kHz |
| 钙化斑块 | 7.00 | 7.4 | 6.65 | **3.17×** | 120.3 kHz |

- 计划书最大档 **1.50×**，由声阻抗推出的范围 **0.32× – 3.17×**
- 顶到钙化斑块时 Rm 是血液的 3.17 倍，**登记表最大只做到 1.5 倍，小了 2.1 倍**
- 反方向更极端：**失去接触（空化气泡包裹换能器）** Rm 降到 0.32×、Qm 冲到 65、
  峰宽收窄 3.1 倍。**这一档计划书里完全没有**，而对一个靠空化工作的器件，
  气泡包裹是常态而非异常

**建议**：把扰动档位从「±百分数」改为「组织类型」，每一档都能说出物理出处。
这既满足计划书自己的参数原则（有依据），又让扰动覆盖真实范围。

## 二、虚拟传感器无噪声〔**已按正确口径重做**〕

> **2026-09-16 重做。** 本节初稿把噪声直接加在 `p_rm_W` 上，违反项目自己的口径登记：
> `docs/03`「P_source、P_port、P_Rm **测点不同**」「主控制与离线图常用 P_Rm，
> **真实反馈页使用 RAW 端口 P_port**」。真实系统测不到功率——它测**电压和电流**再算功率。
> 复现：`python3 workspace/sensor_noise_20260916/noise_model.py`

正确的测量链模型：

```
P_port = |V|·|I|·cos(φ)        φ = arg(v_port / i_port) = arg(z_bvd)
dP/P   = n_V + n_I − tan(φ)·n_φ
```

最后一项在「直接给功率加噪声」时**完全看不到**。恒等式已核对：
`|V||I|cos(φ) = 176.800000 mW`，与模型的 `P_port` 逐位一致。

**先要分清测哪个节点**（`docs/03` 第 3 条已登记该口径）：v3 基线在 f0 处
端口相位 `arg(z_bvd) = −14.80°`，而功放输入端 `arg(z_in) = −0.64°`。**不是一回事。**

### 新暴露的机制：相位误差被 tan(φ) 放大

| 频率 | 端口相位 | 每 1° 相位误差 → 功率误差 |
|---|---|---|
| 650 kHz | −87.78° | **44.95%** |
| 750 kHz | −78.26° | 8.40% |
| **800 kHz（工作点）** | −14.80° | 0.46% |
| 900 kHz | −69.62° | 4.70% |

在谐振点 φ 小、无关紧要；**偏离谐振时 tan(φ) 发散**。
而 P&O 在峰顶走一个 0.5 kHz 步长的信号只有 **0.0177%**——
同处 1° 相位误差造成 0.4613% 误差，**噪信比 26:1**。

### 但后果比这个数字温和——两项都验过

**P&O 蒙特卡洛**（每档 40 次独立运行）：

| 幅度噪声 | 相位噪声 | 新口径 捕获 | 新口径 频率std | 旧口径 捕获 | 旧口径 频率std |
|---|---|---|---|---|---|
| 0.1% | 0.1° | 99.93% | 0.95 kHz | 99.94% | 0.88 kHz |
| 0.1% | 1.0° | 99.75% | **1.85 kHz** | 99.95% | 0.84 kHz |
| 1.0% | 2.0° | 99.27% | 3.03 kHz | 99.31% | 3.11 kHz |

**三级扫描**（v3 推荐阶梯，每档 200 次）：

| 幅度噪声 | 相位噪声 | 平均捕获 | P5 | 最差 |
|---|---|---|---|---|
| 0.1% | 1.0° | 99.87% | 98.16% | 98.16% |
| 1.0% | 2.0° | 99.19% | 98.16% | 93.10% |
| 1.0% | 5.0° | 97.47% | 85.73% | 85.73% |
| 2.0% | 10.0° | 92.48% | 77.14% | 20.96% |

**扫描没有被 tan(φ) 放大带偏**，原因是：放大最严重的地方绝对功率也最小。
650 kHz 处功率只有峰值的 5.1%，即使误差 45% 也只有 7.4%，抬不到峰之上。
要到 5–10° 相位噪声才真正塌，那已超出像样测量链的水平。

### 口径修正改变了什么、没改变什么

- **没改变的**：本节的主结论——**在宽峰上「功率捕获率」失去分辨力**。
  两种口径下捕获率都是 99%+，第 4 周的策略对比仍会得出空结果。
- **改变的**：频率离散度。正确口径下在 0.1% 幅度 + 1° 相位时是 1.85 kHz，
  旧口径只有 0.84 kHz——**旧做法低估了 2.2 倍**。
- **新增的**：tan(φ) 放大这一整项机制，以及下面这条。

### 附带发现：SCBC 还治这个

| | 端口相位 @ f0 | tan(φ) | 1° 相位误差 → 功率误差 |
|---|---|---|---|
| 不补偿 | −14.80° | 0.2643 | 0.461% |
| 加 L0 = 22.87 µH | **−0.00°** | **0.0000** | **0.000%** |

补偿把工作点的 tan(φ) 降低 **4 个数量级**，功率测量对相位误差的敏感度同比下降。

**这是 SCBC 的第二项收益，与「消除伪锁定」相互独立，先前未识别**（见 `docs/07` C 节）。
它使 SCBC 的性价比明显高于原先的评估：一个 22.87 µH 的并联电感同时买到
相位判据单解化**和**功率测量的相位免疫。

## 三、模型只有辐射电阻，缺辐射电抗〔有计算〕

现模型把辐射损耗折进 `Qm = 1/(1/Qm_mat + 1/Q_rad)`，这只是辐射阻抗的**实部**。
虚部（附加质量）改变等效 Lm，从而**移动 fs**。模型里完全没有这一项。

用无限障板圆形活塞的经典结果 `Z_rad = ρcA[R1(2ka) + j·X1(2ka)]` 估量级：

| 声学负载 | ka | X1/R1 | 附加质量比 | Δfs/fs | Δfs |
|---|---|---|---|---|---|
| 脂质斑块 | 2.34 | 0.349 | 0.009 | −0.46% | −3.7 kHz |
| 血液（基线） | 2.20 | 0.411 | 0.013 | −0.65% | −5.2 kHz |
| 纤维斑块 | 2.12 | 0.452 | 0.017 | −0.82% | −6.6 kHz |
| 钙化斑块 | 1.13 | 1.309 | 0.177 | −7.82% | **−62.5 kHz** |

**血液 → 钙化斑块的附加 fs 偏移约 −57 kHz。**

参照：v3 的粗扫半宽是 ±80 kHz，登记表里最大的 fs 扰动（`CASE_FS_M5`）是 −40 kHz。
**这一项与最大的已建模扰动同量级甚至更大，而模型完全无法表达它。**

⚠️ 不要过度解读：
- 该式是无限障板圆形活塞的经典结果；本器件是 31 模空心圆柱、端面为环形、
  内外侧壁也接触流体。这是**量级估计**，不是该几何的精确解。
- 钙化的 ka=1.13 落在活塞公式精度较差的区间，且 X1/R1>1，一阶近似不适用；
  表中已改用精确式 `1/√(1+m)−1`。即便如此绝对值仍应看作**上界性估计**。
- 要得到可用数值需 COMSOL 声固耦合或实测。

但方向是稳的：**X1 与 R1 同阶，模型只取 R1，这是结构性缺项而非精度问题。**

**建议**：BVD 增加一个随声学负载变化的 `ΔLm` 项，与 Rm 一同由组织类型驱动。
这不增加自由参数——两者来自同一个辐射阻抗，只是现在只用了一半。

## 四、缺「扰动速率」这一维〔提议〕

计划书的扰动有**幅度**三档（低/中/高），没有**速率**。
现有实现是 7 段阶跃，每段 0.8 s。

但对一个频率跟踪器，真正的工程指标是**跟踪带宽**——它能跟上多快的变化。
阶跃是最坏情况，不是典型情况；导管推进过程中负载是连续变化的。

**建议**：加一维扫描——`dfs/dt` 从 0 扫到跟踪失败为止，对每种策略得出
「最大可跟踪速率」。这比「在某一条 7 段日程上谁得分高」有用得多，
而且是可迁移的器件指标。这也正好给第 4 周的「恢复时间」一个连续版本。

## 五、热模型的自相矛盾〔提议〕

计划书第一章明确排除「器件温升」。但：
- 电流上限的物理依据**就是**发热
- 占空比（文献器件 9.1%）直接决定这个上限松紧

于是模型里有一条限值，它的物理基础被计划书显式排除在外。这是个自洽性问题。

**建议**：加一个最小热模型——单时间常数、`ΔT = P_loss × R_th × (1 − e^(−t/τ_th))`，
两个参数。它不需要有限元，但能：
- 把电流限值和占空比连起来，让 5 mA 有可检验的含义
- 让「脉冲 vs 连续波」成为可比较的设计变量，而不是未声明的默认

## 六、总论：低 Q 器件上，控制问题的重心不在频率

把前面几条串起来，会得到一个与计划书隐含假设不同的结论。

计划书的三种策略**全部只调频率**。这在高 Q 器件上是对的——峰窄，跑掉一点就掉很多功率。
但一个真实的血管内器件是**重辐射负载、低 Q** 的（Qm≈21，辐射损耗比材料损耗还大），
于是：

| | 高 Q 器件 | 低 Q 器件（本项目） |
|---|---|---|
| 峰宽 | 2 kHz | 74 kHz |
| 频率跟踪的价值 | 高，跑一点就掉功率 | 低，宽峰自己容错 |
| 组织变化改的主要是 | fs | **Rm（0.32×–3.17×）** |
| 三种策略的区分度 | 大 | **几乎没有（都 99%+）** |
| 真正难的是 | 追频率 | **追电阻 / 保匹配** |

支持这个判断的三条独立证据（都已算过）：
1. v3 扰动表：固定频率下 8/34 场景 VSWR 超 3:1；频率跟踪把 **9/9 个纯频率漂移场景全部修好**，
   但对 **8 个电阻漂移场景一个都修不了**（`workspace/disturbance_v3_20260916/`）
2. 本文第一节：组织变化主要改 Rm（10 倍范围），而不是 fs
3. 本文第二节：在宽峰上功率捕获指标失去分辨力

**建议**：把「自适应匹配」从可选项提升为**与三种频率策略并列的第四种策略**，
并把评价指标从功率捕获改为反射/匹配质量。这不是推翻计划书的目标，
恰恰是为了达成它——计划书要的是「有功功率**和匹配状态**保持在合理范围」，
匹配状态那一半目前没有任何策略在管。

## 七、改动优先级

| | 改什么 | 依赖 | 工作量 |
|---|---|---|---|
| 1 | 扰动档位改为组织类型驱动 | 无，公开声阻抗即可 | 小 |
| 2 | 评价指标加反射/VSWR，功率捕获降为辅助 | 无 | 小 |
| 3 | 给虚拟传感器加噪声模型 | 无 | 小 |
| 4 | BVD 加辐射电抗项 ΔLm | 无（但数值需 COMSOL/实测确认） | 中 |
| 5 | 自适应匹配升为第四种策略 | 无 | 中 |
| 6 | 加扰动速率维度 | 无 | 中 |
| 7 | 最小热模型 | 需要占空比 | 中 |

前三项都不依赖任何实测，且都能立刻改变结论的可信度。

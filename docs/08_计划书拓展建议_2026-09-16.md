## 一、〜〜扰动等级比应用真正隐含的小一个量级〜〜**结论已撤回**

> **2026-09-17 撤回。** 原结论「计划书的扰动档比应用真正隐含的小 2.1 倍」
> 建立在钙化斑块 `Z = 7.00 MRayl` 上，而**这个数我没有出处**——多半是拿了皮质骨（约 7.8 MRayl）。
> 扫描声学显微镜的**实测值是 2.23 ± 0.09 MRayl**
> （[Sci Rep 2018, s41598-018-32788-2](https://www.nature.com/articles/s41598-018-32788-2)）。

### 公式本身是真的（已自行推导验证）

`Q_rad = π·Z_piezo/(2·Z_medium)` 不是我编的，可以从能量推出来：

```
半波厚度模、单面辐射、另一面空气背衬：
  位移 u = u0·sin(kx)·cos(ωt)，kL = π（端面为波腹）
  峰值动能 W = ∫(1/2)ρA v²dx = ρAω²u0²L/4
  单面辐射功率 P = (1/2)·Z_m·A·(ωu0)²
  Q = ωW/P = ωρL/(2Z_m)，代入半波条件 ω = πc_p/L
  => Q = π·ρc_p/(2Z_m) = π·Z_piezo/(2·Z_medium)   ✓
```

**【此处为模糊推测内容】**：推导条件是半波厚度模、单面辐射、空气背衬。
本器件是 31 模空心圆柱、三次谐波、**两个环形端面加内外两个柱面**都接触流体。
辐射面由 1 个变约 4 个（Q_rad 应更低），但三次谐波储能是半波的 3 倍（Q_rad 应更高）——
**两个方向相反，我无法解析定出净效应。**

**实测组织范围是 1.00× – 1.23×，完全落在计划书的 ±15/30/50% 之内。**
**计划书的档位对组织变化是够的**，我原先的批评不成立。

### 还剩下什么

   含气液体的等效阻抗是复数、随频率变，且取决于气泡密度与驱动频率相对气泡共振的位置，
   **可能低于也可能高于液体**。在有可靠的气泡云等效阻抗之前，
   这一档只是"值得注意的方向"，不是可用的数值。

## 二、虚拟传感器无噪声〔**已按正确口径重做**〕

> **2026-09-16 重做。** 本节初稿把噪声直接加在 `p_rm_W` 上，违反项目自己的口径登记：
> `docs/03`「P_source、P_port、P_Rm **测点不同**」「主控制与离线图常用 P_Rm，
> **真实反馈页使用 RAW 端口 P_port**」。真实系统测不到功率——它测**电压和电流**再算功率。
> 复现：`python3 workspace/sensor_noise_20260916/noise_model.py`

正确的测量链模型：

```
P_port = |V|·|I|·cos(φ)        φ = arg(v_port / i_port) = arg(z_bvd)
dP/P   = n_V + n_I − tan(φ)·n_φ
```

最后一项在「直接给功率加噪声」时**完全看不到**。恒等式已核对：
`|V||I|cos(φ) = 176.800000 mW`，与模型的 `P_port` 逐位一致。

**先要分清测哪个节点**（`docs/03` 第 3 条已登记该口径）：v3 基线在 f0 处
端口相位 `arg(z_bvd) = −14.80°`，而功放输入端 `arg(z_in) = −0.64°`。**不是一回事。**

### 新暴露的机制：相位误差被 tan(φ) 放大

| 频率 | 端口相位 | 每 1° 相位误差 → 功率误差 |
|---|---|---|
| 650 kHz | −87.78° | **44.95%** |
| 750 kHz | −78.26° | 8.40% |
| **800 kHz（工作点）** | −14.80° | 0.46% |
| 900 kHz | −69.62° | 4.70% |

在谐振点 φ 小、无关紧要；**偏离谐振时 tan(φ) 发散**。
而 P&O 在峰顶走一个 0.5 kHz 步长的信号只有 **0.0177%**——
同处 1° 相位误差造成 0.4613% 误差，**噪信比 26:1**。

### 但后果比这个数字温和——两项都验过

**P&O 蒙特卡洛**（每档 40 次独立运行）：

| 幅度噪声 | 相位噪声 | 新口径 捕获 | 新口径 频率std | 旧口径 捕获 | 旧口径 频率std |
|---|---|---|---|---|---|
| 0.1% | 0.1° | 99.93% | 0.95 kHz | 99.94% | 0.88 kHz |
| 0.1% | 1.0° | 99.75% | **1.85 kHz** | 99.95% | 0.84 kHz |
| 1.0% | 2.0° | 99.27% | 3.03 kHz | 99.31% | 3.11 kHz |

**三级扫描**（v3 推荐阶梯，每档 200 次）：

| 幅度噪声 | 相位噪声 | 平均捕获 | P5 | 最差 |
|---|---|---|---|---|
| 0.1% | 1.0° | 99.87% | 98.16% | 98.16% |
| 1.0% | 2.0° | 99.19% | 98.16% | 93.10% |
| 1.0% | 5.0° | 97.47% | 85.73% | 85.73% |
| 2.0% | 10.0° | 92.48% | 77.14% | 20.96% |

**扫描没有被 tan(φ) 放大带偏**，原因是：放大最严重的地方绝对功率也最小。
650 kHz 处功率只有峰值的 5.1%，即使误差 45% 也只有 7.4%，抬不到峰之上。
要到 5–10° 相位噪声才真正塌，那已超出像样测量链的水平。

### 口径修正改变了什么、没改变什么

- **没改变的**：本节的主结论——**在宽峰上「功率捕获率」失去分辨力**。
  两种口径下捕获率都是 99%+，第 4 周的策略对比仍会得出空结果。
- **改变的**：频率离散度。正确口径下在 0.1% 幅度 + 1° 相位时是 1.85 kHz，
  旧口径只有 0.84 kHz——**旧做法低估了 2.2 倍**。
- **新增的**：tan(φ) 放大这一整项机制，以及下面这条。

### 附带发现：SCBC 还治这个

| | 端口相位 @ f0 | tan(φ) | 1° 相位误差 → 功率误差 |
|---|---|---|---|
| 不补偿 | −14.80° | 0.2643 | 0.461% |
| 加 L0 = 22.87 µH | **−0.00°** | **0.0000** | **0.000%** |

补偿把工作点的 tan(φ) 降低 **4 个数量级**，功率测量对相位误差的敏感度同比下降。

**这是 SCBC 的第二项收益，与「消除伪锁定」相互独立，先前未识别**（见 `docs/07` C 节）。
它使 SCBC 的性价比明显高于原先的评估：一个 22.87 µH 的并联电感同时买到
相位判据单解化**和**功率测量的相位免疫。

## 三、模型只有辐射电阻，缺辐射电抗〔**事实成立，量级已大幅下修**〕

## 四、缺「扰动速率」这一维〔提议〕

计划书的扰动有**幅度**三档（低/中/高），没有**速率**。
现有实现是 7 段阶跃，每段 0.8 s。

但对一个频率跟踪器，真正的工程指标是**跟踪带宽**——它能跟上多快的变化。
阶跃是最坏情况，不是典型情况；导管推进过程中负载是连续变化的。

**建议**：加一维扫描——`dfs/dt` 从 0 扫到跟踪失败为止，对每种策略得出
「最大可跟踪速率」。这比「在某一条 7 段日程上谁得分高」有用得多，
而且是可迁移的器件指标。这也正好给第 4 周的「恢复时间」一个连续版本。

## 五、热模型的自相矛盾〔提议〕

计划书第一章明确排除「器件温升」。但：
- 电流上限的物理依据**就是**发热
- 占空比（文献器件 9.1%）直接决定这个上限松紧

于是模型里有一条限值，它的物理基础被计划书显式排除在外。这是个自洽性问题。

**建议**：加一个最小热模型——单时间常数、`ΔT = P_loss × R_th × (1 − e^(−t/τ_th))`，
两个参数。它不需要有限元，但能：
- 把电流限值和占空比连起来，让 5 mA 有可检验的含义
- 让「脉冲 vs 连续波」成为可比较的设计变量，而不是未声明的默认

## 六、总论：低 Q 器件上，控制问题的重心不在频率

> **2026-09-17 注**：本节原先列的三条证据里，第 2 条（组织变化主要改 Rm，10 倍范围）
> **已随第一节一同撤回**——实测组织范围只有 1.00×–1.23×。
> 本节结论现在只剩两条证据支撑：v3 扰动表的实测（频率跟踪修好 9/9 个频率漂移场景、
> 0/8 个电阻漂移场景），以及第二节的宽峰指标失效。
> **这两条都不依赖组织声阻抗，仍然成立**，但"重心转移"的论证强度比原文弱。

把前面几条串起来，会得到一个与计划书隐含假设不同的结论。

计划书的三种策略**全部只调频率**。这在高 Q 器件上是对的——峰窄，跑掉一点就掉很多功率。
但一个真实的血管内器件是**重辐射负载、低 Q** 的（Qm≈21，辐射损耗比材料损耗还大），
于是：

| | 高 Q 器件 | 低 Q 器件（本项目） |
|---|---|---|
| 峰宽 | 2 kHz | 74 kHz |
| 频率跟踪的价值 | 高，跑一点就掉功率 | 低，宽峰自己容错 |
| 组织变化改的主要是 | fs | **Rm（实测 1.00×–1.23×）** |
| 三种策略的区分度 | 大 | **几乎没有（都 99%+）** |
| 真正难的是 | 追频率 | **追电阻 / 保匹配** |

> **2026-09-17 注**：上表「Rm」一栏原写 0.32×–3.17×，依赖已撤回的 7.0 MRayl，现改为实测值 1.00×–1.23×。方向仍成立但幅度小得多：相对各自的登记档位，Rm 变化用掉了计划书 Rm 区间的 46%，fs 变化（辐射电抗 −5.3 kHz）只用掉 fs 区间的 13%，即组织变化对 Rm 的影响约为对 fs 的 3.5 倍——不是原文暗示的一个数量级。

支持这个判断的证据（都已算过）：
1. v3 扰动表：固定频率下 8/34 场景 VSWR 超 3:1；频率跟踪把 **9/9 个纯频率漂移场景全部修好**，
   但对 **8 个电阻漂移场景一个都修不了**（`workspace/disturbance_v3_20260916/`）
2. ~~本文第一节：组织变化主要改 Rm（10 倍范围）~~ **已撤回**——实测只有 1.00×–1.23×
3. 本文第二节：在宽峰上功率捕获指标失去分辨力

**建议**：把「自适应匹配」从可选项提升为**与三种频率策略并列的第四种策略**，
并把评价指标从功率捕获改为反射/匹配质量。这不是推翻计划书的目标，
恰恰是为了达成它——计划书要的是「有功功率**和匹配状态**保持在合理范围」，
匹配状态那一半目前没有任何策略在管。

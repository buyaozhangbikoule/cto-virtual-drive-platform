## 〇、驱动源：我提出的「阻塞性矛盾」不成立，已撤回

> **本节于 2026-09-16 整节改写。** 原文断言 `100 Vpp / 5 mA` 与「50 Ω 射频功放」
> 互不相容、很可能是两台仪器，并把它列为**阻塞性**问题。**该断言是错的，已撤回。**

错在把**功放的输出电流**与**换能器的电流**当成了同一个量。两者隔着匹配网络，
而匹配网络的本职工作就是做电流/电压变换。实算 v2.1 基线：

| | 电压 | 电流 |
|---|---|---|
| 功放侧（50 Ω 一侧） | 3.37 Vrms = 9.53 Vpp | **59.4 mA** |
| 换能器侧（7 kΩ 一侧） | 36.06 Vrms = **101.98 Vpp** | **5.10 mA** |

电流变换比 11.65:1，电压变换比 10.70:1。

更直接的证据：v2.1 在它自己的标称幅度 `a1 = 1.0`（stage2 冻结的校准点）上，
换能器端正好是 **100.00 Vpp / 5.000 mA**，功放端同时是 **58.27 mA**。
**原项目从一开始就是按这个建的，两个描述完全自洽。**

「5 mA 在 50 Ω 上只有 1.25 mW，不叫功率放大器」这句话本身没错，
但它问的是个错问题——那 5 mA 从来不是功放侧的电流。

### 仍然值得问、但不阻塞的那个问题

5 mA 是换能器端在 7 kΩ 工作点上的电流。真正该问的是它的**性质**：

- 若是「那台器件在该工作点上恰好抽这么多电流」→ 它是一次测量结果，
  换几何后不适用，需要重新测。
- 若是「器件耐受上限」（发热/机械应力）→ 它应当先被改写成与几何无关的量
  （电流密度，或单位体积耗散功率），才能搬到别的几何上。

这个区分影响的是**换几何时该怎么迁移这条限值**，不影响当前方案能否成立。
优先级：中，不是阻塞。

### 附：为什么我会犯这个错

今天这是第三次同型错误。三次都是——**看到一个大比值就当成不可行的证据，
而没有算中间的网络做了什么**：

1. 「7085 Ω 与 50 Ω 差 142 倍，无法匹配」——没算 L 匹配（实际 Γ = 0.0635）
2. 「宽峰判符号需 85 dB，比窄峰高 61 dB」——没算功率后果（3% 噪声下仍 99%）
3. 「换能器 5 mA 与功放安培级差 12 倍，互不相容」——没算匹配网络的变换比

比值本身从来不是不可行性的证明。**下断言之前先把中间那一级算出来。**

## 一、算法的物理审核

### A.〜〜准稳态假设从未被校验，v2.1 下裕量只有 1.15 倍〜〜**已推翻，撤回**

> **2026-09-16 整条撤回。** 原文用手算 `tau = Qm/(pi*f0)` 得 283 µs，
> 称 1.5 ms 驻留只有 5.3 个时常数、裕量 1.15 倍、残余误差 0.5%。**全部不成立。**

**错在一个具体的物理点：瞬态由整个驱动回路的【有载 Q】决定，不是换能器的【空载 Qm】。**
50 Ω 源阻抗与匹配网络 ESR 都在给谐振器加阻尼。把电路写成状态空间取本征值：

| | 原 finding | 实际 |
|---|---|---|
| tau | 283 µs（用空载 Qm=800） | **148.5 µs** |
| 有载 Q | —（未考虑） | **420**，约为空载 Qm 的一半 |
| 1.5 ms 驻留 | 5.3 tau | **10.1 tau** |
| 理论残余 | 0.5% | **0.004%** |

线性系统的阶跃换频响应有闭式解——恰好是「新旧稳态之差」的自由衰减
`x(t) = e^(At)·(x_ss(f1) − x_ss(f2)) + x_ss(f2)(t)`，不需要数值积分。实算四种阶跃：

| 阶跃情形 | 幅度阶跃 | 测得/稳态 | 误差 |
|---|---|---|---|
| 粗扫逼近峰 895→900 kHz | 79.35% | 0.99949 | −0.051% |
| 粗扫越过峰 900→905 kHz | 376.77% | 1.00056 | +0.056% |
| 细扫近峰 899→900 kHz | 26.94% | 0.99963 | −0.037% |
| 终扫近峰 899.9→900 kHz | 0.43% | 0.99975 | −0.025% |

**实测误差 0.03–0.06%。准稳态假设成立，且裕量充裕。**

### A′. 这个检查在什么条件下才真的会失效（保留为登记项）

推翻了结论，但检查本身值得留着——只是阈值远比原文说的宽：

| 空载 Qm | 有载 tau | 1.5 ms 驻留 | 残余 | 判定 |
|---|---|---|---|---|
| 400 | 73.3 µs | 20.5 tau | 0.0000% | 充裕 |
| 800 | 148.5 µs | 10.1 tau | 0.0041% | 充裕 |
| 1600 | 298.9 µs | 5.0 tau | 0.66% | 勉强 |
| 3200 | 599.5 µs | 2.5 tau | 8.19% | 不足 |

阈值在空载 Qm ≈ 1600。但对浸入血液的换能器，**辐射负载单独就把 Qm 压到 31 以下**
（见 `workspace/plan_extensions_20260916/`），所以这个条件在本项目的参数范围内**不可达**。

建议：把「驻留 ≥ 7 × 有载 tau」作为登记表里的一条断言，用**有载 tau**（由状态空间本征值求，
不是手算 Qm/(πf₀)）。它当前恒成立，作用是防止将来改源阻抗或匹配网络时静默失效。

验证脚本：`workspace/algorithm_physics_audit_20260916/transient_check.py`

### B. P&O 跨扰动时方向判断失效，且步长在最该放大时坍缩 〔高〕

P&O 在 `f` 上测参考、在 `f+step` 上测探测，两点相隔 40 ms。
若其间负载变化，它会把**负载变化**读成**自己这一步的结果**。

在 7 段日程的每个边界上模拟这一情形：

| 边界 | 最优点实际移动 | P&O 读到 | 方向对吗 |
|---|---|---|---|
| BASELINE → C0_P30 | 不动 | 下降 | 否 |
| C0_P30 → RM_P50 | 不动 | 下降 | 否 |
| RM_P50 → FS_M5 | 降频 | 下降 | 是 |
| FS_M5 → LMATCH_P10 | 升频 | 下降 | 否 |
| LMATCH_P10 → QL_20 | 降频 | 下降 | 是 |
| QL_20 → COMBINED_HIGH | 降频 | 下降 | 是 |
| COMBINED_HIGH → BASELINE | 升频 | 下降 | 否 |

**这 7 个边界上全部读到「功率下降」**——扰动多半把工作点推离峰。
（注意这是本日程 7 个边界的实测结果，不是定理：若扰动恰好把最优点推向当前频率，
功率会上升。但「推离」是多数情况。）
于是 P&O 的反应多为「反向 + 步长减半」，而这个反应**与最优点实际往哪走不相关**：
7 个边界里 4 个判错方向。

更要命的是步长。初值 0.5 kHz，每误判一次减半：`0.5 → 0.25 → 0.12 → 0.1 kHz`。
而 `CASE_FS_M5` 的 fs 跳变是 **45 kHz**。
**步长恰恰在最需要大步长的时刻坍缩到下限。**

缓解机制存在但不够快：检测器需 3 个连续确认 = 60 ms，而 P&O 一对只跨 40 ms。

现有日程中实际发生的跨边界配对是 **0/15**——机制是真的，代码也忠实地模拟了它
（探测点重新读 `schedule_at(t)`），但从未被触发过。段长 0.8 s、配对跨 40 ms，
单对撞上概率约 5%，15 对全躲开属于运气，不是设计保证。

### C. 相位判据多解 —— 文献有比我们现有防护更好的解法 〔中〕

裸 BVD 的端口相位在窗口内过零 2 次（v2.1 的 ±5° 判据下是 3 个解），
其中只有一个在功率峰上：

| 过零点 | 该点机械功率 |
|---|---|
| 805.4 kHz | 峰值的 92.6% |
| 862.8 kHz | 峰值的 **8.9%** |

控制律用 `np.sign(slope)` 就地测符号做校正，于是**每一个解都成了稳定吸引子**。
物理上，串联谐振附近 `dφ/df` 的符号由电路拓扑唯一确定，是**先验**量；
就地测符号等于主动放弃了「区分自己在哪个谐振附近」的能力。

**这是超声换能器驱动里的已知问题，文献称 antiresonance frequency tracing。**
解法不是事后检测，而是**静态电容宽带补偿（SCBC）**：并联一个电感 `L0 = 1/(w0²·C0)`，
使 C0 支路在 f0 附近开路，端口退化为纯串联 RLC，相位零点唯一。

实测验证（v3 几何，C0 = 1730.5 pF → **L0 = 22.87 µH**）：

- 相位过零点 **2 个 → 1 个**
- 唯一零点 799.9 kHz，功率峰 800.0 kHz，**相差 0.0 kHz，该点功率为峰值的 100.00%**
- 「相位归零」与「功率最大」两个判据不再打架

**这比本审核先前加的「事后功率探测 + 设定点重标定」干净得多**：
SCBC 防止问题发生，事后防护只能补救。建议把 SCBC 作为主要手段，
先前的防护保留作兜底。

### D. ESR 频率无关近似在加宽后的窗口下沿偏差 15% 〔低〕

代码取 `r_L = 2π·f0·L/Q_L` 并全频段固定，于是模型的 `Q ∝ f`；
物理上趋肤效应使 `R ∝ √f`，应为 `Q ∝ √f`。

| 频率 | 固定 R 模型 Q | 趋肤模型 Q | 差 |
|---|---|---|---|
| 650 kHz | 72.2 | 85.0 | **−15.0%** |
| 800 kHz | 88.9 | 94.3 | −5.7% |
| 900 kHz | 100.0 | 100.0 | 0 |

v2.1 的窗口 800–1000 kHz 内最大偏差 5.7%，可接受；
v3 把窗口加宽到 650–950 kHz 后，下沿达 15%。
**加宽扫描窗口的同时，这条近似的适用性也应重新评估**——我上一轮加宽窗口时没想到这一层。
影响的是匹配网络损耗，不影响谐振频率，优先级低。

### E. 单模 BVD 在 v3 窗口内成立（此项通过）

BVD 是单模模型，只有当扫描窗口内没有其他模态时才成立。核算：

| 模态 | 频率 | 窗口内？ |
|---|---|---|
| 长度模 2 次谐波 | 533.3 kHz | 否 |
| **长度模 3 次谐波（工作模态）** | **800.0 kHz** | **是** |
| 长度模 4 次谐波 | 1066.7 kHz | 否 |
| 环向（呼吸）模 | 1057.7 kHz | 否 |
| 壁厚模 | 6451.6 kHz | 否 |

窗口 650–950 kHz 内只有工作模态，最近的邻居各距窗边 >100 kHz。**单模 BVD 成立。**

注意：v2.1 的 BVD 由工作点反推、**没有几何**，这项检查根本无法进行。
让模态洁净性变得可验证，是正向推导的一个实际好处——
这个理由与我先前那条已被推翻的「高阻抗不可匹配」无关，它独立成立。

## 四、必须有实测或实机才能确定的事项

按导师的要求「如果某一部分需要实际数据或者实际设备才能确定请跟我说」，逐条列出：

### 1.〔中〕5 mA 的性质：一次测量，还是器件耐受上限

**注意：本条已从原来的「阻塞」降级。** 见第〇节——`100 Vpp / 5 mA`（换能器端）
与「50 Ω 射频功放」（功放端 58 mA）隔着匹配网络的 11.65:1 电流变换，本来就同时成立，
不存在矛盾。

仍需澄清的是这个数的**性质**，因为它决定换几何时该怎么迁移：

- 若是「那台器件在该工作点恰好抽这么多电流」→ 一次测量结果，换几何后需重测
- 若是「器件耐受上限」（发热/机械应力）→ 应先改写成与几何无关的量
  （电流密度 A/m²，或单位体积耗散 W/m³），才能搬到别的几何上

若能一并给出功放型号与最大输出，可用来核对功率余量，但不影响当前方案成立与否。

### 2.〔阻塞〕元件是否必须有中心孔走导丝

有 → 空心圆柱（几十 Ω）；无 → 实心柱也可（kΩ 级）。
这是应用需求问题，不是电学问题，但它单独就能定下整个阻抗尺度。

### 3. 占空比

文献器件是 9.1%（0.1 ms 脉冲 / PRF 909 Hz）。
占空比决定 5 mA 到底是热限还是别的限制——脉冲下热限会宽松得多。
也决定功率目标该按峰值还是平均值定。**本项目目前按连续波处理，未声明。**

### 4. Qm 实测（阻抗分析仪）

全项目最大的未知量，且直接决定：峰宽 → 扫描阶梯 → 准稳态驻留时间（见 A）。
方法已备好：`workspace/qm_extraction_20260916/实测作业指导书.md`，
按计划书文献 [6]（Janů 2021）的线性化提取法。

### 5. 材料常数

`epsilon_r`、`k31`、`N31`、`Qm_material` 现在全是公开典型值。
同一牌号不同厂家可差 ±20%，直接搬动 C0 与阻抗尺度。

### 6. Qm 随驱动电平的变化

模型是线性的，因此「低幅扫描找到的峰 = 满幅工作的峰」。
真实压电材料在高场下 Qm 下降、谐振频率软化，这个等式不成立。
**这是「降幅扫描」这一做法的成立前提，目前未验证。**

### 7. 血液中的实际辐射负载

`Q_rad = π·Z_piezo/(2·Z_blood) = 31.2` 是**平板、空气背衬、平面波**的公式。
空心圆柱的两个端面与内外侧壁都接触流体，实际辐射损耗可能更大、Qm 更低。
需要在水/血液模拟液中实测。

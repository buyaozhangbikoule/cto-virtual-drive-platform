# 下一阶段真实验证计划

本文件只登记当前虚拟模型需要被验证的假设，不表示已经获得实测数据。

## 1. 阻抗分析仪验证

- 在低驱动、小信号条件下测量0.8–1.0 MHz及其外扩范围的复阻抗。
- 同时保存校准方法、夹具/线缆补偿、温度、负载介质和重复测量条件。
- 从数据中拟合或辨识静态电容`C_0`、机械支路`R_m/L_m/C_m`、`f_s`和`Q_m`，并给出置信区间或重复性，而不是只给单一最优值；匹配电容另记为`C_match`。
- 对比指标：`Re(Z)、Im(Z)、|Z|、arg(Z)`、串/并联特征频率和峰宽。
- 目的：验证假设BVD基线、扰动方向和模型适用频段。

## 2. 电压、电流与功率验证

- 使用明确带宽和校准状态的差分电压探头、电流探头/取样阻抗及功率计算链路。
- 统一RMS、峰值和峰峰值口径，并保留同步采样的相位参考。
- 对比指标：换能器端口复电压、复电流、端口有功/无功/视在功率、源侧输入功率和功率平衡残差。
- 目的：验证戴维南源阻抗近似、匹配网络ESR、端口功率算法以及当前假设的电压/电流控制阈值。

## 3. 水听器与声场验证

- 在完成结构—压电—声场有限元模型、网格收敛和Solver Log审核后，再设计水槽/介质中的水听器扫描。
- 保留探头校准文件、空间步距、扫描几何、负载介质、驱动占空比和环境条件。
- 对比指标：靶区与壁面/非靶区声压、轴向/横向曲线、相对声学效率及必要时的积分声功率。
- 目的：建立电学工作点到声场代理的经验证查找表，并给出模型—仿真—测量误差。

## 4. 在完成真实验证前不得使用的结论

- 不把 `P_Rm` 写成辐射声功率。
- 不把反射代理写成实测反射功率。
- 不把假设电压/电流阈值写成器械安全上限。
- 不把特定BVD模型内的策略排序外推为通用换能器、组织效应或临床安全结论。

# 参数来源登记与使用边界

本次仅补齐参数元数据与只读网页，不修改任何BVD、匹配、源、控制配置或保护门槛，不产生新控制批次。

## 网页查看

运行 `python run_project.py ui`，左侧选择「参数与依据 → 参数来源登记」。按分区或关键字选择参数，再查看展开的来源说明。

每条显示：数值与单位、来源文件／DOI／表页、适用频段、测量或计算条件、假设身份、采用理由和限制。内部来源文件、完整JSON登记及CSV表可下载。统一结果的「采用配置与复现」页签、历史参数探索页和版本页也有入口。

本页不是可写配置编辑器。选择文献、过滤表格或下载数据均不会替换运行参数。文献PDF不随平台分发，DOI入口不保证免费全文。

## 四项核心处置

1. **原BVD不变**：C0、Rm、Lm、Cm、fs、Qm及匹配参数均保留假设／内部派生身份。与工作点数值自洽不代表真实器件已辨识；Rm的内部与负载损耗未被实测分离。
2. **设计工况不是器件额定值**：约100 Vpp是换能器端口目标，约5 mA RMS是推荐量级，50 Ω是戴维南源实数阻抗。没有因此建立完整射频功放、热限或脉冲占空比模型。160 Vpp沿用用户仿真边界；130 Vpp、5.5/6 mA是声明的控制阈值。
3. **Saijo独立登记**：原文Table 2，PDF第3页／期刊1063页；12例固定腹主动脉切片，100–200 MHz声学显微测量。钙化声速为1760±14 m/s（均值±SD），衰减斜率为2.5±0.1 dB/(mm·MHz)。它不是2.5 MRayl；原文未测密度或声阻抗，不能从声速单独得到ρc。不得直接移植到本项目0.9 MHz默认负载。
4. **2.5–7.8 MRayl待核实**：仅追溯到负载实施指导第十二节第3项，尚未建立原始出处。不可当作已证实文献范围、默认值或敏感性扫描上下界。原型1900 kg/m³和3600 m/s保留为声明假设，本次不改代码、不自动采用Saijo数值。

## 登记范围与核对含义

- `current/parameter_sources.json`：元数据源文件，公共条件放在profiles，每条参数可覆盖。
- `current/parameter_sources.py`：展开全部字段，用JSON字段或Python AST读取原始值。不会导入、运行或修改研究脚本。逐项核对正式配置中所有数值型参数是否已登记。
- `current/provenance_ui.py`、`pages/06_参数来源登记.py`：只读网页及下载。
- `current/tests/test_parameter_sources*.py`：元数据完整性、漂移、来源丢失、文献隔离、单位、搜索与页面切换测试。

若源文件值改变但登记未更新，页面给出不一致提示，同时保留登记值和当前原始值，不悄悄覆盖；若登记缺必要字段则停止展示。本页检查“声明与文件是否一致”，不证明物理适用性。冻结批次仍由原有证据校验器审核，不能用来源核对替代批次哈希与源码漂移检查。

覆盖的是正式配置数值输入、物理基线、负载原型主要声明和Saijo参考，不宣称所有历史脚本的内部常数、所有探索滑块或未来参数已经登记完毕。历史滑块改动仍是扫描变量，不升级为实测参数。

登记保留原始精度，页面适当缩短显示；JSON导出包含原始值和原始单位。文献记录仅有均值、SD、样本和频段依据，不能增添原文未报告的测量条件。

## 复核命令

在平台根目录执行：

```powershell
python -B -X utf8 -m current.parameter_sources
python -B -X utf8 -m unittest discover -s current/tests -p "test_parameter_sources*.py" -v
python run_project.py test
python run_project.py verify
```

仅核对来源不需要运行validate。后续若改变物理参数或控制配置，应按独立批次流程重跑，不能改写旧证据。

## 仍需补齐

- 实际器件几何、工作模态、频率响应辨识，以及连续波／脉冲与占空比。
- 钙化密度和声速的一手出处及温度、频带、组织制备条件；查不清就继续声明为假设。
- 高频薄片文献参数迁移到低频、在体或加载模型的独立证据。

这些缺口不会因增加网页字段而自动解决。
